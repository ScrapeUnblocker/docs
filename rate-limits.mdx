ScrapeUnblocker limits traffic per API key, not per IP. Your plan sets one limit: **concurrent requests** - how many of your requests can be in flight at once. A request counts from the moment it reaches us until its response is sent, so slow targets hold a slot longer. Idle keep-alive connections do not count, and each HTTP/2 stream counts separately.

| Plan | Concurrent requests |
| --- | --- |
| Pay as you go | 10 |
| Starter | 25 |
| Pro | 50 |
| Business | 100 |
| Scale | 150 |
| Ultimate | 200 |

Custom plans have their own limits. The plan card in the [dashboard](https://app.scrapeunblocker.com) shows the limit that applies to your key right now.

Your monthly request quota is separate - see [Monthly quota](#monthly-quota) below.

## When you hit the limit

A request over the limit is refused immediately with `429 Too Many Requests` (body `Concurrency limit exceeded`, header `X-SU-Deny-Reason: concurrency`) - it is not queued. Wait for one of your running requests to finish, then send the next.

`429` responses are not billed.

The recommended client behavior:

1. Run a fixed worker pool no larger than your concurrent requests limit.
2. On `429`, back off (for example 1-5 seconds) and retry. Use the `Retry-After` header if it is present.
3. Resume.

```python
import time
import requests

def call(url, key):
    while True:
        r = requests.post(
            "https://api.scrapeunblocker.com/getPageSource",
            params={"url": url},
            headers={"x-scrapeunblocker-key": key},
            timeout=120,
        )
        if r.status_code == 429:
            wait = int(r.headers.get("Retry-After", "2"))
            time.sleep(wait)
            continue
        return r
```

## Monthly quota

When you've used your monthly quota, requests return `402 Payment Required` with the body `Quota exceeded`. Upgrade your plan or wait for the next billing cycle. You can monitor remaining quota in the [dashboard](https://app.scrapeunblocker.com).

Quota is only one of three reasons for a `402` - an unpaid balance past your credit limit and a card that has failed repeatedly produce the same status code with different messages. See [402 payment required](/errors#402-payment-required) for all three and how each clears.
