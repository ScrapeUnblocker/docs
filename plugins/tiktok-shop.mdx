The **TikTok Shop** plugin turns the US TikTok Shop into structured JSON. It is three endpoints:

- **`/social/tiktok-shop-search`** - up to 30 product cards for a keyword, or about 15 for a category: price and discount, rating, review count, sold count, brand, seller and, when TikTok binds one, the promoting video with its play and like counts. A keyword also returns related searches and categories; a category returns its subcategories and breadcrumbs.
- **`/social/tiktok-shop-product`** - one product in full: title, description, status, brand, price or price range, sold count, rating with its 1-5 star distribution, category path, images, options and every variant with price and stock, specifications, shipping, promotion labels, the seller with service scores, and the top reviews the page shows.
- **`/social/tiktok-shop-store`** - a store's profile (rating, followers, sold count, product, review and video counts, service scores) and up to 20 products from its storefront.

The plugin covers the US storefront only and prices are in USD. Each endpoint reads one page and is one billed request. No TikTok account or cookies are involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

List products for a keyword or a category.

```
POST /social/tiktok-shop-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | one of `q` / `category` | Search keyword, e.g. `led face mask`, or a TikTok Shop keyword URL like `https://www.tiktok.com/shop/product/led-face-mask`. |
| `category` | one of `q` / `category` | List a category instead of a keyword: a category URL (`https://www.tiktok.com/shop/c/beauty-personal-care/601450`) or its numeric id (`601450`). |
| `max_results` | no | Products to return, `1`-`30`. Default `30`. A keyword lists up to 30 products, a category about 15. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/social/tiktok-shop-search?q=led%20face%20mask&max_results=5" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.tiktok_shop_search("led face mask", max_results=5)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.tiktokShopSearch("led face mask", { maxResults: 5 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->tiktokShopSearch('led face mask', ['max_results' => 5]);
```

```ruby Ruby

```
</CodeGroup>

To list a category, leave the keyword out and pass the `category` option, e.g. `su.tiktok_shop_search(category="601450")` in Python. A keyword or category TikTok has no listing for returns `404`; try a broader keyword or a category.

| Field | Notes |
| --- | --- |
| `productId` / `url` | TikTok Shop product id and the product page URL. Pass either to [Product](#product). |
| `title` / `image` | Product title and main image. |
| `price` | `current`, `original`, `discountPercent`, `currency` (USD), `currencySymbol` and `fromPrice` (`true` when the card shows a "from" price for a range). |

| `brand` | Brand, when the product lists one. |
| `seller` | `id`, `name` and `logo`. Pass the `id` to [Store](#store). |
| `labels` | Promotion labels, e.g. `Free shipping`. |
| `video` | Present when TikTok binds a promoting video: `id`, `url`, `title`, `author`, `playCount`, `likeCount`, `durationSeconds`, `uploadedAt` and `cover`. |

## Product

```
POST /social/tiktok-shop-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | one of `url` / `product_id` | A product URL (`https://www.tiktok.com/shop/pdp/<slug>/<id>`, `https://shop.tiktok.com/us/pdp/<id>` or a `/view/product/` link) or a bare product id. |
| `product_id` | one of `url` / `product_id` | The numeric product id, e.g. `1732224050708320653`. |

| `reviews` | The top reviews the product page shows (not the full review list): `rating`, `text`, `date`, masked `reviewer`, `verifiedPurchase`, `variant`, `country` and `images`. |

## Store

```
POST /social/tiktok-shop-store
```

| Field | Required | Notes |
| --- | --- | --- |
| `store` | yes | A store URL (`https://www.tiktok.com/shop/store/<name>/<seller id>`) or the seller id, e.g. `7496099972735732109`. |
| `max_results` | no | Storefront products to return, `0`-`20`. Default `20`. `0` = store profile only. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/social/tiktok-shop-store?store=7496099972735732109&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python

su = Client()  # reads SCRAPEUNBLOCKER_KEY
```


## What you can build

- **Product research** - find best-selling products for a keyword or category with sold counts and promoting videos.
- **Price and stock monitoring** - track a product's variants, prices, discounts and stock over time.
- **Seller intelligence** - compare stores by followers, sales and service scores.
- **Creator-led demand signals** - use the bound video's play and like counts to see which products are getting traction.
