The **Allegro** plugin returns offers from Allegro (allegro.pl), Poland's largest marketplace, as structured JSON. It is two endpoints:

- **`/marketplace/allegro-search`** - the offers for a keyword, in Allegro's order: offer and product id, title, price, price with delivery and the cheapest delivery, free delivery and Allegro Smart! flags, the delivery label, rating, rating count, recent buyers (bought in the last 30 days), the sponsored, promoted and Super Seller flags, the seller (id, login, company, positive feedback share), the offer parameters, images and link. Filter by price, condition, where it ships from, delivery speed, offer type and the seller's town or region; sort; collect across pages.
- **`/marketplace/allegro-product`** - one offer: title, catalogue product name, brand and GTIN, price and crossed-out price, selling mode (buy now or auction), stock, condition, rating with its 1-5 star breakdown, recent buyers, category and breadcrumbs, the parameter table, description, images, variants, the seller (Super Seller flag, feedback counts, company name and tax id), location, Smart!, delivery, every shipping method with its price, return days, warranty, end time and reviews.

Prices are in Polish zloty (PLN). No Allegro account or API key is involved.

## Search

```
POST /marketplace/allegro-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `iphone 15` or `lego`. |
| `sort` | no | Result order: `relevance`, `price_asc`, `price_desc`, `price_with_delivery_asc`, `price_with_delivery_desc`, `popularity`, `ending_soon`, `newest`, `rating`. Default `relevance`. |
| `page` | no | First Allegro results page to read, `1`-`100`. Default `1`. |
| `min_price` / `max_price` | no | Price range in zloty (PLN). |
| `condition` | no | Item condition: `new`, `like_new`, `refurbished`, `used`, `damaged`. |
| `shipping_from` | no | Where the item ships from: `pl`, `cz`, `sk`, `hu`, `cn`, `eu`, `allegro_warehouse`. |
| `delivery_time` | no | Delivery speed: `one_day` (tomorrow), `two_days`, `three_days`. |
| `offer_type` | no | `buy_now` (fixed price) or `auction`. |
| `store_city` | no | The seller's town, e.g. `Kraków`. |
| `store_region` | no | The seller's voivodeship, e.g. `mazowieckie` or `slaskie` (or its number `1`-`16`). |
| `max_results` | no | Offers to collect across pages, `1`-`300`. Default `60`. A page holds about 60 offers. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `DE`, `CZ`). Best left blank: Allegro refuses exits from some countries, and the API picks ones it accepts. |

| Field | Notes |
| --- | --- |
| `offerId` / `productId` | The offer number and Allegro's catalogue product id. Pass `offerId` to [Offer](#offer). |
| `title` / `image` / `images` / `url` | Offer title, images and link. |
| `price` / `buyNowPrice` / `currency` / `endsIn` | Price in PLN; for an auction, the current bid with the buy-now price and the time left. |

| `smart` / `deliveryLabel` | Allegro Smart! eligibility and the delivery promise as printed. |

| `parameters` | The offer parameters shown on the card (condition, colour, memory, ...), in Polish as Allegro prints them. |
| `total` / `available` / `lastPage` / `nextPage` | All matches, offers Allegro lets you page through, the last page and the `page` to pass to continue. |

## Offer

```
POST /marketplace/allegro-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `offer_id` | one of `offer_id` / `url` | Allegro offer number, e.g. `16680923539` (the number at the end of an `/oferta/` link, or an `offerId`). |
| `url` | one of `offer_id` / `url` | An Allegro offer or product link, e.g. `https://allegro.pl/oferta/16680923539` or `https://allegro.pl/produkt/...?offerId=16680923539`. Used instead of `offer_id`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Best left blank, as in search. |

| `reviews` | Reviews shown on the offer: `rating`, `text`, `date` and the masked `author` Allegro prints. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, an unknown filter value, or neither `offer_id` nor `url`. |
| `404` | Allegro found no offers for this search, or has no offer with this number. |
| `502` | Allegro blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |
