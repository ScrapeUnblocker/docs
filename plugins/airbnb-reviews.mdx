The **Airbnb Reviews** plugin reads every guest review of an Airbnb listing, not just the few on the room page, and returns them as structured JSON. Give it a listing id or a room URL from any Airbnb domain and it returns each review's star rating, the text as written with its language, Airbnb's translation into the `locale` you pick, the date, the stay detail, photos, the reviewer and the host's response.

The listing summary comes with them: title, room and property type, host, overall and six category ratings, review count, the rating distribution and review tags. Order by relevance, most recent, highest or lowest rated, drop older reviews with `since`, and collect up to 500 per call from any page or offset. Each page of up to 50 reviews read is one billed unit (`pagesFetched`). It is the reviews companion to [Airbnb Stays](/plugins/airbnb) and [Airbnb Listing](/plugins/airbnb-listing).

## Listing reviews

```
POST /travel/airbnb-reviews
```

| Field | Required | Notes |
| --- | --- | --- |
| `room` | yes | Airbnb listing id (e.g. `23860926`) or a room URL on any Airbnb domain, e.g. `https://www.airbnb.co.uk/rooms/23860926`. |
| `max_reviews` | no | How many reviews to return, `1`-`500`. Default `50`. Airbnb serves 50 reviews per request; each request is one billed unit. |
| `page` | no | 1-based page of `max_reviews`-sized pages (`1`-`1000`). Default `1`. Pass a previous response's `nextPage` to continue. |
| `offset` | no | Start at this review position instead of `page` (`0`-`20000`). Pass a previous response's `nextOffset` to resume exactly. |
| `sort` | no | `most_relevant` (default, Airbnb's own order), `most_recent`, `highest_rated` or `lowest_rated`. |
| `locale` | no | Language to translate reviews and host responses into, e.g. `en`, `de`, `fr`, `es`, `pt-BR`. Default `en`. The original text and its language always come back too. |
| `since` | no | Only reviews written on or after this date (`YYYY-MM-DD`). With `sort=most_recent` paging also stops once older reviews start. |
| `include_listing` | no | Also return the listing summary. Default `true`; set `false` to skip it. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). |

### Review fields

| Field | Notes |
| --- | --- |
| `id` / `rating` | Review id and star rating (1-5). |
| `text` / `language` | The review as the guest wrote it, and its language. |
| `translatedText` | Airbnb's translation into `locale`; `null` when the review is already in that language. |
| `date` / `localizedDate` | ISO timestamp and Airbnb's relative date (e.g. `1 week ago`). |
| `stayDetail` / `stayDetailType` | Airbnb's stay line, such as `Stayed a few nights` or `Group trip`, and its type. |
| `photos` | Photos attached to the review. |
| `reviewer` | `name`, `photo`, `location` or `tenure` (time on Airbnb), `profileUrl` and `profileId` (the public profile Airbnb's review cards open), `isSuperhost`, and `deleted` when the guest has since closed their account. `id` is Airbnb's internal account id. |
| `response` | The host's public response, `null` when there is none. |

### Listing summary and paging

| Field | Notes |
| --- | --- |
| `listing.rating` | `overall` plus the six category ratings (out of 5). |
| `listing.ratingDistribution` | Each star's share of ratings as a 0-1 fraction (`0.916` = 91.6%), as Airbnb gives it. |
| `listing.ratingCounts` | Number of ratings per star, worked out from those shares and `reviewsCount`; `null` when they do not fit (seen on some hotel listings). |
| `listing.reviewTags` | Airbnb's review topics (`key`, `name`, `count`), such as Location or Hospitality. |
| `totalResults` / `hasMore` | Reviews the listing has, and whether more remain after this call. |
| `nextPage` / `nextOffset` | Pass as `page` or `offset` to continue. |

## What you can build

- **Guest feedback monitoring** - pull new reviews with `sort=most_recent` and `since` and alert on low ratings.
- **Multilingual sentiment analysis** - analyze every review in one language through `translatedText`, keeping the original.
- **Host response tracking** - see how often hosts reply to reviews and what they say.
- **Short-term rental research** - compare rating distributions and review topics across competing listings.
