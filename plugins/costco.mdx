The **Costco** plugin returns products from Costco (costco.com, or costco.ca with `domain=ca`) as structured JSON. It is two endpoints:

- **`/marketplace/costco-search`** - the products for a keyword: product id and item number, title, brand, link and image, the price (and the top of a price range), was-price, promotions and marketing text, rating and review count, the member-only, online-only and warehouse-only flags, badges, availability, whether it is sold in the warehouse or shipped, the model, features and category path. 24 products per page, as on costco.com; one call collects up to 240.
- **`/marketplace/costco-product`** - one product by product id, item number or link: price and discount, rating, description, details, features, shipping, manufacturer and part number, UPC, order limits, category path, specifications, images, the options (e.g. every color and size) and every variant with its item number and UPC.

No Costco membership is involved. Some Costco prices are shown only in the cart; those products carry `priceShownInCartOnly: true`.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/costco-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `paper towels`, `kirkland coffee` or `tv`. |
| `sort` | no | Result order: `relevance`, `price_low`, `price_high`, `rating`, `newest`, `brand`. Default `relevance`. |
| `page` | no | 1-based results page to start from (24 products per page, as on costco.com). Default `1`. |
| `max_results` | no | Products to collect from `page` on, `1`-`240`. Default `24`. |
| `include_out_of_stock` | no | Also return products that are out of stock (Costco hides them by default). Default `false`. |
| `domain` | no | Costco storefront: `com` (costco.com) or `ca` (costco.ca). Default `com`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. Costco computes `availability` for the delivery location it derives from the visitor, named in `deliveryLocation`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/costco-search?query=paper%20towels&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.costco_search("paper towels", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.costcoSearch("paper towels", { maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->costcoSearch('paper towels', ['max_results' => 3]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.costco_search("paper towels", max_results: 3)
```
</CodeGroup>

Up to 120 products are billed as one request (`max_results` above 120 is two). A search with no matches is a `200` with an empty `products` list. A keyword Costco sends to a category page (e.g. `tv`) returns that category's products, named in `redirectedTo`.

| Field | Notes |
| --- | --- |
| `productId` / `itemNumber` | Costco's product id and item number. Pass either to [Product](#product). |
| `title` / `brand` / `url` / `image` | Name, brand, link and image. |
| `price` / `priceMax` / `wasPrice` / `currency` | The price (the low end of a price range, with `priceMax` the high end), the crossed-out price and the currency (`USD` or `CAD`). |
| `promotions` / `marketingStatement` | Promotion texts and Costco's marketing line, when shown. |
| `rating` / `reviewCount` | Rating and review count. |
| `memberOnly` / `onlineOnly` / `warehouseOnly` | Costco's member-only, online-only and warehouse-only flags. |
| `badges` | Badges on the product tile. |
| `availability` / `inWarehouse` / `shipIt` / `buyableOnline` | Availability for the delivery location in `deliveryLocation`, and how the product is sold. |
| `priceShownInCartOnly` | `true` when Costco shows the price only in the cart. |
| `model` / `features` / `category` / `categoryPath` / `variantCount` | Model number, feature bullets, category, the full category path and the number of variants. |
| `totalResults` / `resultsCollected` | Costco's result count, and how many products this call returned. |
| `redirectedTo` / `correctedQuery` | The category page Costco sent the keyword to, and Costco's spelling correction, if any. |
| `deliveryLocation` | The delivery location Costco derived from the visitor and used for `availability`: `postalCode`, `state`, `city`. |

## Product

```
POST /marketplace/costco-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product` | yes | A Costco product id (`100361434`), item number (`17767`) or product link (`https://www.costco.com/p/-/kirkland-signature-colombian-coffee-dark-roast-3-lbs/100361434`). |
| `domain` | no | Costco storefront: `com` or `ca`. Defaults to the link's storefront, else `com`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

| Field | Notes |
| --- | --- |
| `productId` / `itemNumber` / `title` / `brand` / `url` | Identity and link. |
| `price` / `discount` / `currency` | The price, the discount when Costco shows one, and the currency. |
| `rating` / `reviewCount` | Rating and review count. |
| `memberOnly` / `onlineOnly` / `buyable` / `inWarehouse` / `shipIt` | Costco's flags: member-only, online-only, can be bought online, sold in the warehouse, shipped. |

| `minQuantity` / `maxQuantity` | Order limits. |
| `categoryPath` / `specifications` / `images` | Category path, the specification table and the image gallery. |
| `options` | The product's options, e.g. every color and size with its values. |
| `variants` | Every variant: `itemNumber`, its `options` values, `upc`, `buyable` and `published`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query` or `product`, an unknown `sort` or `domain`, or `max_results` outside `1`-`240`. |
| `404` | Costco has no such product. |
| `502` | Costco blocked every attempt, gave an unusable page, or did not answer in time. Retry. |

## What you can build

- **Price monitoring** - follow Costco prices, was-prices and promotions for the products you sell or buy.
- **Assortment research** - see which brands and Kirkland Signature products Costco carries in a category.
- **Cross-border comparison** - compare the same item on costco.com and costco.ca with `domain`.
- **Product data** - collect specifications, UPCs and variant item numbers for a catalogue.
