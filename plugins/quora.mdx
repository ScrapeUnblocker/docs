The **Quora** plugin turns Quora questions and profiles into structured JSON. Give it a question - a quora.com question URL, an answer URL on it, or the question slug such as `What-is-the-best-way-to-learn-programming` - and it returns the question (id, title, answer, follower and comment counts, topics) and its answers in Quora's own order: the full text with images and links, the author with credential, upvotes, views, shares, comments, created and updated dates and an AI-generated flag, plus the related questions Quora lists. Language editions such as `es.quora.com` work as URLs.

Give it a profile instead and it returns the public profile - headline, follower, answer and question counts, content views, credentials, topics, Spaces, Top Writer years and join date - with its newest answers.

It reads only what Quora shows a logged-out visitor, so no Quora account or cookies are involved. Quora's keyword search and topic feeds sit behind its sign-up wall and are not offered.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Question and answers

```
POST /social/quora
```

| Field | Required | Notes |
| --- | --- | --- |
| `question` | yes | Quora question URL (`https://www.quora.com/What-is-the-best-way-to-learn-programming`), an answer URL on it, or the question slug. |
| `mode` | - | Set to `question` by `quoraQuestion`. |
| `max_answers` | no | How many answers to return, `1`-`300`. Default `20`. Answers come 10 per page after the first few; each page is one billed unit. |
| `include_related` | no | `true` also returns the answers Quora shows from related questions (its "All related" view, `relation`=`related`). By default you get answers to this question and to questions merged into it. Default `false`. |
| `cursor` | no | Continue after a previous call: pass its `nextCursor`. Best-effort, see below. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank for the countries chosen for the site. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/social/quora?mode=question&question=What-is-the-best-way-to-learn-programming&max_answers=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.quora_question("What-is-the-best-way-to-learn-programming", max_answers=3)
```

| Field | Notes |
| --- | --- |
| `id` / `url` | Quora's answer id and its link. |
| `relation` | `answer` (to this question), `merged` (to a question Quora merged into this one) or `related` (with `include_related=true`). |
| `question` | The question the answer was written for: `qid`, `title` and `url`. |
| `author` | `name`, `uid`, `profileUrl`, `imageUrl`, `credential` line, `isVerified` and `isAnonymous`. |
| `text` / `images` / `links` | The full answer text, and the images and links in it. |
| `upvotes` / `views` / `shares` / `comments` | Engagement counts. |
| `createdAt` / `updatedAt` | ISO-8601 dates. |
| `isPinned` / `isAiGenerated` | Pinned answer, and Quora's AI-generated flag. |

The `question` object at the top carries `qid`, `title`, `url`, `answerCount`, `allRelatedCount`, `followerCount`, `commentCount` and `topics`.

Answers are unique within a call. Quora re-ranks the list on every visit, so continuing with `cursor` can repeat or skip answers of earlier calls - dedupe by `id`, or ask for a larger `max_answers` in one call (up to 300) when you need the complete list. `pagingStopped` names why paging ended early (`blocked`, `time` or `unavailable`), and is `null` when it did not.

## Profile

```
POST /social/quora
```

| Field | Required | Notes |
| --- | --- | --- |
| `profile` | yes | Quora profile URL (`https://www.quora.com/profile/Adam-DAngelo`) or profile slug (`Adam-DAngelo`). |
| `mode` | - | Set to `profile` by `quoraProfile`. |
| `max_answers` | no | How many of the newest answers to return, `0`-`200`. Default `10`; `0` returns the profile only. |
| `cursor` | no | Continue after a previous call: pass its `nextCursor`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank for the countries chosen for the site. |

| Field | Notes |

`answers` has the same shape as in question mode. Quora lists only a profile's newest few dozen answers to logged-out visitors; when paging stops there, `pagingStopped` is `quora_logged_out_limit`.

## What you can build

- **Content research** - collect the best answers on a topic to brief writers or seed an FAQ.
- **Brand and topic monitoring** - watch questions about your product or category and their answer counts.
- **Expert discovery** - find active, credentialed authors through their profiles and answer stats.
- **Q&A datasets** - turn long-form answers with their engagement counts into a curated text set.
