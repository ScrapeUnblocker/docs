The **Ahrefs** plugin runs seven of Ahrefs' free SEO tools and returns their answers as structured JSON, with no Ahrefs account, login or API key. Pick the tool with `tool`:

- **Domain tools** take a domain or URL as `target`: `authority` (Domain Rating, backlinks, referring domains and their dofollow share), `backlinks` (the same plus the top backlinks), `traffic` (monthly organic traffic, its value in USD, history, top pages, countries and keywords) and `broken-links` (broken backlinks pointing at the site and broken links on its pages). `mode` sets the scope: the domain with its subdomains, the domain alone, everything under a URL prefix, or one exact URL.
- **Keyword tools** take a search phrase as `keyword` and a market as `country`: `keyword-difficulty` (KD 0-100, the referring domains a page needs to rank and the SERP it was read from), `keywords` (Google keyword ideas and question ideas with difficulty and volume buckets) and `serp` (the top Google results with Ahrefs metrics for each organic result, plus the AI overview, questions, shopping, local and news blocks).

The figures are Ahrefs' own, as its free tools show them to signed-out visitors: the top backlinks, pages, countries and keywords rather than every one, and keyword volumes as buckets such as `10K+`.

## Free SEO tools

```
POST /seo/ahrefs
```

| Field | Required | Notes |
| --- | --- | --- |
| `tool` | yes | `authority`, `backlinks`, `traffic`, `broken-links` (these take `target`), `keyword-difficulty`, `keywords` or `serp` (these take `keyword`). Ahrefs' page names and shorthands also work, e.g. `dr`, `kd`, `backlink-checker`, `keyword-generator`. |
| `target` | for domain tools | Domain or URL, e.g. `github.com` or `https://github.com/features`. |
| `keyword` | for keyword tools | Search phrase, e.g. `crm software`. |
| `country` | no | Two-letter market code. Keyword tools: the Google market searched (default `us`). `traffic`: limits the estimate to that country (default worldwide). Not used by the other domain tools. |
| `mode` | no | Target scope for the domain tools: `subdomains` (default, the domain with all its subdomains), `domain` (without subdomains), `prefix` (everything under the URL) or `exact` (that URL only). |
| `protocol` | no | `traffic` only: `both` (default), `http` or `https`. |
| `questions` | no | `keywords` only: also return question ideas. Default `true`. |

### Response

Every answer carries `tool`, `query` (the resolved target, mode, keyword and country, so a batch can be matched back to its inputs), `source` (the Ahrefs tool page) and `found`, plus the tool's own fields. `tool=backlinks`:

```json
{
  "tool": "backlinks",
  "query": { "target": "github.com", "mode": "subdomains" },
  "source": "https://ahrefs.com/backlink-checker",
  "found": true,
  "domainRating": 97.0,
  "backlinks": 4923570941,
  "referringDomains": 2459599,
  "dofollowBacklinksPercent": 90,
  "dofollowReferringDomainsPercent": 95,
  "topBacklinks": [
    {
      "urlFrom": "https://duckduckgo.com/",
      "urlTo": "https://github.com/duckduckgo/tracker-blocklists",
      "title": "DuckDuckGo - Protection. Privacy. Peace of mind.",
      "anchor": "list of trackers",
      "textBefore": "more , which all help cover different tracking angles. Our",
      "textAfter": "is open source, along with the list of exceptions we",
      "domainRating": 91,
      "redirectChain": [],
      "inRenderedHtml": true,
      "inRawHtml": false
    }
  ]
}
```

| Field | Notes |
| --- | --- |
| `found` | `false` (with the tool's fields empty or `null`) when Ahrefs has no data for the target or keyword. A failure returns an error status instead. |
| `domainRating` | Ahrefs Domain Rating (0-100). |
| `backlinks` / `referringDomains` | Total backlinks and linking domains. `dofollowBacklinksPercent` and `dofollowReferringDomainsPercent` give the dofollow share of each. |
| `topBacklinks` | The strongest backlinks: linking page (`urlFrom`), target (`urlTo`), page `title`, `anchor`, the text around the link, the linking site's `domainRating`, any `redirectChain`, and whether the link is in the rendered and the raw HTML. |

`tool=authority` returns the same fields without `topBacklinks`.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Missing or unknown `tool`, a domain tool without `target` (or a keyword tool without `keyword`), a malformed `country`, or Ahrefs rejected the target or keyword. The message says what to fix. |
| `502` | Ahrefs could not be reached or did not answer in time. Retry. |

## What you can build

- **SEO dashboards** - track Domain Rating, referring domains and organic traffic for your site and a set of competitors.
- **Link building** - find broken backlinks to reclaim and see which pages link to a competitor.
- **Keyword research** - collect keyword and question ideas with difficulty and volume buckets for a topic.
- **SERP analysis** - see who ranks for a keyword and how strong each result is before you target it.
