The **Home Depot Search** plugin turns a Home Depot search into structured JSON. Give it a keyword and it returns the products Home Depot shows - each with its `itemId`, title, brand, model number, price and the original price when it is on sale, currency, star rating, review count, an image and a clean product URL - plus the total result count.

Sort by relevance, price, rating or best sellers, filter by a USD price range, and collect up to `max_results` products across pages (about 24 per page) starting from any `page`.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/homedepot-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `cordless drill` or `interior paint`. |
| `sort` | no | `relevance` (default), `price_low`, `price_high`, `top_rated` or `best_seller`. |
| `min_price` / `max_price` | no | Price range in USD (whole dollars). |
| `page` | no | 1-based page to start from (about 24 per page). Default `1`. |
| `max_results` | no | How many products to collect across pages. Default `24`, max `500`. |
| `proxy_country` | no | Proxy country (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/homedepot-search?query=cordless%20drill&max_price=150&max_results=24" \

```

| Field | Notes |
| --- | --- |
| `itemId` | Home Depot's internal item id, the last segment of the product URL. |
| `title` / `brand` | Product title and brand. |
| `modelNumber` | Manufacturer model number, handy for matching the same product across retailers. |
| `price` / `currency` | Current price and ISO currency (USD). |
| `originalPrice` | The price before a markdown, present only when the product is on sale. |
| `rating` / `reviewCount` | Star rating (out of 5) and number of reviews. |
| `image` / `url` | Product image and a clean product URL. |

A field with no value is left out of that product (for example `brand`, `modelNumber` or `originalPrice`).

## What you can build

- **Price monitoring** - track prices and markdowns for tools, appliances and building materials.
- **Cross-retailer matching** - match products to other stores by `modelNumber` and compare prices.
- **Assortment research** - see which brands and models Home Depot carries for a category.
- **Review signals** - rank products by `rating` and `reviewCount` for buying guides.
