The **Google Play** plugin turns Play Store listings into structured JSON. Give it a package id such as `com.whatsapp` and it returns the app's full listing: title and developer with contact details, category, the star score with its rating and review counts and the full histogram, installs, price and in-app purchase range, content rating, description, icon and screenshots, last update, what's-new notes and the apps Play lists as similar. Or search by keyword and get the matching apps with their package id, developer, score and installs.

`hl` sets the language and `gl` the store country. No Google Play developer account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## App details

```
POST /apps/google-play
```

| Field | Required | Notes |
| --- | --- | --- |
| `app_id` | yes | Play package id, e.g. `com.whatsapp`. |
| `mode` | - | Set to `app` by `googlePlayApp`. |
| `hl` | no | Language code, e.g. `en` (default) or `de`. |
| `gl` | no | Store country (ISO-2), e.g. `us` (default) or `de`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/apps/google-play?mode=app&app_id=com.whatsapp&hl=en&gl=us" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.google_play_app("com.whatsapp", hl="en", gl="us")
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.googlePlayApp("com.whatsapp", { hl: "en", gl: "us" });
```

| Field | Notes |
| --- | --- |
| `appId` / `title` / `summary` / `url` | Package id, app name, Play's short summary and the store link. |
| `description` | Full description (HTML in `description`, plain text in `descriptionText`). |
| `developer` / `developerId` / `developerLegalName` | Developer name, Play developer id and legal entity. |
| `developerWebsite` / `developerEmail` / `developerAddress` / `developerPhone` | The developer's public contact details, when the listing shows them. |
| `genre` / `genreId` | Play category. |
| `score` / `scoreText` | Average star rating (out of 5), as a number and as Play prints it. |
| `ratings` / `reviews` / `histogram` | Number of ratings, number of written reviews and the count per star. |
| `installs` / `minInstalls` / `realInstalls` | The install band as Play prints it, its lower bound and the exact install count. |
| `price` / `currency` / `free` | Price (`0` for free apps) and currency. |
| `offersInAppPurchases` / `inAppPurchases` | Whether the app sells in-app items, and their price range. |
| `contentRating` | Age rating, e.g. `Everyone`. |
| `icon` / `headerImage` / `screenshots` | Listing images. |
| `released` / `updated` | Release date, and last update as a Unix timestamp (`updatedISO`, `updatedText` for other formats). |
| `version` | Current version, when the listing shows one. |
| `whatsNew` / `whatsNewText` | Release notes of the latest update (HTML and plain text). |
| `similarApps` / `similarAppsCount` | Package ids of the apps Play lists as similar. |

## App search

```
POST /apps/google-play
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | Search term, e.g. `vpn`. |
| `mode` | - | Set to `search` by `googlePlaySearch`. |
| `max_results` | no | How many apps to return, `1`-`100`. Default `30`. |
| `hl` | no | Language code, e.g. `en` (default). |
| `gl` | no | Store country (ISO-2), e.g. `us` (default). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/apps/google-play?mode=search&q=vpn&max_results=5" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.google_play_search("vpn", max_results=5)
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.googlePlaySearch("vpn", { maxResults: 5 });
```
```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->googlePlaySearch('vpn', ['max_results' => 5]);
```

## What you can build

- **App store intelligence** - track ratings, installs and the star histogram of your app and its competitors.
- **Release monitoring** - watch `updated` and `whatsNewText` to see when rivals ship.
- **Keyword rank tracking** - record where apps place for a search term, per store country.
- **Market and lead research** - list apps in a niche with their developers and public contact details.
