The **Falabella** plugin returns products from Falabella, the largest department store and marketplace in Chile, Colombia and Peru, as structured JSON. It is two endpoints:

- **`/marketplace/falabella-search`** - the products for a keyword, in Falabella's order: product and SKU id, title, brand and link, the price (or price range), the price with the Falabella CMR card, the crossed-out list price and the discount, rating and review count, the seller, the sponsored and best-seller flags, free shipping and delivery labels, interest-free installments, images, the top specifications and the colour or size options. Falabella shows 48 products per page; one call collects up to 480.
- **`/marketplace/falabella-product`** - one product in full: description and long description, prices, availability, the low-stock count when Falabella shows one, rating, seller, delivery labels, breadcrumbs, specifications, images, videos, the return policy and every colour and size SKU with its own price, availability, delivery options and images.

Pick the store with `country`: `cl` (falabella.com, prices in CLP), `co` (falabella.com.co, COP) or `pe` (falabella.com.pe, PEN). No Falabella account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/falabella-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search, e.g. `zapatillas nike`, `televisor 55` or `notebook`. |
| `url` | one of `query` / `url` | A Falabella search link instead of `query`, e.g. `https://www.falabella.com/falabella-cl/search?Ntt=zapatillas`. Its store, sort and page are used. |
| `country` | no | Falabella store: `cl`, `co` or `pe`. Default `cl`. |
| `sort` | no | `relevance`, `price_low`, `price_high`, `rating` or `brand`. Default `relevance`. |
| `page` | no | 1-based results page to start from, `1`-`200`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`480`. Default `48`. Falabella serves 48 per page and **each page fetched is billed as one request** (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/falabella-search?query=zapatillas%20running&country=cl&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

```


| `totalResults` / `hasMore` / `nextPage` | Falabella's match count, whether more pages exist, and the page to pass as `page` to continue. |
| `correctedQuery` | The query Falabella searched instead, when it corrected the spelling. |

## Product

```
POST /marketplace/falabella-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | Falabella product id, e.g. `17776888` or `prod11930024` (the part after `/product/` in a product link). Needs `country` unless the store is `cl`. |
| `url` | one of `product_id` / `url` | A Falabella product link instead, e.g. `https://www.falabella.com/falabella-cl/product/17776888/...`. Its store and SKU are used. Give `product_id` or `url`, not both. |
| `sku` | no | The variant (SKU) whose price and availability fill the top-level fields. Default: the product's main variant. Every variant is in `variants` either way. |
| `country` | no | With `product_id`: the store, `cl`, `co` or `pe`. Default `cl`. |

```bash cURL

  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `query` nor `url`, a missing or malformed `product_id` / `url`, both `product_id` and `url`, or an unknown `country`. |
| `404` | Search: Falabella found no products, or sends the keyword to a landing page without a results list. Product: no such product. |
| `502` | Falabella blocked every attempt, returned no results page or product data, or the call did not finish in time. Retry. |

## What you can build

- **Price monitoring across Chile, Colombia and Peru** - track list price, sale price and the CMR card price per SKU.
- **Marketplace seller research** - see which sellers list a product and how they price it against Falabella itself.
- **Assortment and size availability** - read every variant's stock, home delivery and store pickup.
- **Promotion tracking** - follow discounts, badges and interest-free installment offers over time.
