The **Airbnb Listing** plugin returns one Airbnb stay in full as structured JSON. Give it a listing id or a room URL from any Airbnb domain and it returns the title, description, room and property type, location with coordinates, the host (superhost flag, response rate, years hosting), the overall and six category ratings, guests, bedrooms, beds and bathrooms, grouped amenities, the photo gallery, highlights, house rules and check-in and check-out times.

Add `check_in` and `check_out` for availability, the cancellation policy and the price for those dates with its nightly breakdown, in the `currency` you choose. Add `include_reviews` for up to 100 guest reviews with translations. It is the single-listing companion to [Airbnb Stays](/plugins/airbnb) (search) and [Airbnb Reviews](/plugins/airbnb-reviews) (every review of a listing).

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Listing details

```
POST /travel/airbnb-room
```

| Field | Required | Notes |
| --- | --- | --- |
| `room` | yes | Airbnb listing id (e.g. `23860926`) or a room URL on any Airbnb domain, e.g. `https://www.airbnb.co.uk/rooms/23860926`. |
| `check_in` | no | Check-in date `YYYY-MM-DD`. With `check_out`, adds price, availability and the cancellation policy. |
| `check_out` | no | Check-out date `YYYY-MM-DD` (with `check_in`). |
| `adults` | no | Adult guests, `1`-`16`. Default `1`. Affects the price. |
| `children` | no | Children aged 2-12, `0`-`15`. Default `0`. |
| `infants` | no | Infants under 2, `0`-`5`. Default `0`. |
| `pets` | no | Pets, `0`-`5`. Default `0`. |
| `currency` | no | Price currency, ISO code such as `USD`, `EUR` or `GBP`. Default `USD`. |
| `locale` | no | Language for Airbnb's texts, e.g. `en`, `de`, `fr`, `es`, `pt-BR`. Default `en`. Host-written text comes back translated when Airbnb has a translation. |
| `include_reviews` | no | `true` also returns guest reviews. Default `false`. |
| `max_reviews` | no | How many reviews to return with `include_reviews`, `1`-`100`. Default `20`. |
| `reviews_sort` | no | `most_relevant` (default), `most_recent`, `highest_rated` or `lowest_rated`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Defaults to `US`. |

### Listing fields

| Field | Notes |
| --- | --- |
| `title` / `subtitle` / `description` | Listing title, Airbnb's one-line summary and the full description (`descriptionLanguage` says which language it is in). |
| `roomType` / `propertyType` / `listingType` | E.g. `Entire home/apt`, `Entire rental unit`; `isLuxe` flags Airbnb Luxe stays. |
| `location` | `address`, `city`, `region`, `country`, `lat` / `lng` (approximate unless `isExact`), and the host's neighborhood and getting-around notes. |
| `host` | `name`, `isSuperhost`, `isVerified`, `yearsHosting`, host `rating` and `reviewsCount`, `responseRate`, `responseTime`, profile highlights and `cohosts`. |
| `rating` | `overall` plus `accuracy`, `cleanliness`, `checkin`, `communication`, `location` and `value` (out of 5). |
| `reviewsCount` / `ratingDistribution` / `reviewTags` | Review count, each star's share of ratings as a 0-1 fraction, and Airbnb's review topics with counts. |
| `isGuestFavorite` / `isNewListing` | Airbnb's Guest favourite and new-listing flags. |
| `guests` / `bedrooms` / `beds` / `bathrooms` / `sleepingArrangements` | Capacity and the bed layout per room. |
| `amenities` | Grouped the way Airbnb groups them: `group` and `items` (`name`, `available`, `subtitle`). |
| `photos` | Gallery: `url`, `caption` and the `room` it shows. |
| `highlights` / `houseRules` / `additionalRules` / `safetyAndProperty` | Listing highlights, house rules, the host's extra rules and safety notes. |
| `checkIn` / `checkOut` | Check-in and checkout times. |
| `cancellationPolicy` | With dates: `summary` and the refund `milestones` with their deadlines. |
| `available` / `unavailableReason` / `canInstantBook` | With dates: whether the stay can be booked, why not if it cannot, and the instant-book flag. |
| `price` | With dates: `total`, `nightly`, `nights`, `currency`, Airbnb's `label`, the `breakdown` lines and any discounted `originalTotal`. |
| `reviews` | With `include_reviews`: `rating`, `text` as written, `translatedText` into `locale`, `language`, `date`, `stayDetail`, the `author` and the host's `response`. |
| `warnings` | Any warnings about the request; empty when there are none. |

## What you can build

- **Rate and availability monitoring** - check a listing's price and availability for your dates on a schedule.
- **Listing quality analysis** - compare category ratings, amenities and house rules across competing stays.
- **Short-term rental research** - enrich search results from [Airbnb Stays](/plugins/airbnb) with capacity, host and policy details.
- **Property data feeds** - build a clean listing record with photos, amenities and coordinates for your own catalog.
