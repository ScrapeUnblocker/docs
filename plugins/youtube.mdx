The **YouTube** plugin turns YouTube into structured JSON through four endpoints:

- **Channel videos** - a channel's latest videos (title, views, likes, comments, publish date, duration, thumbnail) plus the channel's name, handle and subscriber, video and view counts.
- **Search** - results for a query with the video id, title, channel, view count, duration, publish age, thumbnails, a description snippet and badges, filtered by type and sorted.
- **Comments** - a video's comments with author, text, like and reply counts, publish time and the pinned, hearted, verified and uploader flags.
- **Transcript** - a video's captions as timestamped segments and as one joined text, in the language you pick.

Pass channels as a handle (`@mkbhd`), a channel id (`UC...`) or a URL, and videos as an id (`dQw4w9WgXcQ`) or any video URL. No YouTube API key or login is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Channel videos

```
POST /content/youtube-channel
```

| Field | Required | Notes |
| --- | --- | --- |
| `channel` | yes | Channel handle (`@mkbhd`), channel id (`UC...`) or a channel URL. |
| `tab` | no | Which tab: `videos` (default), `shorts` or `streams`. |
| `limit` | no | Max videos to return, `1`-`200`. Default `30`. Honoured on the `videos` tab; other tabs return a single page. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/content/youtube-channel?channel=%40mkbhd&limit=5" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.youtube_channel("@mkbhd", limit=5)
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.youtubeChannel("@mkbhd", { limit: 5 });
```


| Field | Notes |

The `shorts` and `streams` tabs, and the rare call where those details are not available, return the core fields: `videoId`, `title`, `url`, `views`, `published` and `thumbnail`, with the channel's name and id.

## Search

```
POST /content/youtube-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | Search terms. |
| `max_results` | no | How many results to collect across pages (about 20 per page), `1`-`500`. Default `20`. |
| `type` | no | Result type: `video` (default), `channel`, `playlist`, `movie` or `all`. |
| `sort` | no | Ordering: `relevance` (default), `rating`, `date` or `views`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Defaults to `US`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/content/youtube-search?query=python%20tutorial&sort=views&max_results=5" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```


| Field | Required | Notes |
| --- | --- | --- |

| `sort` | no | Comment order: `top` (default) or `newest`. |
| `max_results` | no | How many comments to collect across pages (about 20 per page), `1`-`2000`. Default `20`. |

## Video transcript

```
POST /content/youtube-transcript
```

| Field | Required | Notes |
| --- | --- | --- |
| `video` | yes | Video id (`dQw4w9WgXcQ`) or any YouTube video URL. |
| `lang` | no | Preferred caption language, e.g. `en`. A prefix like `en` matches `en-US`. Omit for the default track. |
| `format` | no | `segments` (default) returns timestamped segments plus the joined text; `text` returns only the joined text. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Defaults to `US`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/content/youtube-transcript?video=dQw4w9WgXcQ&lang=en" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

| Field | Notes |
| --- | --- |
| `segments` | Caption lines with `start` and `dur` in seconds and the `text`. |
| `text` | All segments joined into one plain text, ready for an LLM or a search index. |
| `language` / `languageName` | The caption track that was picked. |
| `isAutoGenerated` | `true` when the track is YouTube's automatic captions. |
| `availableLanguages` | Every caption track on the video: `languageCode`, `name` and `isAutoGenerated`. |
| `title` / `author` / `channelId` / `lengthSeconds` / `viewCount` | Video metadata. Can be `null` when YouTube does not return it with the captions. |

A video without captions returns `404`.

## What you can build

- **Channel monitoring** - track new uploads and their views, likes and comments for the channels you follow.
- **Rank tracking** - record where videos place for your keywords with `sort` and `type`.
- **Audience and sentiment research** - collect top or newest comments and run them through a classifier.
- **LLM and RAG pipelines** - turn videos into searchable, timestamped text with the transcript endpoint.
