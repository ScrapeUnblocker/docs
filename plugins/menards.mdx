The **Menards** plugin returns products from Menards (menards.com, US) as structured JSON. It is two endpoints:

- **`/marketplace/menards-search`** - the products for a keyword: item id, Menards SKU, model number, title, brand, link and image, the shelf price with the everyday low price and the sale flag, Menards' mail-in rebate and the price after it, the unit of measure, pickup and delivery availability with the units in stock at the store, the number of variations and the category, plus the facets (brands, availability, product type) and the store the prices are for. 40 products per page; one call collects up to 120.
- **`/marketplace/menards-product`** - one product: the same price and rebate fields with the sale and rebate end dates, the description, features, specification table, images and breadcrumbs.

No Menards account is involved.

<Warning>
Store prices and stock come only from search with `store_id` or `zip`. Without a store, search returns Menards' default online prices and `stockAtStore` is `0`, and `in_stock_today` needs a store. The product endpoint takes no store: it returns Menards' default online prices (the store in `storeId`), so for one store's price and stock of a product, search for it with `store_id` or `zip`.
</Warning>

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/menards-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `cordless drill`, `garden hose` or `2x4 lumber`. |
| `store_id` | no | Menards store number whose prices and stock to return, e.g. `3181`. Give this or `zip`, not both; with neither, Menards' default online prices are returned and `stockAtStore` is `0`. |
| `zip` | no | US ZIP code; the nearest Menards store is used, e.g. `55401`. |
| `sort` | no | `relevance` (default), `price_low`, `price_high`, `title_asc`, `title_desc`, `brand_asc` or `brand_desc`. |
| `min_price` / `max_price` | no | Price range in USD. |
| `in_stock_today` | no | `true` keeps only items in stock today at the store. Needs `store_id` or `zip`. |
| `delivery_eligible` | no | `true` keeps only items eligible for delivery. |
| `pickup_eligible` | no | `true` keeps only items eligible for in-store pickup. |
| `page` | no | 1-based results page to start from, `1`-`100` (40 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`120`. Default `40`. Each page fetched is billed as one request (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/menards-search?query=space%20heater&zip=55401&sort=price_low&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.menards_search("space heater", zip="55401", sort="price_low", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.menardsSearch("space heater", {
  zip: "55401",
  sort: "price_low",
  maxResults: 3,
});
```

```php PHP

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

```

```ruby Ruby

```
</CodeGroup>

A keyword Menards sends to a category returns that category's products, with the category page in `redirectedTo`. A Menards SKU as `query` returns no products and the product link in `redirectedTo`. A keyword Menards sends to a page of category tiles (for example `interior paint`), or one with no matches, answers `404`.

| Field | Notes |
| --- | --- |
| `store` | The store the prices and stock are for: `storeId`, `name`, `address`, `city`, `state`, `zip` and `distanceMiles` from the ZIP code. |
| `itemId` / `sku` / `url` | Menards' item id, the SKU shown on the product page, and the product link. Pass `url` or `sku` to [Product](#product). |
| `modelNumber` / `title` / `brand` / `image` | Model number (when Menards lists it), title, brand and image. |
| `price` / `regularPrice` / `onSale` | The shelf price before the rebate, the everyday low price, and whether the item is on sale. |
| `rebate` / `rebateLabel` / `priceAfterRebate` | Menards' mail-in rebate (usually 11%), its label and the price after it. |
| `minimumAdvertisedPrice` / `priceInCheckout` | For items whose maker lets Menards show the price only in checkout: `priceInCheckout` is `true` and `priceAfterRebate` is `null`. |
| `unitOfMeasure` / `currency` | The unit the price is for (e.g. `each`) and the currency (`USD`). |
| `availability` | `pickup` and `delivery` flags, `stockAtStore` (units at the store, `0` without one), `stockMessage`, `pickupMessage` and `deliveryMessage`. |
| `variationCount` / `categoryId` | Number of variations and Menards' category id. |
| `queryType` / `redirectedTo` / `category` | How Menards answered the keyword, the page it sent it to, and the category it landed on. |
| `facets` | The filters Menards offers for the result (`name`, `field`, `values` with `value`, `label` and `count`). |
| `totalResults` / `lastPage` / `nextPage` / `hasMore` | Menards' match count and page count; pass `nextPage` as `page` to continue. |

## Product

```
POST /marketplace/menards-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | one of `url` / `sku` | A Menards product link (the `url` of a search result), e.g. `https://www.menards.com/main/.../p-60893668339-c-6455.htm`. |
| `sku` | one of `url` / `sku` | Instead of `url`: the Menards SKU shown on the product page and in search results, e.g. `3646903`. Give one of the two, not both. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, an unknown `sort`, `min_price` above `max_price`, both `store_id` and `zip`, `in_stock_today` without a store, or a product call without (or with both) `url` and `sku`. |
| `404` | No such Menards store (or none near `zip`), no products for the keyword, a keyword Menards sends to a page of category tiles, or no such product. |
| `502` | Menards blocked every attempt, gave no answer or product data, or the call did not finish in time. Retry. |
