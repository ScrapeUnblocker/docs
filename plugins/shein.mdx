The **SHEIN Search** plugin turns a SHEIN (US store) search into structured JSON. Give it a keyword and it returns the products SHEIN shows - each with its goods `id` and `sku`, title, the current price and the list price it is discounted from, the discount, currency, star rating, review count, category, an image, sold-out state, store code and a clean product URL - plus the total result count.

Order by relevance or price and filter by a USD price range. Each call returns SHEIN's first results page, up to 20 products, so `page` must stay `1`. SHEIN limits bursts of searches, so spread large runs over time instead of sending thousands at once.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/shein-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `summer dress` or `phone case`. |
| `sort` | no | `relevance` (default), `price_low` or `price_high`. The order is SHEIN's: a price sort can carry a product or two out of order, as it does on the site. |
| `min_price` / `max_price` | no | Price range in USD (whole dollars). SHEIN's own filter lets some products through on another price, so we enforce it again on `price`: every product returned is inside the range. |
| `max_results` | no | How many products to return. Default `20`, which is also the most a call returns (SHEIN's first results page). |
| `page` | no | Must be `1`: SHEIN does not serve deeper results pages. |
| `proxy_country` | no | Proxy country (ISO-2). Optional. |

| Field | Notes |
| --- | --- |
| `id` | SHEIN goods id, the number at the end of the product URL (`-p-<id>.html`). |
| `sku` | SHEIN's SKU code for the product. |
| `title` / `url` | Product title and a clean product URL. |
| `price` / `currency` | Current price and ISO currency (USD). |
| `originalPrice` / `discountPercent` | The list price the product is discounted from and the discount in percent. |
| `rating` / `reviewCount` | Star rating (out of 5) and number of reviews. `rating` is `null` for a product with no reviews. SHEIN's search gives exact counts up to 1,000; above that `reviewCount` is `1001` and `reviewCountText` is `"1000+"`. |
| `reviewCountText` | The review count as SHEIN shows it (`"100+"`, `"1000+"`), `null` for a product with few reviews. |
| `category` / `categoryId` | SHEIN's category name and id for the product. |
| `image` | Product image URL. |
| `soldOut` | `true` when the product is sold out. |
| `storeCode` | Code of the SHEIN store (seller) that lists the product. |

## What you can build

- **Fast-fashion price tracking** - follow prices and discounts for a keyword over time.
- **Trend research** - see which styles and categories SHEIN ranks for a search, with review counts as a demand signal.
- **Competitor monitoring** - compare SHEIN prices with your own catalog for the same product types.
- **Stock watch** - flag products that go `soldOut`.
