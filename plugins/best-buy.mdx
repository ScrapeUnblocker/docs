The **Best Buy Search** plugin turns a Best Buy (US) search into structured JSON. Give it a keyword and it returns the products Best Buy shows - each with its `sku`, title, brand, model number, current price and the regular price it is discounted from, currency, star rating, review count, an image and a clean product URL - plus Best Buy's `totalResults`.

Sort by relevance, best selling, price, rating, newest or discount, filter by a USD price range, and collect up to `max_results` products across pages (48 per page) starting from any `page`.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/bestbuy-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `laptop` or `noise cancelling headphones`. |
| `sort` | no | `relevance` (default), `best_selling`, `price_low`, `price_high`, `rating`, `newest` or `discount`. |
| `min_price` / `max_price` | no | Price range in USD (whole dollars). |
| `max_results` | no | How many products to collect across pages. Default `24`, max `500`. |
| `page` | no | 1-based results page to start from (48 per page, up to 40). Default `1`. |
| `proxy_country` | no | Proxy country (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/bestbuy-search?query=laptop&sort=price_low&max_results=48" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

| Field | Notes |
| --- | --- |
| `sku` | Best Buy's product id, also the last segment of the product URL. |
| `title` / `brand` / `model` | Product title, brand and model number. |
| `price` / `currency` | Current price and ISO currency (USD). |
| `originalPrice` | The regular price, present only when the product is on sale. |
| `rating` / `reviewCount` | Star rating (out of 5) and number of reviews. A product with no reviews has `rating` `0.0` and `reviewCount` `0`. |
| `image` / `url` | Product image and a clean product URL. |

A field with no value is left out of that product (for example `model` or `originalPrice`).

## What you can build

- **Price monitoring** - track `price` and `originalPrice` for a SKU to catch sales and price drops.
- **Assortment research** - pull every laptop, TV or headphone in a category with brand and model.
- **Repricing and MAP checks** - compare Best Buy prices against your own listings by model number.
- **Deal feeds** - sort by `discount` to build a live list of the biggest markdowns.
