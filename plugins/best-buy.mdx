The **Best Buy** plugin returns Best Buy (US) data as structured JSON. It is two endpoints:

- **`/marketplace/bestbuy-search`** - give it a keyword and it returns the products Best Buy shows, each with its `sku`, title, brand, model number, current price and the regular price it is discounted from, currency, star rating, review count, an image and a clean product URL, plus Best Buy's `totalResults`.
- **`/marketplace/bestbuy-product`** - one product by `sku` (from a search) or link: price and savings, shipping, pickup and delivery availability, rating, description, features, what is in the box, every specification, full-size images, categories, the seller, open-box offers and dimensions. See [Product](#product).

Sort by relevance, best selling, price, rating, newest or discount, filter by a USD price range, and collect up to `max_results` products across pages (48 per page) starting from any `page`.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/bestbuy-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `laptop` or `noise cancelling headphones`. |
| `sort` | no | `relevance` (default), `best_selling`, `price_low`, `price_high`, `rating`, `newest` or `discount`. |
| `min_price` / `max_price` | no | Price range in USD (whole dollars). |
| `max_results` | no | How many products to collect across pages. Default `24`, max `500`. |
| `page` | no | 1-based results page to start from (48 per page, up to 40). Default `1`. |
| `proxy_country` | no | Proxy country (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/bestbuy-search?query=laptop&sort=price_low&max_results=48" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.bestbuy_search("laptop", sort="price_low", max_results=48)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.bestbuySearch("laptop", { sort: "price_low", maxResults: 48 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->bestbuySearch('laptop', ['sort' => 'price_low', 'max_results' => 48]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.bestbuy_search("laptop", sort: "price_low", max_results: 48)
```

| Field | Notes |
| --- | --- |
| `sku` | Best Buy's product id, also the last segment of the product URL. |
| `title` / `brand` / `model` | Product title, brand and model number. |
| `price` / `currency` | Current price and ISO currency (USD). |
| `originalPrice` | The regular price, present only when the product is on sale. |
| `rating` / `reviewCount` | Star rating (out of 5) and number of reviews. A product with no reviews has `rating` `0.0` and `reviewCount` `0`. |
| `image` / `url` | Product image and a clean product URL. |

A field with no value is left out of that product (for example `model` or `originalPrice`).

## Product

```
POST /marketplace/bestbuy-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `sku` | one of `sku` / `url` | Best Buy SKU, e.g. `6613868` (the number after `/sku/` in a product link, or its `skuId=`; the `sku` of a search result). |
| `url` | one of `sku` / `url` | Instead of `sku`: a bestbuy.com product link, e.g. `https://www.bestbuy.com/product/hp-omnibook-x-flip/JJGQJRKGTJ/sku/6613868` or `https://www.bestbuy.com/site/-/6613868.p?skuId=6613868`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/bestbuy-product?sku=6613868" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.bestbuy_product("6613868")
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```



</CodeGroup>

To look a product up by link, leave the first argument out and pass `url` (`su.bestbuy_product(url="https://www.bestbuy.com/...")` in Python, `su.bestbuyProduct(undefined, { url })` in Node.js). Give `sku` or `url`, not both. Each product is billed as one request.

| Field | Notes |
| --- | --- |
| `sku` / `title` / `brand` / `model` / `upc` / `productType` / `condition` / `url` | The product. |
| `price` / `originalPrice` / `savings` / `savingsPercent` / `currency` | Price in USD, and the regular price and saving when it is on sale. |
| `available` / `availableForShipping` / `availableForPickup` / `availableForDelivery` | Whether Best Buy sells it now and how it can be had, nationwide (not for one store or ZIP code). |
| `rating` / `reviewCount` | Star rating and review count. |
| `description` / `features` / `includedItems` | The description, each feature (`title`, `description`) and what is in the box. |
| `specifications` | Every specification as `group` / `name` / `value`. |
| `image` / `images` | The main image and every image, full size. |
| `category` / `categories` | The leaf category and the path from the root. |
| `seller` | Best Buy (`id: "bby"`) or a Marketplace seller id. |
| `openBoxOffers` | Open-box offers (`Excellent`, `Good`, `Fair`) with their prices and links. |
| `dimensions` / `releaseDate` | Height, width, depth and weight, and the release date when Best Buy gives one. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters: a missing `query` (search), or a missing or invalid `sku` / `url`, or both given (product). |
| `404` | Product: Best Buy has no product with this SKU. |
| `502` | Best Buy blocked every attempt, returned no data, or the call did not finish in time. Retry. |

## What you can build

- **Price monitoring** - track `price` and `originalPrice` for a SKU to catch sales and price drops.
- **Assortment research** - pull every laptop, TV or headphone in a category with brand and model.
- **Repricing and MAP checks** - compare Best Buy prices against your own listings by model number.
- **Deal feeds** - sort by `discount` to build a live list of the biggest markdowns.
- **Open-box tracking** - watch `openBoxOffers` for a SKU to catch cheaper open-box stock.
