The **Tripadvisor Places** plugin turns a Tripadvisor list page - the Restaurants, Hotels or Attractions of a city or area - into structured JSON. Give it the list URL and it returns each place with its name, type, rating, review count, price range, cuisine, phone, address, country, coordinates, an image and a direct link to the place's review page.

It pages through the list for you (about 30 places per page) up to `max_results`, so one call can collect a whole city's top restaurants. Pass any place link it returns to [Tripadvisor Reviews](/plugins/tripadvisor-reviews) to read that place's reviews.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Place list

```
POST /travel/tripadvisor
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | yes | Tripadvisor list URL (Restaurants, Hotels or Attractions), e.g. `https://www.tripadvisor.com/Restaurants-g60763-New_York_City_New_York.html`. |
| `max_results` | no | How many places to collect across pages (about 30 per page), `1`-`1020`. Default `30`. Large values take longer. |
| `page` | no | 1-based results page to start from, `1`-`34`. Default `1`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Leave blank to let the API pick. |

### Place fields

| Field | Notes |
| --- | --- |
| `name` / `type` | Place name and its type (e.g. `Restaurant`, `Hotel`). |
| `url` | The place's Tripadvisor review page. Pass it to [Tripadvisor Reviews](/plugins/tripadvisor-reviews). |
| `image` | Main photo URL. |
| `rating` / `reviewCount` | Average rating (out of 5) and number of reviews. |
| `priceRange` | Tripadvisor's price range, e.g. `$` or `$$ - $$$`. |
| `cuisine` | Cuisines, for restaurants. |
| `phone` / `address` / `postalCode` / `country` | Contact details and location. |
| `coordinates` | `lat` / `lng`. |

The top-level `category` says which kind of list was read (`restaurants`, `hotels` or `attractions`). A field Tripadvisor does not publish for a place comes back `null` or is left out.

## What you can build

- **Local market research** - list every restaurant in a city with cuisine, price range and rating.
- **Lead lists for hospitality** - collect names, phones, addresses and coordinates of hotels or attractions in an area.
- **Ranking monitoring** - track how places move in a city's list and how their review counts grow.
- **Review pipelines** - feed each place `url` into [Tripadvisor Reviews](/plugins/tripadvisor-reviews) to read its reviews.
