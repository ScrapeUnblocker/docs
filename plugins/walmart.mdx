The **Walmart** plugin returns Walmart (US) data as structured JSON. It is two endpoints:

- **`/marketplace/walmart-search`** - the products Walmart shows for a keyword, each with title, price and was-price, star rating and review count, brand, seller, availability, image and a clean product URL. Sort, filter by price and page through to `max_results`.
- **`/marketplace/walmart-product`** - one product page in full: price, was-price and list price, Rollback and Clearance flags, stock, the seller and how many others sell it, shipping, pickup and delivery, the return policy, the rating with its star histogram and aspect scores, the first reviews, description, specifications, every variant, images and videos. See [Product](#product).

It runs on the same fetch chain that serves `getPageSource`. Walmart sits behind PerimeterX and blocks traffic from outside the US, so the plugin renders the search from the US and reads the products from Walmart's own `__NEXT_DATA__` island - no Walmart developer account needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Endpoint

```
POST /marketplace/walmart-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `laptop` or `coffee maker`. |
| `sort` | no | `best_match` (default), `price_low`, `price_high`, `best_seller`, `rating_high` or `new`. |
| `min_price` / `max_price` | no | Price range in USD. |
| `page` | no | 1-based page to start from (~40 products per page). Default `1`. |
| `max_results` | no | How many products to collect across pages. Default `40`, max `1000`. |
| `proxy_country` | no | Proxy country (ISO-2). Defaults to US (required by Walmart). |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/walmart-search?query=laptop&sort=price_low&max_results=60" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.walmart_search("laptop", sort="price_low", max_results=60)
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

  maxResults: 60,
});
```



</CodeGroup>

A keyword Walmart sends to a category landing page with no product grid (e.g. `baby` or `pharmacy`) answers `404`, and the message names the landing page URL. Search for something more specific, such as a product type or brand.

### Product fields

| Field | Notes |
| --- | --- |
| `price` / `wasPrice` | Current price and the struck-through original, as numbers. `wasPrice` is `null` when there is no markdown. |
| `currency` | ISO currency (USD). |
| `rating` / `reviewCount` | Star rating and number of reviews, when the tile shows them. |
| `brand` | Product brand. `null` on search tiles that do not carry it. |
| `seller` | `Walmart.com` or a marketplace seller name. |
| `availability` | Stock state as Walmart words it. |
| `url` | Clean `/ip/` product URL. |

<Note>
Any field with no value is omitted from a product, so each item carries only the fields Walmart's search tile actually showed (e.g. `wasPrice` or `brand` may be absent).
</Note>

## Product

```
POST /marketplace/walmart-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `item_id` | one of `item_id` / `url` | Walmart item id, the number at the end of a product link, e.g. `18638703162` for `walmart.com/ip/.../18638703162`. |
| `url` | one of `item_id` / `url` | Instead of `item_id`: a walmart.com product link, e.g. `https://www.walmart.com/ip/HP-15-6-inch-Laptop/18638703162`. |
| `proxy_country` | no | Country the request is made from (ISO-2). Default `US`: walmart.com refuses most other countries, so leave it unset. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/walmart-product?item_id=18638703162" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

result = su.walmart_product(item_id="18638703162")
```

```ts Node.js

```


| Field | Notes |
| --- | --- |
| `itemId` / `productId` / `url` | Walmart's item id (the number in the link), its catalog product id and the product link. |
| `title` / `brand` / `model` / `upc` / `manufacturerPartNumber` | Product identity, as the page shows it. |
| `price` / `wasPrice` / `listPrice` / `savings` | Current price, the struck-through price and list price, and the saving. `priceText` is the price line as Walmart words it. |
| `unitPrice` / `unitPriceText` | Price per unit (e.g. per ounce), where Walmart shows one. |
| `rollback` / `clearance` | Walmart's Rollback and Clearance flags. |
| `availability` / `inStock` / `orderLimit` | Stock state, a boolean, and the most one order may hold. |
| `seller` | `name`, `type` (`walmart` or a marketplace seller), `rating`, `reviewCount` and `fulfilledByWalmart`. |
| `additionalSellerCount` | How many other sellers offer the item. Their offers are not on the product page, so only the count is returned. |
| `fulfillment` | One entry per way to get it (`shipping`, `pickup`, `delivery`): `available`, `status`, `date`, `price`, `location` and Walmart's `message`. |
| `location` | The US location Walmart assigned to the request, which the fulfillment dates and store are quoted for. It is not a ZIP code or store you choose. |
| `returnPolicy` | Whether it is returnable, free returns, the return window in days and Walmart's text. |
| `rating` / `reviewCount` / `reviewSummary` | Star rating and count, plus the star histogram, the recommend percentage and aspect scores. |
| `reviews` | The first reviews on the page: `rating`, `title`, `text`, `date`, `author` (as Walmart shows it), `helpfulVotes` and the `seller` it was bought from. |
| `categories` / `shortDescription` / `description` / `highlights` / `specifications` / `warranty` / `warnings` | Category path and the product page text and specs. |
| `variantOptions` / `variants` | The variant menus (colour, size) and every variant with its own `itemId`, `attributes`, `price`, `wasPrice`, stock, link and image. |
| `images` / `videos` | Image and video links. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters: a missing `query` (search), or a missing or invalid `item_id` / `url`, or both given (product). |
| `404` | Search: Walmart sends the keyword to a category landing page with no product grid (the message names it). Product: no such Walmart item (Walmart shows its not-found page). |
| `502` | Walmart blocked every attempt, returned no data, or the call did not finish in time. Retry. |

## What you can build

- **Price monitoring and repricing** - track price and `wasPrice` for a product over time.
- **Catalog and assortment research** - pull a whole category with brands and sellers.
- **Review-volume signals** - `rating` and `reviewCount` show what is actually selling.
- **Competitor tracking** - compare the same keyword against your own listings.
- **Product detail feeds** - pull specifications, variants and fulfillment for the items a search returns, by their `id`.
