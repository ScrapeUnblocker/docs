The **Bodega Aurrera** plugin returns grocery and household products from Bodega Aurrera (bodegaaurrera.com.mx), Walmart de Mexico's discount chain, as structured JSON. It is two endpoints:

- **`/groceries/bodegaaurrera-search`** - the products for a keyword: product id, name, brand, link and image, the price, the was-price and saving while a promotion runs, unit price and price range, rating and review count, availability, the seller, the sales unit, department and category path, badges, the pickup and delivery labels and the sponsored flag. About 44 products per page; one call collects up to 220.
- **`/groceries/bodegaaurrera-product`** - one product: the search fields plus UPC, model, installments, order limit and minimum, the rating breakdown, product type, short and long description, ingredients, specifications, fulfilment options, the store the price is for and the image gallery.

Prices are in Mexican pesos (MXN) and belong to the store the storefront assigns a new visitor, named in `storeId` (search) and `store` (product); a store or postal code cannot be chosen. A keyword the site sends to a category page still returns that category's products. No Bodega Aurrera account is involved.

## Search

```
POST /groceries/bodegaaurrera-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search, e.g. `leche`, `arroz`, `detergente` or `pañales`. |
| `url` | one of `query` / `url` | Instead of `query`: a Bodega Aurrera search link, e.g. `https://www.bodegaaurrera.com.mx/search?q=leche` (its sort and page are used). |
| `sort` | no | `relevance`, `price_low` or `price_high`. Default `relevance`. |
| `page` | no | 1-based results page to start from, `1`-`25`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`220`. Default `44` (about one page). Each page read is billed as one request (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/groceries/bodegaaurrera-search?query=leche&sort=price_low&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.bodegaaurrera_search("leche", sort="price_low", max_results=3)
```


| Field | Notes |
| --- | --- |
| `productId` / `url` | Bodega Aurrera item id and link. Pass the id as `product_id` to [Product](#product). |
| `name` / `brand` / `image` | Name, brand and image. |
| `price` / `currency` | The price in MXN at the assigned store. |
| `wasPrice` / `savings` | The previous price and the saving, only while a promotion runs. |
| `unitPrice` / `priceRange` | Price per unit and the price range of a product with options, when the site shows them. |
| `rating` / `reviewCount` | Rating and number of reviews (`null` and `0` for an unrated product). |
| `availability` / `availabilityText` / `inStock` | Stock status code, its text as the site prints it, and a boolean. |
| `seller` / `sellerType` | Who sells it (`INTERNAL` for Bodega Aurrera itself, otherwise a marketplace seller). |
| `salesUnit` | `EACH` or a weight unit for items sold by weight. |
| `department` / `category` | Department and full category path. |
| `badges` / `fulfillment` | Badges such as `MSI` (interest-free months) and the pickup and delivery labels. |
| `sponsored` / `position` | Paid placement flag and rank in the results. |
| `storeId` | The store the prices and stock are for. |
| `correctedQuery` | The query the site searched instead, when it corrected the spelling. |
| `totalResults` / `nextPage` / `hasMore` | The site's result count; pass `nextPage` as `page` to continue. |

## Product

```
POST /groceries/bodegaaurrera-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | Bodega Aurrera item id, e.g. `00750649502153` (the number at the end of an `/ip/` link; search results give it as `productId`). |

| Field | Notes |
| --- | --- |
| `upc` / `model` | Barcode and model number, when the site lists them. |
| `installments` | The interest-free installment offer, as text. |
| `orderLimit` / `orderMinimum` | How many units one order may hold, and the minimum. |

| `images` | The image gallery. |

The other fields are the same as in search.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `query` nor `url`, both `product_id` and `url`, or `page` above `25`. |
| `404` | No products for this search, a keyword the site sends to a promotional landing page with no product list (use a more specific query, such as a brand or product type), or (product) no such product. |
| `502` | The site's bot check refused every attempt, no page came back, or the call did not finish in time. Retry. |
