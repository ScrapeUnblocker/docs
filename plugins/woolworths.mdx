The **Woolworths** plugin returns Woolworths Australia (woolworths.com.au) grocery data as structured JSON. One endpoint covers four methods: **search** by keyword, list a **category**, list a **specials** page (Half Price by default), or fetch one **product** in full with its ingredients, allergens and nutrition panel.

Every product carries its stockcode, name, brand, size, barcode and link, the price with any was-price and saving, the promotion (half price, special, multibuy or offer), the unit price, stock and purchase limit, the health star rating and its categories. Prices are Woolworths' online prices in AUD. Listings return 36 products per page; `max_results` collects up to 360 across pages, and each page fetched is one billed unit (`pagesFetched`).

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

Products matching a keyword.

```
POST /groceries/woolworths
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `woolworthsSearch`. In a raw request `search` is the default. |
| `query` | yes | What to search for, e.g. `milk`, `tim tam` or `chicken breast`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `unit_price_asc`, `unit_price_desc` or `name`. |
| `specials_only` | no | `true` keeps only products on special. Default `false`. |
| `page` | no | 1-based listing page to start from (36 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`360`. Default `36`. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). Woolworths answers every country, so leave it blank unless you need one. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/groceries/woolworths?mode=search&query=milk&sort=unit_price_asc&max_results=36" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.woolworths_search("milk", sort="unit_price_asc", max_results=36)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.woolworthsSearch("milk", { sort: "unit_price_asc", maxResults: 36 });
```

```php PHP

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->woolworthsSearch('milk', ['sort' => 'unit_price_asc', 'max_results' => 36]);
```

The search, category and specials methods return the same product objects:

| Field | Notes |
| --- | --- |
| `id` | Woolworths stockcode. Pass it to [Product](#product). |
| `name` / `brand` / `size` | Product name, brand and pack size as Woolworths shows them. |
| `url` / `barcode` | Product page link and the EAN barcode. |
| `price` / `wasPrice` / `savings` | Current price, the struck-through price and the saving, in AUD. `wasPrice` and `savings` are `null` when the product is not on special. |
| `onSale` / `promotion` | Whether the product is on special, and the deal: `type` (`half_price`, `special`, `multibuy` or `offer`) and `text`; multibuy deals add `quantity` and `price`. |
| `unitPrice` | Price per unit: `price`, `per` (e.g. `1L`, `100G`) and the label `text`. |
| `soldBy` / `inStock` / `available` / `purchaseLimit` | How it is sold, stock and availability flags, and the maximum per order. |
| `isNew` / `onlineOnly` / `sponsored` | Woolworths' flags. Sponsored products are placed by Woolworths and can repeat across pages; repeats are dropped. |
| `image` / `categories` | Product image URL and the categories it belongs to. |
| `healthStarRating` / `rating` | Health Star Rating (out of 5) and the shopper rating, `null` when Woolworths shows none. |

`totalResults`, `totalPages` and `nextPage` page through the rest; pass `nextPage` as `page` to continue. `suggestedTerm` carries Woolworths' spelling suggestion when it has one.

<Note>
Woolworths shows tobacco products only to signed-in shoppers. A tobacco search returns `200` with no products and an entry in `warnings` explaining why.
</Note>

## Category

One category listing, such as Milk or Bakery.

```
POST /groceries/woolworths
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `category` by `woolworthsCategory`. In a raw request it is implied when `category` is given. |
| `category` | yes | A browse link (`https://www.woolworths.com.au/shop/browse/dairy-eggs-fridge/milk`), its path (`dairy-eggs-fridge/milk`) or a category id (`1_6E4F4E4`). |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `unit_price_asc`, `unit_price_desc` or `name`. |
| `page` | no | 1-based listing page to start from (36 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`360`. Default `36`. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). Leave blank unless you need one. |

## Specials


| --- | --- | --- |

| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `unit_price_asc`, `unit_price_desc` or `name`. |
| `page` | no | 1-based listing page to start from (36 products per page). Default `1`. |

## Product

One product in full, with ingredients, allergens and the nutrition panel.

```
POST /groceries/woolworths
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `product` by `woolworthsProduct`. In a raw request it is implied when `product` is given. |
| `product` | yes | A stockcode (`888137`) or a product link (`https://www.woolworths.com.au/shop/productdetails/888137/woolworths-full-cream-milk`). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). Leave blank unless you need one. |

`product` carries every field listed under [Search](#search), plus:

| Field | Notes |
| --- | --- |
| `description` / `ingredients` | Product description and the ingredient list as printed. |
| `allergens` | `contains`, `mayContain` and `freeFrom` lists. |
| `dietary` | Dietary and nutrition claims, e.g. `Gluten Free`. |
| `nutrition` | Nutrition panel rows: `name`, `perServing` and `per100` (per 100 g or mL). |

| `department` / `aisle` | Where Woolworths files the product. |
| `images` / `variants` | All product images, and other sizes or versions of the product. |

## What you can build

- **Grocery price monitoring** - track `price`, `wasPrice` and `unitPrice` for a basket of stockcodes over time.
- **Specials and promotion tracking** - pull the Half Price and multibuy pages each week and see what goes on deal.
- **Cross-retailer comparison** - compare unit prices against [Coles](/plugins/coles) and [ALDI Australia](/plugins/aldi-au).
- **Nutrition and allergen databases** - build a product catalog keyed by barcode with ingredients, allergens and the nutrition panel.
