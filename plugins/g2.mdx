The **G2** plugin turns G2 product reviews into structured JSON. Give it a product slug such as `slack` (or a g2.com product URL) and it returns the product summary - rating, review count, star distribution, categories, G2's AI summary, the most cited pros and cons, and review counts by company size, industry and region - plus the reviews themselves: title, rating, date, the reviewer's job title and company size, what they like and dislike, the full questionnaire answers, the validation and incentive badges and any vendor response.

The plugin also searches G2's product catalog by keyword, which is the quickest way to find a product's slug.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Product reviews

```
POST /reviews/g2
```

| Field | Required | Notes |
| --- | --- | --- |
| `product` | yes | G2 product slug, e.g. `slack` or `hubspot-sales-hub`, or a g2.com product URL such as `https://www.g2.com/products/slack/reviews`. |
| `mode` | - | Set to `reviews` by `g2Reviews`. |
| `page` | no | 1-based page to start from: 10 reviews per page, at most 10 pages per sort and filter view. Pass the `nextPage` of a previous response to continue. Default `1`. |
| `max_results` | no | How many reviews to collect across pages, `1`-`100`. Default `10`. Each page fetched is one billed unit. |
| `sort` | no | `g2_default` (default, G2's own ranking), `most_recent`, `most_helpful`, `highest_rated` or `lowest_rated`. |
| `stars` | no | Only reviews with this star rating (`1`-`5`). |
| `search` | no | Only reviews whose answers mention this keyword. |
| `details` | no | `true` also fetches the product page for `vendor`, `description`, `website` and `languages` (one more billed unit). Default `false`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank for the country chosen for the site. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/reviews/g2?mode=reviews&product=slack&sort=most_recent&max_results=10" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.g2_reviews("slack", sort="most_recent", max_results=10)
```


`vendor`, `website`, `description`, `languages` and `image` on the product are filled in when you pass `details=true`. `hasMore` and `nextPage` tell you where to continue; `viewLimitReached` is `true` once you hit G2's 10-page limit for the current sort and filter view (switch `sort`, `stars` or `search` to reach other reviews). An unknown slug returns `404`.

### Review fields

| Field | Notes |
| --- | --- |
| `id` / `url` | G2's review id and a link to the review. |
| `title` / `rating` / `date` | Review headline, star rating (out of 5) and publish date (`updatedDate` when edited). |
| `reviewer` | `name` (as G2 shows it, e.g. first name and initial), `anonymous`, job `title`, `industry` and `companySize`. |
| `likeBest` / `dislike` / `problemsSolved` | The answers to G2's three main questions. `recommendations` holds the reviewer's recommendations to others, when given. |
| `answers` | Every question and answer of the review, in order. `text` joins them. |
| `validatedReviewer` / `validationMethod` | Whether and how G2 validated the reviewer. |
| `currentUser` / `incentivized` / `source` | G2's badges: current user, incentivized review and the review source (e.g. `Organic`). `badges` lists them as G2 prints them. |
| `aiTranslated` / `translatedFrom` | Set when G2 machine-translated the review. |
| `vendorResponse` | The vendor's reply, or `null`. |

## Product search

```
POST /reviews/g2
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | Keyword to search G2's product catalog for, e.g. `crm` or `project management`. |
| `mode` | - | Set to `search` by `g2Search`. |
| `page` | no | 1-based page to start from: 20 products per page, at most 20 pages. Default `1`. |
| `max_results` | no | How many products to return, `1`-`100`. Default `20`. Search answers whole pages of 20, so it can return a few more. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank for the country chosen for the site. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/reviews/g2?mode=search&query=project%20management&max_results=20" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python

```

## What you can build

- **Competitor review tracking** - pull the newest reviews of your product and its rivals with `sort=most_recent`.
- **Win/loss and feature research** - mine `likeBest`, `dislike` and the top `pros` and `cons` for recurring themes.
- **Segment analysis** - compare ratings by reviewer company size and industry.
- **Market maps** - search a category keyword to list products with their rating and review count.
