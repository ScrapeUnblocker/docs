The **Trustpilot** plugin turns a company's Trustpilot page into structured JSON. Give it the company's domain, such as `www.nike.com`, and it returns a `company` summary (TrustScore, total reviews, the 1-5 star distribution, categories and contact) plus a `reviews` array, each review with its rating, title, text, author, verified badge, language, dates and the company's reply.

Reviews come 20 to a page. Start at any `page`, fetch up to 20 consecutive pages in one call with `pages`, and narrow the list with `stars`, `sort`, `language`, `date`, `search`, `verified` or `replies`. No Trustpilot account or login is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Company reviews

```
POST /reviews/trustpilot
```

| Field | Required | Notes |
| --- | --- | --- |
| `company` | yes | The reviewed company's domain, e.g. `www.nike.com` or `nike.com`. A full site URL or a Trustpilot review URL also works. |
| `page` | no | 1-based page to start from, 20 reviews per page. Default `1`. |
| `pages` | no | How many consecutive pages to fetch from `page` onward, `1`-`20`. Default `1`. Stops early at the last page. |
| `stars` | no | Only reviews with these star ratings (`1`-`5`). Repeat the key for several, e.g. `stars=4&stars=5`; in the SDKs pass a list. |
| `sort` | no | `recency` (default, newest first) or `relevancy`. |
| `language` | no | Review language as an ISO-2 code (`en`, `de`) or `all` (default). |
| `date` | no | Only reviews from a recent window: `last30days`, `last3months`, `last6months` or `last12months`. Omit for all time. |
| `search` | no | Keyword to search for within the company's reviews. |
| `verified` | no | `true` returns only reviews with Trustpilot's verified badge. Default `false`. |
| `replies` | no | `true` returns only reviews the company replied to. Default `false`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Defaults to a country chosen for the site. |

The `company` object carries `trustScore`, `totalReviews`, `reviewsLast12Months`, the `ratingDistribution` (count per star, plus `total`), `categories`, `contact` and the `profileUrl`. `totalFilteredReviews` and `pagination` count the reviews that match your filters; `query` echoes the filters that were applied.

### Review fields

| Field | Notes |
| --- | --- |
| `id` | Trustpilot's review id. |
| `title` / `text` | Review headline and body. |
| `rating` | Star rating, `1`-`5`. |
| `author` | `name`, `country` (ISO-2), `reviewCount` (reviews the author has written) and `verified`. |
| `date` / `experiencedDate` | When the review was posted and the date of the experience it describes (ISO-8601). |
| `verified` / `verificationLevel` | Trustpilot's verified badge and its level, e.g. `not-verified`. |
| `likes` | Useful votes on the review. |
| `language` | Language code of the review. |
| `reply` | The company's reply as `text` and `date`, or `null` when the company has not replied. |

## What you can build

- **Review monitoring** - pull new reviews with `sort=recency` or `date=last30days` and alert on low ratings.
- **Reputation dashboards** - track `trustScore`, `totalReviews` and the star distribution over time.
- **Support quality tracking** - use `replies=true` to see which reviews a company answers and how.
- **Sentiment and topic analysis** - feed review `text` into a classifier, filtered by `language` or `search`.
