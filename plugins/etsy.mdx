The **Etsy** plugin returns Etsy listings as structured JSON. It is two endpoints:

- **`/marketplace/etsy-search`** - the listings Etsy shows for a keyword, each with title, price, shop name, image and a clean listing URL. Sort, filter by price and page through to `max_results`.
- **`/marketplace/etsy-product`** - one listing in full: price and price range, sale details, stock, rating with the review summary, the first reviews, the shop's profile, every variation with its price, description, materials, category, shipping, images and video. See [Product](#product).

It runs on the same fetch chain that serves `getPageSource`, and reads the cards straight from Etsy's server-rendered HTML - no Etsy API key or OAuth app needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Endpoint

```
POST /marketplace/etsy-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `handmade jewelry`. |
| `sort` | no | `relevancy` (default), `price_asc`, `price_desc`, `newest` or `top_reviews`. |
| `min_price` / `max_price` | no | Price range. |
| `page` | no | 1-based page to start from (~48 per page). Default `1`. |
| `max_results` | no | How many products to collect across pages. Default `48`, max `500`. |
| `proxy_country` | no | Proxy country (ISO-2). Defaults to US (USD prices). |
| `include_sponsored` | no | `true` to also return Etsy's paid ad placements. Default `false`: ads are left out, since Etsy mixes them into every page regardless of the search order and `sort`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/etsy-search?query=handmade%20necklace&sort=top_reviews&max_results=96" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.etsy_search("handmade necklace", sort="top_reviews", max_results=96)
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

  maxResults: 96,
});
```


## Response

```json
{
  "query": "handmade necklace",
  "resultsCollected": 96,
  "products": [
    {
      "id": "1502837465",
      "title": "Personalized Name Necklace, Custom Gold Jewelry",
      "url": "https://www.etsy.com/listing/1502837465",
      "price": 28.5,
      "currency": "USD",
      "currencySymbol": "$",
      "shop": "GoldenLeafStudio",
      "image": "https://i.etsystatic.com/....jpg",
      "sponsored": false
    }
  ]
}
```

### Product fields

| Field | Notes |
| --- | --- |
| `price` | Numeric price. |
| `currency` | ISO currency code of the price (e.g. `USD`, `EUR`). Follows `proxy_country` (USD by default). |
| `currencySymbol` | The currency symbol as Etsy shows it (e.g. `$`, `€`). |
| `sponsored` | `true` for Etsy's promoted listings (ads), `false` for organic results. Ads come back only with `include_sponsored=true`, in the order Etsy shows them, and do not follow `sort`. |
| `shop` | The Etsy shop selling the item. On a sponsored card it may carry Etsy's own promoted-listing prefix (e.g. `Ad ・ By ...`). |
| `image` | Listing thumbnail URL. |
| `url` | Clean `/listing/` URL. |

<Note>
Any field with no value is omitted from a product. Prices come back in the proxy country's currency, so the plugin defaults to US - pass `proxy_country` to price in another market.
</Note>

## Product

```
POST /marketplace/etsy-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `listing_id` | one of `listing_id` / `url` | Etsy listing number, e.g. `1702915637` (the number in `etsy.com/listing/1702915637/...`). |
| `url` | one of `listing_id` / `url` | Instead of `listing_id`: an etsy.com listing link, e.g. `https://www.etsy.com/listing/1702915637/solstice-mug`. |
| `proxy_country` | no | Country the request is made from (ISO-2). Default `US`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/etsy-product?listing_id=1702915637" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.etsy_product(listing_id="1702915637")
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.etsyProduct({ listingId: "1702915637" });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->etsyProduct(['listing_id' => '1702915637']);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.etsy_product(listing_id: "1702915637")
```

</CodeGroup>

Each listing is billed as one request.

<Note>
Etsy prices a listing, its shipping cost and VAT for the shopper location it assigns to the request, and that location can differ from `proxy_country`. `currency` and `shopperRegion` say which one a response used (e.g. `EUR` / `BE`), so read them before comparing prices across calls.
</Note>

| Field | Notes |

| `listingId` / `url` / `title` | The listing. |

| `variations` | Each variation menu with its options, their `price` / `priceMax` and availability. |
| `description` / `materials` / `highlights` / `category` / `categories` | The listing text and its category path. |
| `shipping` | Cost and currency (`null` with `costText` when Etsy shows no fixed cost), origin, ships from, destination, estimated delivery, processing time and returns. |
| `images` / `video` | Image links and the listing video, when there is one. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters: a missing `query` (search), or a missing or invalid `listing_id` / `url` (product). |
| `404` | Product: no such Etsy listing, or it is no longer available. |
| `502` | Etsy blocked every attempt, returned no data, or the call did not finish in time. Retry. |

## What you can build

- **Price and assortment research** - pull a whole niche with shops and prices.
- **Trend spotting** - `sort=newest` surfaces what sellers are listing now.
- **Shop monitoring** - track a category's price distribution over time.
- **Sourcing** - find makers and compare pricing across shops.
- **Shop and listing research** - read sales counts, Star Seller status and review scores for the listings a search returns.
