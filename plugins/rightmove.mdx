The **Rightmove** plugin turns a Rightmove property search into structured JSON. Give it a UK place name, choose to buy or rent, and get the listings back: price (amount, currency, rent frequency and the price as printed), transaction type, bedrooms and bathrooms, property type, address, a short summary, coordinates, images, the estate agent (name, branch and phone) and the listing dates.

Filter by price, bedrooms and property type, sort the results, and collect up to 1,008 listings in one call. No Rightmove account is needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Property search

```
POST /realestate/rightmove
```

| Field | Required | Notes |
| --- | --- | --- |
| `location` | yes | UK place name, e.g. `London`, `Manchester` or `Milton Keynes`. A place Rightmove cannot resolve returns `404`. |
| `channel` | no | `buy` (default, for sale) or `rent` (to rent). |
| `min_price` / `max_price` | no | Price range in GBP. |
| `min_bedrooms` / `max_bedrooms` | no | Bedroom range. |
| `property_type` | no | Rightmove property types, comma-separated, e.g. `flat,detached`. |
| `sort` | no | `relevance` (default), `newest`, `price_asc`, `price_desc` or `oldest`. |
| `max_results` | no | How many listings to collect across pages (about 24 per page). Default `48`, max `1008`. |
| `page` | no | 1-based results page to start from. Default `1`, max `42`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

| Field | Notes |
| --- | --- |
| `id` / `url` | Rightmove property id and a clean listing URL. |
| `address` | Display address as Rightmove shows it. |
| `price` | `amount` (number), `currency` (`GBP`), `frequency` (e.g. `monthly` for rentals) and `display` (the price as printed, e.g. `£1,000 pcm`). |
| `transactionType` | Rightmove transaction type, `buy` or `rent`. |
| `bedrooms` / `bathrooms` | Room counts. |
| `propertyType` / `propertyTypeFull` | Short type (e.g. `Apartment`) and the full label (e.g. `2 bedroom apartment`). |
| `summary` | Listing summary text. |
| `coordinates` | `lat` / `lng`. |
| `images` | Listing photo URLs. |
| `agent` | Estate agent `name`, `branch` and `phone`. |
| `addedOrReduced` | Rightmove's "Added on" or "Reduced on" line. |
| `firstVisibleDate` | When the listing first appeared. |
| `listingUpdateReason` / `listingUpdateDate` | Latest change to the listing (e.g. `new`, `price_reduced`) and when it happened. |

`totalResults` is the number of matches Rightmove reports for the search.

## What you can build

- **Rent and price tracking** - follow asking rents and prices by town, bedroom count and property type.
- **New-listing and price-cut alerts** - run a search on a schedule with `sort=newest` and watch `listingUpdateReason`.
- **Agent market share** - count listings per `agent` and branch across a region.
- **Map-based analysis** - plot listings by `coordinates` to study supply by neighbourhood.
