The **Google Lens** plugin runs a Google Lens search for an image and returns the results as structured JSON. Give it the public URL of an image - a product photo, a landmark, a logo - and it returns the **visual matches** Lens finds (usually around 60): the page each match is on, its site and domain, the matching image with its size and thumbnail, and, for product matches, the price and currency (plus the product name, brand and description when Google has them) and the price text, rating and review count as the tile shows them.

The response also carries `relatedSearches` - what Lens recognised in the image, such as `Eiffel Tower` with its Knowledge Graph id - and `aiOverview`, Google's own description of the image when it is ready in time (else `null`). Google fetches the image itself, so the URL must be publicly reachable. No Google account or API key is involved. To search images by keyword instead, use [Google Images](/plugins/google-images).

<Note>
Google loads Lens matches for non-US visitors only, so every call is served from a non-US exit, a US request included (by default from a European country). `proxyCountry` in the response says which country served the call. Shopping matches and prices follow that country; `gl` and `hl` set the Google market and language.
</Note>

## Endpoint

```
POST /images/google-lens
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | yes | Public `http(s)` URL of the image to search with, e.g. a product photo. Google fetches the image itself. |
| `proxy_country` | no | Country the request is sent from (ISO-2, e.g. `DE`, `FR`). Shopping matches and prices follow the country Google sees the request from. A `US` request is served from a non-US exit (see the note above). |
| `gl` | no | Google market override (ISO-2). Default: `proxy_country`, else `us`. |
| `hl` | no | Google UI language, e.g. `en`, `de`. Default `en`. |
| `max_results` | no | Cap on the visual matches returned, `1`-`100`. Default: all (usually around 60). |

In cURL the image URL goes in the query string, so URL-encode it; the SDKs do that for you.

Each search is billed as one request. A `502` (no visual matches) is not billed.

| Field | Notes |
| --- | --- |
| `visualMatches` | The matches in Lens order. Each has `title`, `url` (the page the image is on), `domain`, `source` (site name), `imageUrl` (the matching image), `thumbnailUrl`, `width`, `height` and `position`. |
| `price` / `currency` / `product` | For product matches: the price and currency, and `product` with `name`, `brand` and `description` when Google has them (else `null`). |
| `priceText` / `rating` / `reviews` | The price, rating and review count as the match tile shows them, when it does. |
| `relatedSearches` | What Lens recognised in the image: `query`, its Knowledge Graph id `kgmid` and the Google search `url`. |
| `aiOverview` | Google's own description of the image (`text`, `markdown`, and the `references` it cites), or `null` when it was not ready in time. |
| `proxyCountry` | The country that served the call, which shopping matches and prices follow. |
| `resultsCollected` | Number of visual matches returned. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, or the image URL is unusable (it answers `404`, or is a web page instead of an image). Plain-text message. |
| `403` | Google kept answering with a CAPTCHA after retries. Try another `proxy_country`. |
| `502` | No visual matches: Google could not fetch the image, the request was blocked, or the call did not finish in time. Not billed. Retry. |
| `503` | No proxy exit was free for this market. Retry, or pick another `proxy_country`. |

## What you can build

- **Find where an image appears** - list the pages and sites that use a product photo, a logo or artwork.
- **Visual product search** - turn a product photo into shopping matches with prices for a market.
- **Counterfeit and reseller monitoring** - spot shops reusing your product images.
- **Image recognition** - get what Lens recognises in an image (landmarks, products, brands) with its Knowledge Graph id.
