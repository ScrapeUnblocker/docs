The **ALDI Australia** plugin returns aldi.com.au product data as structured JSON. One endpoint covers four methods: **search** by keyword, list a **category** (including ALDI's Lower Prices group), list a **Special Buys** drop with its on-sale date and themes, or fetch one **product** in full with its ingredients, allergens, claims and storage.

Every product carries its SKU, name, brand, size and link, the price as a number and as ALDI shows it, any was-price, the unit price, a bottle deposit where one applies, the Special Buys on-sale date, badges, availability, online-sale and age-restricted flags, the image and its categories. ALDI Australia does not sell groceries online, so the prices are ALDI's **in-store prices** in AUD. Listings return 60 products per page; `max_results` collects up to 600 across pages, and each page fetched is one billed unit (`pagesFetched`).

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

Products matching a keyword.

```
POST /groceries/aldi-au
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `aldiAuSearch`. In a raw request `search` is the default. |
| `query` | yes | What to search for, e.g. `milk`, `chocolate` or `nappies`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `name_asc` or `name_desc`. |
| `page` | no | 1-based listing page to start from (60 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`600`. Default `60`. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). ALDI answers every country, so leave it blank unless you need one. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/groceries/aldi-au?mode=search&query=milk&sort=price_asc" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY
```


The search, category and specials methods return the same product objects:

| Field | Notes |
| --- | --- |
| `id` | ALDI SKU (18 digits). Pass it to [Product](#product). |
| `name` / `brand` / `size` / `url` | Product name, brand, pack size and product page link. |
| `price` / `priceText` | In-store price as a number and as ALDI prints it. |
| `wasPrice` / `onSale` / `savings` | The previous price and saving when ALDI shows a price drop. |
| `unitPrice` | Price per unit: `price`, `per` (e.g. `1 L`, `100 g`) and the label `text`. `null` for items sold by the piece. |
| `bottleDeposit` | Container deposit where one applies, else `null`. |
| `specialBuy` | For Special Buys: `onSaleDate` and ALDI's label `text` (e.g. `While Stocks Last`). `null` for the regular range. |
| `badges` | ALDI's badges on the product tile. |
| `available` / `soldOnline` / `ageRestricted` | Availability, whether ALDI sells it online, and the age-restricted flag. |
| `image` / `categories` / `categoryKeys` | Product image URL, category names and ALDI's category keys (usable as `category` in [Category](#category)). |

`totalResults`, `totalPages` and `nextPage` page through the rest; pass `nextPage` as `page` to continue. `spellingSuggestion` carries ALDI's suggestion when it has one.

## Category

One category listing, such as Milk, or ALDI's Lower Prices group.

```
POST /groceries/aldi-au
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `category` by `aldiAuCategory`. In a raw request it is implied when `category` is given. |
| `category` | yes | A category link (`https://www.aldi.com.au/products/dairy-eggs-fridge/milk/k/1111111160`) or its key (`1111111160`). `1588161425841179` is Lower Prices. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `name_asc` or `name_desc`. |
| `page` | no | 1-based listing page to start from (60 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`600`. Default `60`. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). Leave blank unless you need one. |

## Special Buys

One Special Buys drop - the current one by default - with every drop ALDI has announced.

```
POST /groceries/aldi-au
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `specials` by `aldiAuSpecials`. In a raw request send `mode=specials`. |
| `category` | no | Which Special Buys drop: its date (`2026-10-14`) or link. Default: the current drop. |
| `theme` | no | Keep one theme of the drop, e.g. `Gardening`. The themes of each drop are in `promotions[].themes`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `name_asc` or `name_desc`. |
| `page` | no | 1-based listing page to start from (60 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`600`. Default `60`. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). Leave blank unless you need one. |

To list another announced drop, pass its date or link as `category`, e.g. `su.aldi_au_specials(category="2026-10-14")` (`https://www.aldi.com.au/special-buys/2026-10-14` also works). A date with no drop returns `404`.

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/groceries/aldi-au?mode=specials&theme=Gardening" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

## Product

One product in full, with ingredients, allergens, claims and storage.

```
POST /groceries/aldi-au
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `product` by `aldiAuProduct`. In a raw request it is implied when `product` is given. |
| `product` | yes | An ALDI SKU (`000000000000371077`) or a product link (`https://www.aldi.com.au/product/farmdale-light-milk-2l-000000000000398691`). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `AU`). Leave blank unless you need one. |

## What you can build

- **In-store price tracking** - follow ALDI's shelf prices and unit prices for a basket of SKUs.
- **Special Buys calendar** - list every announced drop with its themes and products before it goes on sale.
- **Cross-retailer comparison** - compare unit prices against [Woolworths](/plugins/woolworths) and [Coles](/plugins/coles).
- **Product and allergen catalogs** - collect descriptions, ingredients, allergens and storage for the ALDI range.
