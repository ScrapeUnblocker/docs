The **Flipkart** plugin returns products from Flipkart (flipkart.com, India) as structured JSON. It is two endpoints:

- **`/marketplace/flipkart-search`** - the products for a keyword, in Flipkart's order: the product id (FSN), title, brand, price, MRP and discount, rating, rating and review counts, the F-Assured badge, sponsored flag, Flipkart's badge (e.g. Bestseller), stock, key specs, category, images and link. Sort, filter by price and collect across pages.
- **`/marketplace/flipkart-product`** - one product: description, category path, price, MRP, discount and the best price with bank offers, stock, rating with its 1-5 star breakdown and the per-aspect ratings (Camera, Battery, ...), highlights, the full specification table, images, every variant, the seller with its rating, the bank and exchange offers, delivery days, cash on delivery, the return policy and the top reviews.

Prices are in Indian rupees (INR). No Flipkart account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/flipkart-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `iphone 17` or `running shoes`. |
| `sort` | no | Result order: `relevance`, `popularity`, `price_asc`, `price_desc`, `newest`. Default `relevance`. |
| `page` | no | First Flipkart results page to read, `1`-`100`. Default `1`. |
| `min_price` / `max_price` | no | Price range in rupees (INR). |
| `max_results` | no | Products to collect across pages, `1`-`240`. Default `24`. A page holds 24 products (40 in fashion grids). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/flipkart-search?query=iphone%2015&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.flipkart_search("iphone 15", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```


```ruby Ruby

```
</CodeGroup>

Each Flipkart page read is billed as one request (`pagesFetched`).

| Field | Notes |
| --- | --- |
| `productId` / `itemId` / `listingId` | The FSN (Flipkart's product id), the `itm...` id from the link and the listing id. Pass `productId` to [Product](#product). |
| `title` / `brand` / `subtitle` | Product name, brand and Flipkart's subtitle line, when it has one. |
| `price` / `originalPrice` / `discountPercent` / `currency` | Selling price, MRP (when discounted), the discount and `INR`. |
| `rating` / `ratingCount` / `reviewCount` | Average rating and how many ratings and written reviews it has. |
| `assured` / `sponsored` / `badge` | The F-Assured badge, the sponsored flag and Flipkart's label (e.g. `Bestseller`). |
| `availability` / `inStock` | Flipkart's stock status and a boolean derived from it. |
| `keySpecs` / `category` | The spec bullets on the result card and the product category. |
| `image` / `images` / `url` | Main image, gallery and product link. |
| `position` | Rank in Flipkart's results. |
| `total` / `totalPages` / `nextPage` | Flipkart's result count, page count and the `page` to pass to continue. |

## Product

```
POST /marketplace/flipkart-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | Flipkart product id: the FSN (`pid`, e.g. `MOBHQV9YCUG4ZQZK`) or the `itm...` id from a product link. |
| `url` | one of `product_id` / `url` | A Flipkart product link, e.g. `https://www.flipkart.com/apple-iphone-17-black-256-gb/p/itmc61b40459dd98?pid=MOBHQV9YCUG4ZQZK`. Used instead of `product_id`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/flipkart-product?product_id=MOBHQV9YCUG4ZQZK" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

result = su.flipkart_product("MOBHQV9YCUG4ZQZK")
```


To look a product up by link, leave the first argument out and pass `url` (`su.flipkart_product(url="https://www.flipkart.com/...")` in Python, `su.flipkartProduct(undefined, { url })` in Node.js). Each product is billed as one request.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, or neither `product_id` nor `url`. |
| `404` | Flipkart found no products for this search, or has no product with this id. |
| `502` | Flipkart blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Price monitoring for India** - track selling price, MRP, discount and the best bank-offer price over time.
- **Assortment research** - collect a category's results with ratings and review counts as demand signals.
- **Seller and offer tracking** - watch who sells a product and which bank and exchange offers apply.
- **Spec comparison** - compare specification tables and aspect ratings across rival products.
