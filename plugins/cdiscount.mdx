The **Cdiscount** plugin returns products from Cdiscount (cdiscount.com, France) as structured JSON. It is two endpoints:

- **`/marketplace/cdiscount-search`** - the products for a keyword: product id (the SKU) and offer id, title, link and images, the price with the crossed-out reference price and the discount (only when Cdiscount shows one), rating and review count, the seller (Cdiscount or a marketplace seller), whether Cdiscount fulfils it, the Cdiscount à volonté flag, free shipping and the delivery label, condition, key specifications and promotion badges. A page holds about 47 products; one call collects up to 300.
- **`/marketplace/cdiscount-product`** - one product: brand, EAN and manufacturer reference, breadcrumbs, the price with and without VAT, the crossed-out price and its kind, the eco-participation, stock and order limit, condition, the seller, delivery, the count and lowest price of the new and used offers, rating with its breakdown and criteria ratings, specifications, description, images, videos, variants, energy class, repairability index, installments, badges, documents and the latest reviews.

Prices are in euros, as shown to a signed-out shopper. Search results give the brand only as an id (`brandId`); the product endpoint has the brand name. No Cdiscount account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.

## Search

```
POST /marketplace/cdiscount-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `iphone 15` or `machine a laver`. |
| `page` | no | First Cdiscount results page to read, `1`-`100`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`300`. Default `47`. A page holds about 47 products; each page is billed as one request. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/cdiscount-search?query=aspirateur%20robot&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.cdiscount_search("aspirateur robot", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.cdiscountSearch("aspirateur robot", { maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->cdiscountSearch('aspirateur robot', ['max_results' => 3]);
```



| Field | Notes |
| --- | --- |
| `productId` / `offerId` | Cdiscount product id (the SKU; pass it to [Product](#product)) and the offer shown on the tile. |
| `title` / `url` / `image` / `images` | Product name, link and images. |
| `brandId` / `categoryId` | Cdiscount's brand and category ids (the brand name is on the product endpoint). |
| `price` / `currency` | The price, in EUR. |
| `strikePrice` / `discountPercent` | The crossed-out reference price and the discount, only when Cdiscount shows one. |
| `rating` / `reviewCount` | Average rating and number of reviews. |
| `seller` / `marketplace` | The seller (`id`, `name`, `isCdiscount`) and whether it is a marketplace seller. |
| `fulfilledByCdiscount` / `cdiscountAVolonte` | Whether Cdiscount ships it from its own warehouses, and whether it is part of the Cdiscount à volonté programme. |
| `freeShipping` / `deliveryLabel` | Free shipping flag and Cdiscount's delivery text. |
| `condition` / `isNew` | The item's condition. |
| `otherOffers` | Number of other new and used offers and their lowest prices. |
| `highlights` / `badges` | Key specifications and promotion badges. |
| `position` | Rank in the results. |
| `total` / `lastPage` / `nextPage` | Cdiscount's result count and last page; pass `nextPage` as `page` to continue. |

## Product

```
POST /marketplace/cdiscount-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `sku` | one of `sku` / `url` | Cdiscount product id, e.g. `ip17256black` (the part after `f-<number>-` in a product link, or `productId` from search). |
| `url` | one of `sku` / `url` | A Cdiscount product link, e.g. `https://www.cdiscount.com/telephonie/telephone-mobile/apple-iphone-17-256gb-black/f-14404-ip17256black.html`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/cdiscount-product?sku=ip17256black" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.cdiscount_product("ip17256black")
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```

```php PHP
use ScrapeUnblocker\Client;
```


To look a product up by link, leave the first argument out and pass `url` (`su.cdiscount_product(url="https://www.cdiscount.com/...")` in Python, `su.cdiscountProduct(undefined, { url })` in Node.js). Each product is billed as one request.

| Field | Notes |
| --- | --- |
| `brand` / `ean` / `manufacturerReference` / `breadcrumbs` | Brand name, EAN barcode, manufacturer part number and category path. |
| `price` / `priceWithoutVat` / `ecoParticipation` | The price, the same price without VAT, and the eco-participation fee included in it. |

| `offers` | Count of all, new and used offers, and the lowest new and used price. The individual marketplace offers and their sellers' ratings are not included. |
| `ratingBreakdown` / `recommendedCount` / `criteriaRatings` | Reviews per star (1-5), how many reviewers recommend it, and the average per criterion. |
| `highlights` / `specifications` | Key specifications, and every specification as `group`, `name` and `value`. |
| `description` / `images` / `videos` / `documents` | Description (`null` when the page has none), images, videos and documents such as the product sheet. |
| `variants` | Other versions of the product (storage, colour...): `productId`, `offerId`, `attributes`, `price`, `url` and `selected`. |

| `installments` / `badges` | The pay-in-instalments offer and the promotion badges. |
| `reviews` | The latest reviews: `id`, `rating`, `title`, `text`, `author` (as Cdiscount shows it), `date` and `productVariant`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, no `sku` or `url`, or a `sku` that is not a Cdiscount product id. |
| `404` | Cdiscount found nothing for the search, or has no product with this SKU. |
| `502` | Cdiscount blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Price monitoring** - track Cdiscount prices, discounts and the reference price they are measured against.
- **Marketplace research** - see which products Cdiscount sells itself and which come from marketplace sellers.
- **Assortment and content analysis** - collect EANs, specifications, energy classes and repairability scores per category.
- **Review analysis** - follow ratings, criteria scores and the latest reviews for your products.
