The **Coles** plugin returns Coles Australia (coles.com.au) grocery data as structured JSON. One endpoint covers four methods: **search** by keyword, list a **category**, list the products on **special** (all deals, or only half-price, multibuy or online-only), or fetch one **product** in full with its ingredients, allergens and nutrition panel.

Every product carries its id, name, brand, size and link, the price with any was-price and saving, the promotion, the unit price, stock with the quantity available, purchase and promotional limits, its categories and the minimum shelf life. Prices are Coles' online prices in AUD. Listings return 48 products per page; `max_results` collects up to 480 across pages, and each page fetched is one billed unit (`pagesFetched`).

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

<Note>
Coles serves its site only to Australia, New Zealand, the US and Canada, so `proxy_country` accepts `AU`, `NZ`, `US` or `CA`; any other country is rejected. Leave it blank and the plugin picks one of them for you.
</Note>

## Search

Products matching a keyword.

```
POST /groceries/coles
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `colesSearch`. In a raw request `search` is the default. |
| `query` | yes | What to search for, e.g. `milk`, `tim tam` or `chicken breast`. |
| `special` | no | Keep only products on special: `all`, `half-price`, `multibuy` or `online-only`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc` or `unit_price_asc`. |
| `page` | no | 1-based listing page to start from (48 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`480`. Default `48`. Each page fetched is one billed unit. |
| `proxy_country` | no | `AU`, `NZ`, `US` or `CA`. Leave blank to spread over all of them. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/groceries/coles?mode=search&query=tim%20tam&sort=unit_price_asc" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python

```

The search, category and specials methods return the same product objects:

| Field | Notes |
| --- | --- |
| `id` | Coles product id. Pass it to [Product](#product). |
| `name` / `brand` / `size` / `url` | Product name, brand, pack size and product page link. |
| `barcode` | EAN barcode. Listings usually carry `null`; [Product](#product) fills it. |
| `price` / `wasPrice` / `savings` | Current price, the struck-through price and the saving, in AUD. `null` when Coles shows none. |
| `onSale` / `promotion` | Whether the product is on special, and the deal: `type` (`half_price`, `special`, `multibuy` or `offer`) and `text`; multibuy deals add `quantity` and `price`. |
| `priceDescription` | Coles' price label when it has one, e.g. `1/2 Price`. |
| `unitPrice` | Price per unit: `price`, `per` (e.g. `1l`, `100g`) and the label `text`. |
| `inStock` / `available` / `availableQuantity` | Stock and availability flags, and the quantity Coles reports as available. |
| `purchaseLimit` / `promotionalLimit` | Maximum per order, and maximum at the promotional price. |
| `onlineOnly` / `sponsored` | Online-only deal and sponsored placement flags. |
| `image` / `categories` / `minimumShelfLife` | Product image URL, its categories, and Coles' minimum shelf life label (e.g. `Life 7 days min`). |

`totalResults`, `totalPages` and `nextPage` page through the rest; pass `nextPage` as `page` to continue. `didYouMean` carries Coles' spelling suggestion when it has one.

## Category

One category listing, such as Milk or Bakery.

```
POST /groceries/coles
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `category` by `colesCategory`. In a raw request it is implied when `category` is given. |
| `category` | yes | A browse link (`https://www.coles.com.au/browse/dairy-eggs-fridge/milk`) or its path (`dairy-eggs-fridge/milk`). |
| `special` | no | Keep only products on special: `all`, `half-price`, `multibuy` or `online-only`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc` or `unit_price_asc`. |
| `page` | no | 1-based listing page to start from (48 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`480`. Default `48`. Each page fetched is one billed unit. |
| `proxy_country` | no | `AU`, `NZ`, `US` or `CA`. Leave blank to spread over all of them. |

`product` carries every field listed under [Search](#search), plus:

| Field | Notes |
| --- | --- |
| `barcode` / `description` / `ingredients` | EAN barcode, product description and the ingredient list as printed. |
| `allergens` / `dietary` | Allergen statement and dietary claims, as Coles prints them. |
| `storage` / `usage` / `dimensions` | Storage and usage instructions and pack dimensions, `null` when absent. |
| `nutrition` | Nutrition panel rows: `name`, `perServing`, `per100` (per 100 g or mL) and, where printed, `dailyIntake`. |
| `servingSize` / `servingsPerPack` | Serving size and servings per pack. |
| `countryOfOrigin` / `countryOfOriginLabel` / `australianIngredientsPercent` | Country of origin, the label text and the share of Australian ingredients. |
| `images` | All product images. |
| `variants` | Other sizes and versions of the product, as product objects. Variants Coles lists without a price come back with `price: null` and `inStock: false`. |
| `lastUpdated` | When Coles last updated the product data (ISO). |

## What you can build

- **Grocery price monitoring** - track `price`, `wasPrice` and `unitPrice` for a basket of products over time.
- **Half-price and multibuy tracking** - pull the specials each week, by deal type, and see what goes on promotion.
- **Cross-retailer comparison** - compare unit prices against [Woolworths](/plugins/woolworths) and [ALDI Australia](/plugins/aldi-au).
- **Nutrition and allergen databases** - build a catalog keyed by barcode with ingredients, allergens and the nutrition panel.
