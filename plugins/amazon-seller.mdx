The **Amazon seller** plugin returns an Amazon third-party seller's public profile page as structured JSON. It is one endpoint:

- **`/marketplace/amazon-seller`** - one seller: name, logo and storefront link, the headline rating, rating count and positive share Amazon shows, the feedback summary for 30 days, 90 days, 12 months and lifetime (average rating, counts, positive / neutral / negative split and the 5-to-1 star histogram), the seller's own "about" text, the business name, address and every row of Amazon's "Detailed Seller Information" (business type, trade register and VAT number where the marketplace shows them), a link to Amazon's contact form, and the recent feedback.

Identify the seller with `seller_id` plus `marketplace` - for example the `sellerId` of an offer from the [Amazon offers plugin](/plugins/amazon-offers) - or with any Amazon URL that names the seller. Ratings and feedback are per marketplace, so the same seller can look different on `amazon.de` and `amazon.co.uk`. Amazon's own retail sellers show no ratings; those fields are `null`.

<Note>
The plugin returns what Amazon publishes on the profile page and nothing more. There is no phone number or e-mail field: Amazon routes buyers through its contact form, returned as `contactUrl`. Business name, address, trade register and VAT number come back where the marketplace shows them (EU and UK marketplaces mostly do).
</Note>

## Seller profile

```
POST /marketplace/amazon-seller
```

| Field | Required | Notes |
| --- | --- | --- |
| `seller_id` | one of `seller_id` / `url` | Amazon seller (merchant) id, e.g. `A3PEV2IAOYFKM6` - the `sellerId` of an offer from `/marketplace/amazon-offers`. Pair with `marketplace`. |
| `url` | one of `seller_id` / `url` | Any Amazon URL that names the seller: the profile (`https://www.amazon.de/sp?seller=A1J6G6R957S11K`), a storefront (`/s?me=...`) or a sold-by link. The seller id and marketplace are read from it. |
| `marketplace` | no | Regional Amazon site the seller sells on. Default `amazon.com`. One of `amazon.com`, `amazon.co.uk`, `amazon.de`, `amazon.fr`, `amazon.it`, `amazon.es`, `amazon.nl`, `amazon.se`, `amazon.pl`, `amazon.com.be`, `amazon.com.tr`, `amazon.ca`, `amazon.com.mx`, `amazon.com.br`, `amazon.co.jp`, `amazon.in`, `amazon.ae`, `amazon.sa`, `amazon.sg`, `amazon.com.au`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Optional: a seller profile is the same from every country, so by default any country is used. |

| Field | Notes |
| --- | --- |
| `name` / `logo` / `storefrontUrl` | The seller's display name, logo and storefront link. |
| `rating` / `ratingCount` / `positivePercent` | The headline numbers Amazon shows. |
| `ratingPeriod` / `ratingSummary` | Which period the headline covers (`12m`, or `lifetime` for a seller with few recent ratings) and the summary line as printed. |
| `feedbackSummary` | One entry per period (`30d`, `90d`, `12m`, `lifetime`): average `rating`, `ratingCount`, `ratingsWithText`, `positivePercent` / `neutralPercent` / `negativePercent` (4-5, 3 and 1-2 stars), the matching counts, and the `stars` histogram with `percent` and `count` per star. |
| `about` | The seller's own description, as free text. |
| `businessName` / `businessAddress` / `businessAddressLines` | The business name and address Amazon publishes, as one line and split into lines. |
| `businessDetails` | Every row of Amazon's "Detailed Seller Information" as `label` / `value` (e.g. business type, trade register number, VAT number, customer services address), where the marketplace shows them. |
| `contactUrl` | Amazon's contact-seller form. The plugin returns no phone number or e-mail field. |
| `recentFeedback` | The recent feedback on the profile: `rating`, `text`, `author`, `date`, the `rater` line, `struckThrough` (feedback Amazon struck out) and `amazonMessage` (when Amazon took responsibility for the order). |
| `exitCountry` / `exitProvider` | The country and the type (`isp`, `residential` or `datacenter`) of the proxy that served the call. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | No or invalid `seller_id` / `url`, or an unsupported `marketplace`. |
| `404` | Amazon has no seller profile with this id on this marketplace. |
| `502` | Amazon blocked every attempt, returned no profile page, or the call did not finish in time. Retry. |

## What you can build

- **Seller vetting** - check a seller's rating trend (30 days against lifetime) and negative share before you buy from them or partner with them.
- **Competitor monitoring** - track the sellers on your products, together with the [Amazon offers plugin](/plugins/amazon-offers).
- **Brand protection** - identify the businesses behind unauthorised offers by their published name, address and registration details.
- **Marketplace research** - map who sells in a category and how their feedback develops.
