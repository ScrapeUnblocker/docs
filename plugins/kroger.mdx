The **Kroger** plugin returns grocery data from Kroger (kroger.com) and its banner sites (Ralphs, Fred Meyer, King Soopers, Fry's Food, Smith's, QFC, Harris Teeter, Mariano's and the rest) as structured JSON. It is two endpoints:

- **`/groceries/kroger-search`** - the products for a keyword at one store, in the site's order: Kroger product id, UPC, name, brand, size, link and image, the price the shopper pays now with the regular and sale price, the promotion (sale, price drop, multibuy, must buy, buy one get one), unit price, stock level, the aisle location, whether the store offers pickup, delivery, in-store or shipping for it, rating, categories and SNAP eligibility.
- **`/groceries/kroger-product`** - one product by Kroger product id, UPC / GTIN barcode or product link: the same price and stock fields, plus the description, highlights, every image, ingredients, allergens, the nutrition panel, dietary tags and claims, category paths, country of origin, storage and size.

Kroger prices differ from store to store, so every answer is priced for one store, named in `store`. Pick it with `store_id`, or with a `zip` code (the banner's nearest store that takes online orders), or leave both blank for the banner's default store. Prices are in USD. No Kroger account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /groceries/kroger-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `milk`, `coca cola` or `gluten free bread`. |
| `banner` | no | Which Kroger-family site to use: `kroger`, `ralphs`, `fredmeyer`, `kingsoopers`, `frysfood`, `smithsfoodanddrug`, `qfc`, `dillons`, `bakersplus`, `citymarket`, `gerbes`, `foodfourless`, `harristeeter`, `marianos`, `metromarket`, `picknsave`, `jaycfoods`, `payless`, `foodsco`. Host names (`ralphs.com`) and common spellings (`food4less`, `smiths`, `frys`) work too. Default `kroger`. |
| `brand` | no | Only products of these brands, e.g. `Kroger` or `Kroger,Simple Truth` (separate several with commas or a vertical bar). |
| `store_id` | no | Kroger store id (8 digits, e.g. `01400929`): prices, stock and aisles are that store's. Every answer shows it as `store.storeId`, and `nearbyStores` lists more when you search by `zip`. Give `store_id` or `zip`, not both. |
| `zip` | no | US ZIP code: prices for the banner's nearest store to it that takes online orders (the nearest store at all when none does). The answer lists the nearby stores in `nearbyStores`. |
| `max_results` | no | Products to return, `1`-`24`. Default `24`. |

<Note>
A search returns the first page of Kroger's results only: up to 24 products per call. `totalResults` still reports the site's full match count, so narrow the keyword or add `brand` to reach products further down the list.
</Note>

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/groceries/kroger-search?query=milk&banner=kroger&zip=45202&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```


| Field | Notes |
| --- | --- |
| `productId` / `upc` / `gtin14` | Kroger's 13-digit product id and the barcodes. Pass any of them to [Product](#product). |
| `name` / `brand` / `size` / `url` / `image` | Product name, brand, pack size, link and image. |
| `price` / `priceText` / `currency` | What the shopper pays now at this store, the price as the site prints it (or the deal text), and `USD`. |
| `regularPrice` / `salePrice` / `onSale` / `savings` | The regular price, the sale price and saving when there is one. |
| `promotion` | `type` (`sale`, `price_drop`, `multibuy`, `must_buy`, `bogo`), `text`, for multibuy deals `quantity` and `quantityPrice`, and `expiresAt`. |
| `unitPrice` | `price`, `unit` and `text`, e.g. `$0.03/fl oz`. |
| `soldBy` / `priceIsEstimate` | `unit` or `weight`; for weighed items the price is Kroger's per-item estimate and `priceIsEstimate` is `true`. |
| `available` / `stockLevel` / `unavailableReason` / `maxOrderQuantity` | Whether the store sells it now, `HIGH`, `LOW` or `TEMPORARILY_OUT_OF_STOCK`, the site's reason when it cannot be ordered, and the order limit. |
| `fulfillment` | `pickup`, `delivery`, `inStore`, `ship`: whether the store offers the product that way. |
| `aisle` | Where it is in the store: `number`, `description`, `side`, `bay`, `shelf`. |
| `rating` / `reviewCount` / `categories` / `snapEligible` | Rating, review count, categories and SNAP eligibility. |
| `offers` | Extra deals on the product, such as `Save $2 each when you buy 3`. |
| `position` / `sponsored` | Rank in the results, and whether the slot is sponsored. |
| `store` | The store the prices are for: `storeId`, `name`, `banner`, `address`, `latitude`, `longitude`, `fulfillmentMethods`, `hours`, `pricesFor` (`pickup` or `inStore`) and `selectedBy` (`store_id`, `zip` or `default`). |
| `nearbyStores` | With `zip`: the banner's stores near it, with `phone` and `distanceMiles`. Pass a `storeId` as `store_id` to price another one. |
| `totalResults` / `resultsCollected` | The site's total match count, and how many products this call returned. |

## Product

```
POST /groceries/kroger-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product` | yes | Kroger's 13-digit product id (`0001111041700`), a UPC or GTIN barcode (`011110417005`), or a product link from any banner (`https://www.kroger.com/p/kroger-2-reduced-fat-milk/0001111041700`). A link picks its banner by itself. |
| `banner` | no | Which Kroger-family site to use, as in search. Default `kroger`. |
| `store_id` | no | Kroger store id whose price, stock and aisle to return, as in search. |
| `zip` | no | US ZIP code: prices for the banner's nearest store to it that takes online orders, as in search. Leave both blank for the banner's default store. |

`product` carries every search field above, plus:

| Field | Notes |
| --- | --- |
| `description` / `highlights` / `images` | Product text, the bullet highlights and every image angle, large. |

| `dietary` / `claims` | Dietary tags (e.g. `Kosher`, `Vegetarian`) and label claims (e.g. `No Added Sugar`). |
| `organic` / `glutenFree` / `kosher` / `nonGmo` | The same tags as flags. |
| `taxonomy` | Category paths, e.g. `Dairy & Eggs > Milk & Dairy Free Milk > ...`. |
| `countryOfOrigin` / `storage` / `dimensions` / `weight` | Origin, storage type, package dimensions and weight as Kroger lists them. |
| `receiptName` | The product's name on the till receipt. |
| `ratingBreakdown` | Number of ratings per star, `5` to `1`. |
| `alcohol` / `ageRestricted` | Whether the product is alcohol, and whether it needs an age check. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query` or `product`, an unknown `banner`, a `store_id` that is not 8 digits, both `store_id` and `zip`, or `max_results` outside `1`-`24`. |
| `404` | No store of the banner near `zip`, `store_id` is not one of the banner's stores, or (product) the banner has no such product at that store. |
| `502` | Kroger blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Store-level price tracking** - follow the price, sale and promotion of a basket of products at the stores you care about.
- **Price comparison across banners** - read the same UPC on Kroger, Ralphs, Fred Meyer or Harris Teeter and compare.
- **Promotion monitoring** - catch buy one get one, multibuy and price drop deals with their expiry dates.
- **Nutrition and ingredient data** - build product databases with ingredients, allergens and full nutrition facts.
- **In-store navigation** - map products to their aisle, bay and shelf.
