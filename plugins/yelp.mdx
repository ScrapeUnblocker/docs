The **Yelp Local** plugin returns Yelp business data as structured JSON. It has two methods:

- **Search** - a term and a location, such as `coffee` in `San Francisco, CA`, returns the businesses Yelp lists: name, rating, review count, price tier, categories, address, neighborhood, this week's hours, a review snippet and a clean business link. Filter by sort, price and open-now, and collect up to 240 across pages (10 per page).
- **Business** - a business URL returns one place in full: phone, address, website, menu link, opening hours, attributes, specialties, review highlights, photos and popular dishes.

To read a business's reviews, use [Yelp Reviews](/plugins/yelp-reviews) with the `businessId` or `url` from these results.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /local/yelp
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `yelpSearch`. In a raw request `search` is the default. |
| `find_desc` | yes | Search keyword or category, e.g. `coffee` or `plumbers`. |
| `find_loc` | yes | Location to search, e.g. `San Francisco, CA` or `94109`. |
| `sort` | no | `recommended` (default), `rating`, `review_count` or `distance`. |
| `price` | no | Price tier `1`-`4` (`$` to `$$$$`); combine like `1,2`. |
| `open_now` | no | `true` keeps only businesses open now. Default `false`. |
| `max_results` | no | How many businesses to collect across pages (10 per page), `1`-`240`. Default `30`. |
| `start` | no | Result offset to start from. Default `0`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Defaults to `US`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/local/yelp?mode=search&find_desc=coffee&find_loc=San%20Francisco%2C%20CA&sort=rating&max_results=10" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.yelp_search("coffee", "San Francisco, CA", sort="rating", max_results=10)
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```


| Field | Notes |
| --- | --- |
| `businessId` / `alias` / `url` | Yelp's business id, its alias and a clean `/biz/` link. Pass any of them to [Yelp Reviews](/plugins/yelp-reviews), or the `url` to [Business](#business). |
| `isAd` | `true` for sponsored results Yelp places in the list; filter them out if you want organic results only. |
| `name` / `rating` / `reviewCount` | Business name, star rating (out of 5) and number of reviews. |
| `priceRange` | `$` to `$$$$`, left out when Yelp shows none. |
| `categories` | Yelp categories. |
| `address` / `city` / `neighborhoods` | Street address, city and neighborhoods. |
| `hoursCurrentWeek` | This week's opening hours per day, as `HH:MM-HH:MM` ranges. |
| `reviewSnippet` / `image` | The review excerpt Yelp shows on the card, and the main photo. |

`totalResults` is how many businesses Yelp matched; page further with `start`.

## Business

```
POST /local/yelp
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `detail` by `yelpBusiness`. In a raw request send `mode=detail`. |
| `url` | yes | A Yelp business URL or `/biz/` alias, e.g. `https://www.yelp.com/biz/gary-danko-san-francisco`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Defaults to `US`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/local/yelp?mode=detail&url=https%3A%2F%2Fwww.yelp.com%2Fbiz%2Fgary-danko-san-francisco" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client
```

| Field | Notes |
| --- | --- |
| `phone` / `website` / `menuUrl` | Phone number as Yelp lists it, the business website and its menu link. |
| `address` / `street` / `city` / `state` / `zipCode` / `country` / `timezone` | Full address, its parts, and the local time zone. |

| `monthlySearchCount` / `isYelpAdvertiser` / `yelpGuaranteed` | Yelp's monthly search count, advertiser flag and Yelp Guaranteed flag, as Yelp shows them. |

## What you can build

- **Local lead generation** - list businesses for a category and city with phone, website and address.
- **Market and location research** - compare ratings, review counts and price tiers across a neighborhood.
- **Business data enrichment** - add hours, attributes, photos and popular dishes to your own listings.
- **Review pipelines** - feed each `businessId` into [Yelp Reviews](/plugins/yelp-reviews) for the full review text.
