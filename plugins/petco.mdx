The **Petco** plugin returns pet-supply product data from Petco (petco.com, US) as structured JSON. It is two endpoints:

- **`/marketplace/petco-search`** - the products for a keyword: SKU and product id, title, brand, link and image, the price, list price and Repeat Delivery (autoship) price, the sale flag, rating and review count, description, category, fulfilment flags (autoship, pickup, same-day delivery, in-store only), prescription flag, attributes (flavour, life stage...) and every size or colour variation with its own SKU and prices. Filter by brand, fulfilment and price. 48 products a page; one call collects up to 480.
- **`/marketplace/petco-product`** - one product in full: UPC, all prices (online, list, autoship, pickup), availability and online stock quantity, rating with its star histogram and recommend share, description, highlights, ingredients, feeding directions, specifications, dimensions, pet type, breadcrumbs, fulfilment flags, images, every variant with its prices and stock, and the first reviews (up to 10).

Prices are the online prices a signed-out shopper sees, in USD. Store-specific stock and member (Vital Care) prices are not included. No Petco account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/petco-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search for, e.g. `dog food`, `cat litter` or `fish tank`. |
| `url` | one of `query` / `url` | Instead of `query`: a petco.com search link, e.g. `https://www.petco.com/shop/en/petcostore/search?query=dog%20food`. |
| `sort` | no | `relevance`, `price_low`, `price_high`, `rating`, `popular`, `newest`, `name_asc` or `name_desc`. Default `relevance`. |
| `brand` | no | Only this brand, as petco.com names it (e.g. `Purina Pro Plan`; the `brands` list of a search shows the names). |
| `fulfillment` | no | Only products offered this way: `delivery`, `autoship`, `pickup` or `same_day`. |
| `min_price` / `max_price` | no | Price range in USD. |
| `page` | no | 1-based results page to start from, `1`-`200` (48 products per page, as on petco.com). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`480`. Default `48`. Each page of 48 fetched is billed as one request (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/petco-search?query=dog%20food&brand=Purina%20Pro%20Plan&fulfillment=autoship&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.petco_search("dog food", brand="Purina Pro Plan", fulfillment="autoship", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.petcoSearch("dog food", {
  brand: "Purina Pro Plan",
  fulfillment: "autoship",
  maxResults: 3,
});
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->petcoSearch('dog food', [
    'brand' => 'Purina Pro Plan',
    'fulfillment' => 'autoship',
    'max_results' => 3,
]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.petco_search("dog food", brand: "Purina Pro Plan", fulfillment: "autoship", max_results: 3)
```
</CodeGroup>

To search with a link instead, leave the first argument out and pass `url` (`su.petco_search(url="https://www.petco.com/shop/en/petcostore/search?query=dog%20food")` in Python, `su.petcoSearch(undefined, { url })` in Node.js). A term Petco sends to a brand or category page returns that page's listing, named in `redirectedTo`.

| `totalResults` / `lastPage` / `hasMore` / `nextPage` | Petco's match count and last page, and the page to pass as `page` to continue. |
| `redirectedTo` | The brand or category page Petco sent the term to, when it did (else `null`). |

## Product

```
POST /marketplace/petco-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product` | yes | A Petco SKU (the number a product link ends in, e.g. `3748364`) or a petco.com product link. A link returns its own variant; a SKU picks that variant. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `query` nor `url`, an unknown `sort` or `fulfillment`, a `page` above `200`, a `max_results` above `480`, `min_price` above `max_price`, or a `product` that is not a SKU or petco.com link. |
| `404` | Petco found no products for the search (or none on that `page`), or has no such product. |
| `502` | Petco did not answer or blocked every attempt, or the call did not finish in time. Retry. |

## What you can build

- **Pet supply price tracking** - follow online, sale and Repeat Delivery prices for a brand or category.
- **Stock monitoring** - watch online stock quantity for every size of a product.
- **Assortment research** - compare brands, ratings and fulfilment options across Petco's catalogue.
- **Product data enrichment** - pull ingredients, feeding directions, specifications and images for a product catalog.
