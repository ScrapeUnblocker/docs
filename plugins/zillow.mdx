The **Zillow** plugin turns Zillow into structured JSON. It has two endpoints:

- **Search** (`/realestate/zillow`) - give it a city and state or a ZIP and get the listings back: price, beds, baths, living area, lot size, address and coordinates, home type, Zestimate and rent Zestimate, tax-assessed value, days on Zillow, broker and a clean listing URL. Filter by status (for sale, for rent or sold), price, beds, baths and home type, and collect up to 820 listings in one call.
- **Property detail** (`/realestate/zillow-detail`) - give it a `zpid` or a property URL and get one home in full: description, facts, parking, price history, tax history, schools, MLS and broker, the photo gallery and the 3D tour link.

Use search to find homes and their `zpid`, then read each one in full through the detail endpoint. No Zillow account or API key is needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search listings

```
POST /realestate/zillow
```

| Field | Required | Notes |
| --- | --- | --- |
| `location` | yes | City and state or ZIP, e.g. `Austin, TX` or `78704`. |
| `status` | no | `for_sale` (default), `for_rent` or `sold`. |
| `home_type` | no | `houses`, `condos`, `townhomes`, `multi_family`, `apartments`, `manufactured` or `lots_land`. Omit for all types. |
| `min_price` / `max_price` | no | Price range in USD (monthly rent with `status=for_rent`). |
| `beds` | no | Minimum bedrooms. |
| `baths` | no | Minimum bathrooms. |
| `sort` | no | `newest` (default), `price_asc`, `price_desc`, `relevant`, `beds`, `sqft` or `lot`. |
| `max_results` | no | How many listings to collect across pages (about 41 per page). Default `41`, max `820`. |
| `page` | no | 1-based results page to start from. Default `1`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Defaults to US. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/realestate/zillow?location=Austin%2C%20TX&status=for_sale&beds=3&max_results=10" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python

su = Client()  # reads SCRAPEUNBLOCKER_KEY
```

`totalResults` is the number of matches Zillow reports for the search; `resultsCollected` is how many listings came back in `homes`.

| Field | Notes |
| --- | --- |
| `zpid` | Zillow property id. Pass it to the property detail endpoint. |
| `price` / `priceText` | Numeric price (monthly rent for rentals) and the price as Zillow prints it. |
| `currency` | Currency as Zillow sends it on search cards (`$`). |
| `beds` / `baths` / `area` | Bedrooms, bathrooms and living area in sqft. |
| `lotArea` / `lotAreaUnit` | Lot size and its unit. |
| `homeType` / `status` / `statusText` | Home type (e.g. `SINGLE_FAMILY`), listing status (e.g. `FOR_SALE`) and Zillow's status label. |
| `address`, `street`, `city`, `state`, `zipcode` | Full address and its parts. |
| `latitude` / `longitude` | Coordinates. |
| `zestimate` / `rentZestimate` | Zillow's value and rent estimates, when shown. |
| `taxAssessedValue` | Tax-assessed value, when shown. |
| `daysOnZillow` | Days since the listing went live on Zillow. |
| `broker` | Listing brokerage. |
| `hasImage` / `has3DModel` / `hasVideo` | Media flags for the listing. |
| `image` / `url` | Main photo and a clean listing URL. |

<Note>
Rental searches can return apartment buildings (`isBuilding: true`). They have no `zpid` and carry `lotId`, `buildingName`, a rent range (`price` to `maxPrice`), `units` and `availableUnits` instead.
</Note>

## Property detail

```
POST /realestate/zillow-detail
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | one of `url` / `zpid` | Zillow property URL, e.g. `https://www.zillow.com/homedetails/.../29429575_zpid/`. |
| `zpid` | one of `url` / `zpid` | Zillow property id, e.g. `29429575` (the `zpid` from a search result). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/realestate/zillow-detail?zpid=29429575" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

## What you can build

- **Market analytics** - pull listings for a city or ZIP and track price, price per sqft and days on Zillow over time.
- **Investment screening** - compare `price` with `zestimate` and `rentZestimate` to rank homes by estimated yield.
- **New-listing alerts** - run the same search on a schedule with `sort=newest` and flag `zpid`s you have not seen.
- **Property enrichment** - add price history, facts, schools and photos to your own records through the detail endpoint.
