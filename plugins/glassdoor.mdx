The **Glassdoor** plugin turns Glassdoor into structured JSON. It has three endpoints:

- **Job search** (`/jobs/glassdoor`) - a keyword and an optional location in, the job listings out: title, company with rating and logo, location, posting age, pay range with pay period and source, snippet, skills and the Easy Apply and sponsored flags.
- **Company reviews** (`/reviews/glassdoor`) - a company in, its employee reviews out: overall and six sub-ratings, recommend, CEO approval and business outlook, pros, cons and advice, job title, employment status, location and date, plus the employer's rating summary and company details.
- **Company salaries** (`/salaries/glassdoor`) - a company in, its salary estimates by job title out: base and total pay at five percentiles, currency, the number of salaries behind each estimate and the latest report.

For reviews and salaries, give the company as a Glassdoor employer id (`1651`), a Glassdoor company URL or a plain company name (`Microsoft`). No Glassdoor account is needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Job search

```
POST /jobs/glassdoor
```

| Field | Required | Notes |
| --- | --- | --- |
| `keyword` | yes | Job title or keywords, e.g. `data analyst`. |
| `location` | no | Location name, e.g. `New York, NY`. Resolved to Glassdoor's location id automatically; a name Glassdoor does not know returns `400`. |
| `loc_id` | no | Glassdoor numeric location id. Skips the name lookup. |
| `loc_type` | no | Type of `loc_id`: `C` (city), `S` (state), `N` (nation) or `M` (metro). |
| `sort` | no | `recency` (default) or `relevance`. |
| `job_type` | no | `fulltime`, `parttime`, `contract`, `internship`, `temporary` or `apprenticeship`. Omit for any. |
| `experience` | no | `internship`, `entrylevel`, `midseniorlevel`, `director` or `executive`. Omit for any. |
| `from_age` | no | Posted within this many days: `1`, `3`, `7`, `14` or `30`. |
| `min_salary` | no | Minimum annual salary. |
| `remote` | no | `true` for remote jobs only. Default `false`. |
| `radius` | no | Search radius in miles around the location. |
| `max_results` | no | How many jobs to collect across pages (about 30 per page). Default `30`, max `900`. |
| `page` | no | 1-based results page to start from. Default `1`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Defaults to US. |

## Company reviews

```
POST /reviews/glassdoor
```

| Field | Required | Notes |
| --- | --- | --- |
| `company` | yes | A Glassdoor employer id (`9079`), any Glassdoor company URL (`https://www.glassdoor.com/Reviews/Google-Reviews-E9079.htm`) or a company name (`Bank of America`, matched with Glassdoor's company search). No match returns `404`. |
| `sort` | no | `recent` (default), `helpful`, `highest` or `lowest`. |
| `rating` | no | Only reviews with this overall star rating, `1`-`5`. |
| `job_title` | no | Only reviews from job titles matching this text, e.g. `software engineer`. |
| `keyword` | no | Only reviews mentioning this keyword, e.g. `remote`. |
| `topic` | no | Only reviews about one topic: `compensation`, `culture`, `career_development`, `management`, `work_life_balance` or `diversity_and_inclusion`. |
| `employment_status` | no | Comma list of `full_time`, `part_time`, `contract`, `intern`, `freelance`. Default `full_time,part_time` (Glassdoor's own view). |
| `language` | no | Comma list of review languages (ISO 639-3): `eng`, `fra`, `deu`, `nld`, `por`, `spa`, `ita`. Default `eng`. |
| `current_only` | no | `true` for reviews by current employees only. Default `false`. |
| `max_results` | no | How many reviews to return, `1`-`25`. Default `3`. Above 3 the call also reads the other sort orders and each star rating and merges the distinct reviews. |
| `proxy_country` | no | Only `US` (or blank, the default) is accepted: Glassdoor sends visitors from other countries to their local site, where these pages do not exist. |

<Note>
Glassdoor shows signed-out visitors only the first page (3 reviews) of each sort or filter view, so there is no `page` parameter. Use `sort`, `rating` and the filters to reach other reviews, or raise `max_results` to read several views in one call. `publicLimitReached` is `true` when fewer reviews came back than you asked for because those views ran out. The plugin returns a sample of an employer's reviews, not its full review history.
</Note>

The response also carries:

- `summary` - overall rating, recommend / CEO approval / business outlook percentages, the CEO, sub-rating averages, `ratingDistribution` and reviews in the last 7 and 30 days.
- `companyMeta` - company name, logo, website, industry, sector, headquarters and size.
- Three counts that measure different sets: `totalReviews` is the number of reviews matching every filter of the call; `summary.allReviewsCount` is every review Glassdoor holds for the employer, in any language or status; `summary.reviewCount` is the number of ratings behind `overallRating`. `ratingDistribution` covers only part of the reviews for large employers, so read it as proportions, not totals.

Every field is always present and is `null` when Glassdoor does not show it.

## Company salaries

```
POST /salaries/glassdoor
```

| Field | Required | Notes |
| --- | --- | --- |
| `company` | yes | A Glassdoor employer id (`9079`), any Glassdoor company URL or a company name (`Bank of America`). No match returns `404`. |
| `job_title` | no | Narrow to job titles matching this text, using Glassdoor's own job-title search, e.g. `software engineer`. |
| `max_results` | no | How many job-title rows to return, `1`-`100` (10 per Glassdoor page, most-reported titles first). Default `20`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Defaults to US, so pay is reported for the US market in USD. |

## What you can build

- **Compensation benchmarking** - compare base and total pay percentiles for the same job title across employers.
- **Employer brand monitoring** - track a company's ratings, recommend and CEO approval shares and new reviews over time.
- **Hiring signals** - follow how many roles a company posts, where and at what pay through job search.
- **Job boards and aggregators** - pull fresh listings with pay ranges for a keyword and location.
