The **AliExpress** plugin returns AliExpress data as structured JSON. It is two endpoints:

- **`/goods/aliexpress-search`** - give it a keyword and it returns the products AliExpress shows, each with its `productId`, title, numeric price plus the formatted price and currency, the original price, rating, how many have sold (`orders`), images and a clean product URL, plus the total result count.
- **`/goods/aliexpress-product`** - one item, priced in the `currency` you pick and shipped to the `country` you pick: price range and discount, rating and orders, the store, every shipping option with fees and delivery dates, the option menus, every SKU with its price and stock, specifications and images. See [Product](#product).

Sort by relevance, orders, price or newest and collect up to 1,200 products per call (about 60 per page). AliExpress localises prices and titles by region, so the currency and language follow the proxy country: pass `proxy_country` (for example `US`) to pin them.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /goods/aliexpress-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `keyword` | yes | What to search, e.g. `wireless earbuds` or `phone case`. |
| `sort` | no | `relevance` (default), `orders`, `price_asc`, `price_desc` or `newest`. |
| `max_results` | no | How many products to collect across pages (about 60 per page). Default `60`, max `1200`. |
| `page` | no | 1-based results page to start from, `1`-`20`. Default `1`. |
| `proxy_country` | no | Proxy country (ISO-2). Also sets the currency and language AliExpress answers in. Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/goods/aliexpress-search?keyword=wireless%20earbuds&sort=orders&proxy_country=US" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```


| Field | Notes |
| --- | --- |
| `productId` / `url` | AliExpress product id and a clean `/item/<id>.html` URL. |
| `title` | Product title, in the language of the proxy country's AliExpress site. |
| `price` / `currency` / `currencySymbol` | Numeric price, ISO currency and its symbol. The currency follows `proxy_country`. |
| `priceFormatted` | The price as AliExpress prints it. |
| `originalPrice` / `originalPriceFormatted` | The price before the discount. `null` when there is none. |
| `rating` | Star rating (out of 5). |
| `orders` / `ordersText` | Units sold as a number (the lower bound AliExpress shows, e.g. `10,000+` -> `10000`) and the original text. |
| `image` / `images` | Main image and the image gallery from the result card. |

## Product

```
POST /goods/aliexpress-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | AliExpress item id, e.g. `1005010503016514` (the number in `/item/<id>.html`; the `productId` of a search result). |
| `url` | one of `product_id` / `url` | Instead of `product_id`: an AliExpress item link, e.g. `https://www.aliexpress.com/item/1005010503016514.html` (any storefront: `.com`, `.us`, `de.`, `fr.` ...). |
| `country` | no | Ship-to country (ISO-2, e.g. `US`, `DE`, `GB`). Shipping options, delivery times and whether the item is sold at all depend on it. Default `US`. |
| `currency` | no | Price currency, e.g. `USD`, `EUR`, `GBP`. Default `USD`. One of: `USD`, `EUR`, `GBP`, `CAD`, `AUD`, `NZD`, `CHF`, `SEK`, `NOK`, `DKK`, `PLN`, `CZK`, `HUF`, `RON`, `BGN`, `TRY`, `ILS`, `AED`, `SAR`, `JPY`, `KRW`, `SGD`, `MYR`, `THB`, `IDR`, `PHP`, `VND`, `INR`, `BRL`, `MXN`, `CLP`, `COP`, `PEN`, `ZAR`, `UAH`, `KZT`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/goods/aliexpress-product?product_id=1005010503016514&country=DE&currency=EUR" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

</CodeGroup>

To look a product up by link, leave the first argument out and pass `url` (`su.aliexpress_product(url="https://www.aliexpress.com/item/...")` in Python, `su.aliexpressProduct(undefined, { url })` in Node.js). Give `product_id` or `url`, not both. Each product is billed as one request.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters: a missing `keyword` (search), or a missing or invalid `product_id` / `url` / `country` / `currency`, or both `product_id` and `url` (product). |
| `404` | Product: no such AliExpress item, or AliExpress does not sell it to `country`. |
| `502` | AliExpress blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Product sourcing** - find top-selling items for a keyword with price and order counts.
- **Price comparison** - compare AliExpress prices in your local currency against other marketplaces.
- **Trend tracking** - watch `orders` grow over time to spot rising products.
- **Dropshipping catalogs** - collect titles, prices and images for a niche in one call.
- **Landed-cost checks** - read each SKU's price and the shipping fee and delivery time to your customers' country.
