The **AutoScout24** plugin turns a car search on Europe's largest car marketplace into structured JSON. Pass a make and model and the filters you need, and get the listings back: title, make, model and variant, condition, price (amount, formatted price and AutoScout24's price rating), mileage, first registration, fuel, transmission, power in kW and hp, engine size, location (country, ZIP, city, street), the seller (type, name, phones) and the listing images.

Filter by fuel, transmission, price, registration year, mileage, power and seller country, sort the results, and collect up to 400 listings in one call. No AutoScout24 account is needed.

Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Car search

```
POST /vehicles/autoscout24
```

| Field | Required | Notes |
| --- | --- | --- |
| `make` | no | Make slug, e.g. `bmw`, `volkswagen` or `audi`. |
| `model` | no | Model slug, e.g. `x5` or `golf`. Requires `make`. |
| `fuel` | no | `gasoline`, `diesel`, `electric`, `hybrid`, `lpg` or `cng` (or a raw AutoScout24 fuel code). |
| `transmission` | no | `automatic`, `manual` or `semi-automatic`. |
| `price_from` / `price_to` | no | Price range in EUR. |
| `year_from` / `year_to` | no | First-registration year range. |
| `mileage_to` | no | Maximum mileage in km. |
| `power_from` / `power_to` | no | Power range, in the unit set by `power_unit`. |
| `power_unit` | no | `kw` (default) or `hp`. |
| `country` | no | Seller country (ISO-2), e.g. `DE`, `IT` or `NL`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `newest`, `mileage_asc`, `year_desc` or `power_desc`. |
| `max_results` | no | How many listings to collect across pages (about 20 per page). Default `40`, max `400`. |
| `page` | no | 1-based results page to start from. Default `1`, max `20`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

| Field | Notes |
| --- | --- |
| `id` / `url` | AutoScout24 listing id and a clean listing URL. |
| `title` | Listing title (the version line the seller wrote). |
| `make` / `model` / `modelGroup` / `variant` | Make and model as AutoScout24 names them. |
| `condition` | `used`, `new`, `demonstration`, `old-timer` or `employee-car`. |
| `isNewListing` | `true` when the listing was posted recently (not a new car). |
| `price` | `raw` (number, EUR), `formatted` (as printed) and `label`, AutoScout24's price rating (e.g. `top-price`, `good-price`, `fair-price`, `expensive`). |
| `mileageKm` / `firstRegistration` | Mileage in km and first registration (`MM/YYYY`). |
| `fuel` / `transmission` | Fuel type and gearbox. |
| `powerKw` / `powerHp` / `engineCc` | Power in kW and hp, engine size in cc. |
| `location` | Seller `country`, `zip`, `city` and `street`. |
| `seller` | Seller `type` (e.g. `Dealer`), `name`, AutoScout24 `id` and `phones`. |
| `images` | Listing photo URLs. |

`totalResults` and `totalPages` are the counts AutoScout24 reports for the search.

## What you can build

- **Used-car pricing** - build price curves by make, model, year, mileage and power across European markets.
- **Deal finding** - sort by price and filter on AutoScout24's `top-price` and `good-price` ratings.
- **Dealer and stock analysis** - track listings and prices per seller and country.
- **Market alerts** - run a search on a schedule with `sort=newest` and flag new listings.
