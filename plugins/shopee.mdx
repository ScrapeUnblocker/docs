The **Shopee** plugin turns Shopee, which runs a separate marketplace site for each of its markets, into structured JSON. It is two endpoints:

- **`/marketplace/shopee-search`** - one results page of up to 40 products for a keyword in one market (Singapore, Indonesia, Malaysia, Thailand, Vietnam, the Philippines, Taiwan or Brazil): item and shop ids, name, link and image, the price in the market's currency, the crossed-out price and discount where Shopee shows them, the average rating, where the seller ships from and the promotion labels. Sort, filter by price, keep one shop's products, or pass a Shopee search or category link as it is.
- **`/marketplace/shopee-product`** - one product: price, rating, labels and images, and the shop's public profile (rating and rating count, followers, number of products, response rate, official and preferred flags, join date). In Singapore, Malaysia, Taiwan and Brazil it also returns the full listing: availability (in stock, sold out or withdrawn), description, brand, condition, the category path the product page shows, videos, variations and models (with which variations are sold out), attributes, pre-order flag, estimated shipping days and listing date. A product Shopee no longer has comes back as a `404` with `"status": "not_found"`.

What Shopee does not show: Shopee serves one results page per search, so one call returns at most 40 products; run several sort orders or price ranges for more. In Indonesia, Thailand, Vietnam and the Philippines a product comes back with its title and main image only, plus price, rating, labels and shop (`dataLevel` says which you got). The same `meta` level comes back in the other markets when Shopee refuses to render the product page; it is then read from the product's search card, so pass the product link with its title in it (not `/product/<shop>/<item>`). Per-variation prices, stock counts, units sold, a product's rating count and reviews are not included, because Shopee leaves them out of every page it shows signed-out visitors (whether each variation can be bought is included). In Brazil many products show their Pix price: the card then gives the discount against the list price but not the list price itself, so `originalPrice` is `null` and `isPixPrice` is `true`. `price` is what Shopee shows a signed-out shopper, which can be a promotional or new-customer price (see `labels`). No Shopee account or API key is involved.

Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.

## Search

```
POST /marketplace/shopee-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | one of `q` / `shop_id` / `url` | What to search for, e.g. `iphone case` or `air fryer`. |
| `country` | no | Shopee market: `sg` (shopee.sg), `id` (shopee.co.id), `my` (shopee.com.my), `th` (shopee.co.th), `vn` (shopee.vn), `ph` (shopee.ph), `tw` (shopee.tw) or `br` (shopee.com.br). Default `sg`. Prices are in that market's currency. |
| `shop_id` | one of `q` / `shop_id` / `url` | Only this shop's products (the number in a shop's links, e.g. `442800909`). Without `q` it lists the shop. |
| `url` | one of `q` / `shop_id` / `url` | A Shopee search or category link, e.g. `https://shopee.sg/search?keyword=lego`, used as it is; `q`, `country`, `shop_id`, `sort` and the price filters are then ignored. |
| `sort` | no | `relevance` (default), `sales`, `newest`, `price_asc` or `price_desc`. |
| `min_price` / `max_price` | no | Price range in whole units of the market's currency. Shopee applies it with its own logic (a promotion can pass on its pre-discount price), so we enforce it again on `price`: every product returned is inside the range. |
| `max_results` | no | Products to return, `1`-`40` (one Shopee results page). Default `40`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/shopee-search?q=iphone%20case&country=sg&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.shopee_search("iphone case", country="sg", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.shopeeSearch("iphone case", { country: "sg", maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->shopeeSearch('iphone case', ['country' => 'sg', 'max_results' => 3]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

```
</CodeGroup>

To list one shop, leave the keyword out and pass `shop_id`, e.g. `su.shopee_search(shop_id="442800909")` in Python. Each search is billed as one request.

| Field | Notes |
| --- | --- |
| `itemId` / `shopId` | Shopee's ids. Pass them (with `country`), or the `url`, to [Product](#product). |
| `name` / `url` / `image` | Product name, link and main image. |
| `price` / `currency` | The price in the market's currency, as Shopee shows a signed-out shopper. |
| `originalPrice` / `discountPercent` | The crossed-out price and the discount, when Shopee shows them. Some result cards carry the discount badge without the crossed-out price (Singapore and the Philippines always, Brazil on cards that show the Pix price), so `discountPercent` can come without `originalPrice`. |
| `isPixPrice` | `true` when a Brazilian card shows the price paid with Pix: `price` is then the Pix price, `discountPercent` is measured against the list price, and the list price is not on the card. `false` elsewhere. |
| `rating` | Average star rating, `null` for a product nobody has rated yet. |
| `location` | Where the seller ships from. |
| `labels` | Promotion badges, e.g. a campaign price. |
| `position` | Rank on the results page. |

## Product

```
POST /marketplace/shopee-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | one of `url` / `shop_id` + `item_id` | A Shopee product link, e.g. `https://shopee.sg/Beats-iPhone-17-Case-i.442800909.40270108836` or `https://shopee.co.id/product/1426163997/40581375446`. |
| `shop_id` / `item_id` | one of `url` / `shop_id` + `item_id` | Instead of `url`: the shop id and the item id, the two numbers after `-i.` in a product link. |
| `country` | no | With `shop_id` + `item_id`: the Shopee market, as in search. Default `sg`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. none of `q`, `shop_id` and `url` on a search, or neither a product `url` nor `shop_id` + `item_id`. |
| `404` | Shopee found no products for the search, or has no such product. For a product the body is JSON: `{"status": "not_found", "country": "br", "shopId": 341216199, "itemId": 11726761814, "message": "..."}` - Shopee says the product was removed or never existed. |
| `502` | Shopee blocked every attempt, gave an unusable answer, or did not answer in time. This is a failed call, not an answer about the product: retry. |

## What you can build

- **Price monitoring across markets** - track a product's price and promotions in each Shopee market.
- **Assortment research** - see which shops and brands rank for a keyword, by sales or by price.
- **Seller vetting** - compare shops by rating, followers, response rate and official status.
- **Catalogue enrichment** - pull descriptions, variations, attributes and images for products you list.
