The **Rakuten** plugin returns items from Rakuten Ichiba (rakuten.co.jp), Japan's largest online marketplace, as structured JSON. It is two endpoints:

- **`/marketplace/rakuten-search`** - the items for a keyword (in Japanese or English): item id and code, the shop, title and subtitle, link and images, the price in yen (and the top of the range when variants are priced differently), the Rakuten points a signed-out shopper earns, rating and review count, shipping fee, delivery estimate, unit price, subscription price, the daily genre rank, sold-out, used, pre-order and super-deal flags, genres and tags. Rakuten's sponsored items come back separately in `sponsored`. Rakuten serves 45 items per page; one call collects up to 450.
- **`/marketplace/rakuten-product`** - one item: the shop, title, tagline and description, condition, price (tax included), free shipping, availability and stock (when the shop shares it), delivery message, order limit, rating, genre and breadcrumbs, the shop's own categories, attributes, the variant options and every variant (SKU) with its options, price, availability, stock, JAN code and image, and the images.

Rakuten Ichiba is a Japanese site: titles and descriptions are in Japanese, and prices are in **yen**, tax included. No Rakuten account or API key is involved.

<Note>

## Search

```
POST /marketplace/rakuten-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search, in Japanese or English, e.g. `iphone`, `コーヒー` or `ナイキ スニーカー`. |
| `url` | one of `query` / `url` | Instead of `query`: a Rakuten search link, e.g. `https://search.rakuten.co.jp/search/mall/coffee/?s=2` (its keyword, genre, sort, page and price filter are used). |
| `sort` | no | `relevance` (default), `price_low`, `price_high`, `newest`, `review_count`, `review_score`. |
| `page` | no | 1-based results page to start from, `1`-`150`. Default `1`. Rakuten lets a search be paged through to 6,750 items. |
| `min_price` / `max_price` | no | Price range, in yen. |
| `genre_id` | no | Limit to one Rakuten genre (category) id, e.g. `100227` (food); every result's `genreId` is one. |
| `max_results` | no | Items to collect across pages, `1`-`450`. Default `45`. Rakuten serves 45 per page and each page read is billed as one request (`pagesFetched`). |

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/rakuten-search?query=%E3%82%B3%E3%83%BC%E3%83%92%E3%83%BC&sort=review_count&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

```



To search with a Rakuten search link, leave the first argument out and pass `url` (`su.rakuten_search(url="https://search.rakuten.co.jp/search/mall/...")` in Python, `su.rakutenSearch(undefined, { url })` in Node.js).

| `soldOut` / `used` / `preOrder` / `superDeal` / `hasVariants` | Item flags. |
| `genreId` / `genres` / `tags` | Rakuten genre id and path, and the item's tags. |
| `sponsored` | Rakuten's sponsored items for the search, with the same fields, kept apart from `products`. |
| `totalResults` / `reachableResults` / `nextPage` | Rakuten's match count, how far it lets the search be paged, and the next page to pass as `page`. |
| `relatedKeywords` | Rakuten's related searches. |

## Product

```
POST /marketplace/rakuten-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | The item as `<shopCode>/<itemCode>`, e.g. `dai-one/15-128-a` (the two path parts of an item link; search results give them as `shopCode` and `itemCode`). |
| `url` | one of `product_id` / `url` | Instead of `product_id`: a Rakuten item link, e.g. `https://item.rakuten.co.jp/dai-one/15-128-a/` (a `variantId` in it is used). |
| `variant_id` | no | SKU whose price and stock fill the top-level fields, e.g. `r-sku00003161`; by default the item's lowest price and overall availability. Every SKU is listed in `variants` either way. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. no `query` or `url`, a `min_price` above `max_price`, a non-numeric `genre_id`, a `product_id` not in `<shopCode>/<itemCode>` form, or both `product_id` and `url`. |
| `404` | Rakuten found no items for the search, or has no such item. |
| `502` | No usable answer from Rakuten on every attempt, or the call did not finish in time. Retry. |
