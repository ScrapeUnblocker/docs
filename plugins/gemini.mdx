The **Gemini** plugin asks Google Gemini (gemini.google.com) one question, as a signed-out visitor, and returns its answer as structured JSON: the answer as plain text and as Markdown, the **citations** (the pages Gemini cites inline, each with the answer sentences it backs and where in the answer the first of them appears), the **sources** Gemini consulted when it searched the web, whether it searched at all, its follow-up prompts, the model label the app shows and where Gemini placed the visitor.

Use it to see what Gemini recommends for the questions your customers ask, which sites it cites, and how that changes from one country to another. Set `country` to ask from that country: Gemini tailors local results, currency and language defaults to where it locates the visitor, and `locationCountry` in the answer says where it placed the call.

A few things to know:

- **Answers vary.** Each call starts a new conversation, and identical calls get different answers, as they do for people. Track a question over several calls rather than reading one answer as fixed.
- **Calls can be slow.** Gemini writes its answer before we can return it, and a call can take a minute or two. Give your HTTP client a generous timeout (the SDKs wait 180 seconds by default; raise it to 300, e.g. `Client(timeout=300)` in Python).
- **No account.** Gemini is used signed out; no Google account or API key is involved.

## Endpoint

```
POST /ai/gemini
```

| Field | Required | Notes |
| --- | --- | --- |
| `prompt` | yes | The question to ask, as a user would type it, e.g. `best CRM for small business`. At most 4,000 characters. Each call starts a new conversation. |
| `country` | no | Two-letter country code to ask from, e.g. `US`, `GB`, `DE`. Leave blank for any European location. A country we cannot ask from is a `400` that lists the available ones. |

| Field | Notes |
| --- | --- |
| `answer` / `answerMarkdown` | The answer as plain text and as Markdown (headings, bold, lists and tables kept). |
| `citations` | Pages Gemini cites inline: `position`, `title`, `url`, `domain`, `siteName`, `description`, `citedText` (the answer sentences that page backs) and `firstCitedAt` (the character offset of the first of them in `answerMarkdown`). |
| `sources` | Pages Gemini consulted when it searched the web: `position`, `title`, `url` and `domain`. |
| `webSearch` | Whether Gemini searched the web for this answer. |
| `followUpPrompts` | The follow-up suggestions Gemini offers: the short `label` and the full `prompt` it would send. |
| `richBlocks` | Number of cards Gemini drew that have no text (e.g. a sports score or an image strip); they are left out of the answer. |
| `model` | The model label the Gemini app shows. |
| `location` / `locationCountry` | Where Gemini placed the visitor. |
| `country` / `proxyCountry` | The country you asked for, and the country the call was sent from. |
| `complete` | `true` when Gemini finished its answer. |
| `conversationId` | Gemini's id for this one-question conversation. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters: an empty or too long `prompt`, or a `country` we cannot ask from (the message lists the available ones). |
| `502` | Gemini refused every attempt, gave no answer, or did not answer in time. Retry. |

## What you can build

- **AI visibility tracking** - see whether Gemini recommends your brand or product for the questions your customers ask, and who it names instead.
- **Citation monitoring** - track which sites Gemini cites and which sentences they back, by topic and country.
- **Answer comparison** - put Gemini's answer next to [Google AI Mode](/plugins/google-ai-mode) and other assistants for the same question.
- **Market research** - ask the same question from several countries and compare local recommendations.
