The **SofaScore** plugin returns live scores, fixtures, results and statistics from SofaScore (sofascore.com) as structured JSON. It is six endpoints:

- **`/sports/sofascore-events`** - a sport's matches on one day in your time zone, or the matches in progress right now, biggest competitions first, optionally for one country or competition and one status.
- **`/sports/sofascore-match`** - one match with the sections you ask for: statistics, lineups, incidents, head-to-head, odds, momentum, form, votes, managers, best players, shot map, commentary and highlights.
- **`/sports/sofascore-search`** - teams, players, competitions, matches, managers, referees and venues for a name, optionally within one sport.
- **`/sports/sofascore-team`** - a team (or a tennis player, MMA fighter and other individual competitors) with its last and next matches, squad, competitions and transfers.
- **`/sports/sofascore-player`** - a player with season statistics for any competition, last matches with the player's rating, transfers, attributes and national-team record.
- **`/sports/sofascore-tournament`** - a competition and season with standings, rounds, last and next matches, top players and top teams.

All 26 SofaScore sports are covered: `football`, `basketball`, `tennis`, `ice-hockey`, `american-football`, `baseball`, `handball`, `volleyball`, `cricket`, `rugby`, `futsal`, `table-tennis`, `esports`, `darts`, `snooker`, `mma`, `aussie-rules`, `waterpolo`, `floorball`, `bandy`, `badminton`, `beach-volley`, `minifootball`, `padel`, `motorsport` and `cycling`. Common names work too (`soccer`, `hockey`, `nba`, `nfl`, `ufc`, `f1` and the like). Motorsport and cycling are races, not matches, so they have no day list; search, teams, players and competitions work for them.

Teams, players and competitions can be given as an id, a sofascore.com link or a plain name. A name is resolved with the site's own search (the best match, within `sport` when you pass it), and the response echoes it as `resolvedFrom`. Each call is billed as one request, however many reads it takes. No SofaScore account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Matches on a day, or live now

```
POST /sports/sofascore-events
```

| Field | Required | Notes |
| --- | --- | --- |
| `sport` | no | The sport, see the list above. Default `football`. |
| `date` | no | The day as `YYYY-MM-DD`, or `today`, `yesterday` or `tomorrow` in `timezone`. Default today. |
| `timezone` | no | Time zone the day is read in: an IANA name (`Europe/London`, `America/New_York`) or a UTC offset (`+02:00`). Default `UTC`. SofaScore's own day lists span about a day either side; the plugin keeps exactly your day. |
| `live` | no | `true` for the matches in progress right now (`date` is then ignored). Default `false`. |
| `status` | no | Keep only `live`, `upcoming` or `finished` matches. Default `all`. |
| `country` | no | Only one country or category, by name, slug, ISO code or id: `england`, `Spain`, `US`, and for tennis `ATP` or `WTA`. |
| `tournament` | no | Only one competition: an id, a sofascore.com tournament link or a name such as `Premier League` or `NBA`. Give `country` or `tournament`, not both. |
| `max_results` | no | Matches to return, `1`-`500`, the biggest competitions first. Default `100`. |

<CodeGroup>
```bash cURL
# A day's matches in your time zone
curl -X POST "https://api.scrapeunblocker.com/sports/sofascore-events?sport=football&date=2026-11-01&timezone=Europe/London&max_results=20" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"

# Tennis matches in progress right now
curl -X POST "https://api.scrapeunblocker.com/sports/sofascore-events?sport=tennis&live=true" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

day = su.sofascore_events(sport="football", date="2026-11-01", timezone="Europe/London", max_results=20)
live = su.sofascore_events(sport="tennis", live=True)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const day = await su.sofascoreEvents({ sport: "football", date: "2026-11-01", timezone: "Europe/London", maxResults: 20 });
const live = await su.sofascoreEvents({ sport: "tennis", live: true });
```

```php PHP

```

| Field | Notes |

| `resultsCollected` / `hasMore` | Matches returned, and whether the day has more than `max_results`. |

A live list has the same match fields with `status.type` `inprogress`; call it again to follow the scores.

## Match

```
POST /sports/sofascore-match
```

| Field | Required | Notes |
| --- | --- | --- |
| `match` | yes | The match id (e.g. `16363907`, from the events or search results) or a sofascore.com match link. A link without `#id:` names the pairing; the match in progress, else the next, else the latest is used. |
| `include` | no | Sections to add, comma separated (the SDKs also take a list): `statistics`, `lineups`, `incidents`, `h2h`, `odds`, `momentum`, `pregame_form`, `votes`, `managers`, `best_players`, `shotmap`, `commentary`, `highlights`, or `all` / `none`. Default `statistics,lineups,incidents`. |

## Search

```
POST /sports/sofascore-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | A team, player, competition, match, manager, referee or venue name, at least 2 characters: `real madrid`, `sinner`, `premier league`, `arsenal chelsea`. |
| `sport` | no | Keep to one sport. |
| `type` | no | `all` (mixed, best match first), `teams`, `players`, `tournaments`, `matches`, `managers`, `referees` or `venues`. Default `all`. |
| `page` | no | 1-based results page to start from, `1`-`5`; the site serves 20 per page. Default `1`. |
| `max_results` | no | Results to collect across pages, `1`-`100`. Default `20`. |

## Player

```
POST /sports/sofascore-player
```

| Field | Required | Notes |
| --- | --- | --- |
| `player` | yes | An id (e.g. `12994`), a sofascore.com player link, or a name such as `Lionel Messi`. |
| `sport` | no | The sport, to resolve a name within it. |
| `include` | no | Sections to add, comma separated (the SDKs also take a list): `seasons`, `season_stats`, `last_matches`, `transfers`, `attributes`, `national_team`, or `all` / `none`. Default `season_stats,last_matches`. |

| `season` | no | For `season_stats`: a season id or its year as SofaScore writes it (`26/27`, `2026`). Default the latest. |

## Tournament

```
POST /sports/sofascore-tournament
```

| Field | Required | Notes |
| --- | --- | --- |
| `tournament` | yes | The competition: an id (e.g. `17`), a sofascore.com tournament link (its `#id:` picks the season), or a name such as `Premier League` or `NBA`. |
| `sport` | no | The sport, to resolve a name within it. |
| `season` | no | A season id or its year as SofaScore writes it (`26/27`, `2026`). Default the current one. |
| `include` | no | Sections to add, comma separated (the SDKs also take a list): `seasons`, `standings`, `rounds`, `last_matches`, `next_matches`, `top_players`, `top_teams`, or `all` / `none`. Default `standings,last_matches,next_matches`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. no `query` / `match` / `team` / `player` / `tournament`, an unknown `sport`, a day list for motorsport or cycling, both `country` and `tournament`, or `max_results` out of range. |
| `404` | No such match, team, player, competition or season, or an unknown `country` or `tournament` in the events filter. |
| `502` | SofaScore refused every attempt or did not answer in time. Retry. |

A section the site does not have for an entity is named in `unavailable`, not an error; a section whose read failed is named in `failedSections`.

## What you can build

- **Live score feeds** - follow every match in progress for a sport, with scores by period and the status, and refresh it on a timer.
- **Fixtures and results databases** - collect each day's matches across sports, countries and time zones.
- **Match analytics** - expected goals, shot maps, lineups with player ratings, momentum and incidents for scouting or betting models.
- **Odds tracking** - opening and current odds for every market of a match.
- **Player and team profiles** - squads with market values and contracts, season statistics, transfers and form.
- **League tables** - standings, top scorers and top teams for any competition and season.
