The **Tripadvisor Reviews** plugin returns the reviews of a hotel, restaurant or attraction as structured JSON. Give it the place's review page URL from any Tripadvisor site (Hotel_Review, Restaurant_Review, Attraction_Review or AttractionProductReview) or its bare location id, and it returns each review's title, full text, rating, published date and date of stay, trip type, language, helpful votes, the reviewer, sub-ratings, photos and the owner's response.

The place comes with them: name, type, overall rating, review count, the 1-5 star histogram, sub-ratings such as cleanliness or value, the ranking, address, coordinates, phone and website. Reviews come newest first, 10 per page (15 for restaurants), and one call collects up to 200. Pick the review language with `language`, stop at a date with `since`, and continue from `nextPage`. Each review page read is one billed unit (`pagesFetched`).

## Place reviews

```
POST /travel/tripadvisor-reviews
```

| Field | Required | Notes |
| --- | --- | --- |
| `url` | one of `url` / `location_id` | The place's review page on any Tripadvisor site, e.g. `https://www.tripadvisor.com/Hotel_Review-g60763-d93589-Reviews-The_Michelangelo_New_York-New_York_City_New_York.html`. |
| `location_id` | one of `url` / `location_id` | Tripadvisor location id - the digits after `-d` in a place URL, e.g. `93589`. |
| `max_reviews` | no | How many reviews to collect across pages, `1`-`200`. Default `20`. Each page is one billed unit. |
| `page` | no | 1-based review page to start from (10 reviews per page, 15 for restaurants), `1`-`500`. Default `1`. Pass a previous response's `nextPage` to continue. |
| `language` | no | Review language, which Tripadvisor ties to its site: `en`, `de`, `fr`, `it`, `es`, `pt`, `nl`, `ja`, `ko`, `ru`, `sv`, `tr`, `da`. Default: the language of the URL's site (tripadvisor.com is `en`), or the place's most-reviewed of these languages when that site lists none. |
| `since` | no | Only reviews published on or after this date (`YYYY-MM-DD`). Paging stops once older reviews start, so it also saves pages. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`, `DE`). Leave blank; pinning a country makes the call slower. |

### Review fields

| Field | Notes |
| --- | --- |
| `id` / `title` / `text` | Review id, title and the full review text. |
| `rating` | Star rating (1-5). |
| `publishedDate` / `travelDate` | When the review was published (`YYYY-MM-DD`) and the month of the visit (`YYYY-MM`). |
| `tripType` | The kind of trip the reviewer took, e.g. `couples`. |
| `language` / `isMachineTranslated` | Review language; reviews written in another language appear machine-translated, flagged here with their `originalLanguage`. |
| `helpfulVotes` | Helpful votes from other readers. |
| `user` | Reviewer display `name`, `location` and number of `contributions`. |
| `subratings` | The reviewer's per-aspect ratings, when given. |
| `photos` | Photos attached to the review, when there are any. |
| `ownerResponse` | The owner's reply: `text`, `publishedDate` and `authorRole`. `null` when there is none. |

### Place and paging

| Field | Notes |
| --- | --- |
| `place` | `name`, `type` (`hotel`, `restaurant`, `attraction`), `rating`, `reviewsCount`, the 1-5 `ratingHistogram`, `subratings`, `ranking`, `address`, `coordinates`, `phone` and `website`. |
| `totalResults` | Reviews in the chosen language. |
| `hasMore` / `nextPage` | Whether more reviews remain, and the page to pass as `page` to continue. |

## What you can build

- **Reputation monitoring** - poll a hotel or restaurant with `since` and alert on new low ratings.
- **Owner response tracking** - see which reviews get a reply, and from which role.
- **Competitive benchmarking** - compare ratings, histograms and sub-ratings across competing places in a city.
- **Review analytics at scale** - list places with [Tripadvisor Places](/plugins/tripadvisor), then read each one's reviews.
