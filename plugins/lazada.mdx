The **Lazada** plugin returns products from Lazada, Southeast Asia's marketplace, as structured JSON. It covers six markets - Singapore (`sg`), Malaysia (`my`), Thailand (`th`), the Philippines (`ph`), Vietnam (`vn`) and Indonesia (`id`) - picked with `country`. It is two endpoints:

- **`/marketplace/lazada-search`** - the products for a keyword, in Lazada's order: item and SKU id, name, price with the crossed-out price and discount, rating, review count, units sold, brand, seller, where it ships from, stock, the LazMall, free shipping and sponsored flags, image and link. Sort, filter by price and collect across pages.
- **`/marketplace/lazada-product`** - one product: title, brand, description, highlights, category path, price and discount, rating with its 1-5 star breakdown, stock and the maximum order quantity, images, the specification table, every variant (SKU, attributes, price, image, availability, link), the seller with its positive rating and store highlights, the delivery option and estimate, and the warranties.

Prices are in the market's currency (SGD, MYR, THB, PHP, VND or IDR). No Lazada account or API key is involved.

<Note>

## Search

```
POST /marketplace/lazada-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `iphone case` or `air fryer`. |
| `country` | no | Lazada market: `sg` (lazada.sg), `my` (lazada.com.my), `th` (lazada.co.th), `ph` (lazada.com.ph), `vn` (lazada.vn), `id` (lazada.co.id). Default `sg`. |
| `sort` | no | Result order: `relevance`, `price_asc`, `price_desc`. Default `relevance`. |
| `page` | no | First Lazada results page to read, `1`-`102`. Default `1`. |
| `min_price` / `max_price` | no | Price range in the market's currency. |
| `max_results` | no | Products to collect across pages, `1`-`400`. Default `40`. A page holds 40 products. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/lazada-search?query=yoga%20mat&country=sg&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.lazada_search("yoga mat", country="sg", max_results=3)
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.lazadaSearch("yoga mat", { country: "sg", maxResults: 3 });
```

```php PHP

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->lazadaSearch('yoga mat', ['country' => 'sg', 'max_results' => 3]);
```

</CodeGroup>

Each Lazada page read is billed as one request (`pagesFetched`).

| Field | Notes |

| `position` | Rank in Lazada's results. |
| `total` / `matches` / `nextPage` | Results Lazada lets you page through, all matches it reports, and the `page` to pass to continue. |

## Product

```
POST /marketplace/lazada-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `item_id` | one of `item_id` / `url` | Lazada item id - the number after `-i` in a product link, e.g. `13907853520`. Pair with `country`. |
| `url` | one of `item_id` / `url` | A Lazada product link, e.g. `https://www.lazada.sg/products/apple-iphone-18-pro-max-i13907853520-s124925162667.html`. Used instead of `item_id` and `country`. |
| `sku_id` | no | SKU id (the number after `-s`) to select one variant. |
| `country` | no | Lazada market of `item_id`: `sg`, `my`, `th`, `ph`, `vn` or `id`. Default `sg`. |

To look a product up by link, leave the first argument out and pass `url` (`su.lazada_product(url="https://www.lazada.sg/products/...")` in Python, `su.lazadaProduct(undefined, { url })` in Node.js). Each product is billed as one request.

| Field | Notes |

| `itemId` / `skuId` / `country` | The item, the SKU the top-level price is for, and the market. |

| `delivery` / `warranties` | The delivery option with its fee and the estimate, and the return and warranty terms. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, an unknown `country`, or neither `item_id` nor `url`. |
| `404` | Lazada found no products for this search, or has no active product with this id (or shows it in its mobile app only). |
| `502` | Lazada blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |
