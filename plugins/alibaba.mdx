The **Alibaba** plugin turns Alibaba.com wholesale listings into structured JSON. It is two endpoints:

- **`/marketplace/alibaba-search`** - a keyword search (any language): product id, title, URL, images, the USD price range with the price per quantity range (`priceTiers`), the minimum order (`moq`), sold count, rating, lead time, certifications and the supplier card - name, store and profile URL, country, years on Alibaba, Verified / Verified PRO / Gold Supplier flags, Trade Assurance and response rate.
- **`/marketplace/alibaba-product`** - one product by id or URL in full: categories, images, videos, price tiers in the local currency and in USD, SKU variants, attributes, lead time per quantity, packaging, ship-from, Trade Assurance and the supplier's location, business type, rating, response time and on-time delivery rate.

No Alibaba account, buyer login or API key is involved. For China's domestic wholesale marketplace, see the [1688 plugin](/plugins/1688).

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/alibaba-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | What to search, e.g. `bluetooth speaker` or `yoga mat`. Any language. |
| `page` | no | 1-based results page to start from, `1`-`100`. Default `1`. Pass the `nextPage` of a previous response to continue. |
| `max_results` | no | Products to collect across pages, `1`-`480`. Default `48`. Alibaba serves 48 per page and each page fetched is billed as one request (`pagesFetched`). |
| `sort` | no | `relevance` (default) or `sales` (most sold in the last 180 days first). |
| `verified` | no | `true` = only Verified (third-party inspected) suppliers. Default `false`. |
| `verified_pro` | no | `true` = only Verified PRO suppliers. Default `false`. |
| `trade_assurance` | no | `true` = only products covered by Trade Assurance. Default `false`. |
| `supplier_country` | no | Only suppliers located in this country (ISO-2), e.g. `CN`, `US`, `IN`. |
| `proxy_country` | no | Proxy country (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/alibaba-search?q=bluetooth%20speaker&trade_assurance=true&max_results=48" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.alibaba_search("bluetooth speaker", trade_assurance=True, max_results=48)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.alibabaSearch("bluetooth speaker", { tradeAssurance: true, maxResults: 48 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->alibabaSearch('bluetooth speaker', ['trade_assurance' => true, 'max_results' => 48]);
```



| Field | Notes |
| --- | --- |
| `productId` / `url` | Alibaba product id and the product page URL. Pass the id to [Product](#product) for the full listing. |
| `image` / `thumbnail` / `images` | Full-size main image, a 300x300 rendition of it, and the image list. |
| `priceText` / `priceMin` / `priceMax` / `currency` | Price range as Alibaba prints it and as numbers, in USD. |
| `priceTiers` | Price per quantity range: `minQuantity`, `maxQuantity` (`null` = and up), `price` and `promotionPrice`. Empty when the card shows only a range. |
| `promotionPriceText` / `promotionPriceMin` / `promotionPriceMax` / `discountText` | Promotion price and discount, when the product has one. |
| `moq` / `moqUnit` / `moqText` | Minimum order quantity and its unit. |
| `sold` / `soldText` | Units sold, when Alibaba shows it. |
| `rating` / `reviewsCount` | The supplier store's rating and review count shown on the card. |
| `leadTimeDays` | Lead time in days, when shown. |
| `category` / `certifications` / `sponsored` | Alibaba category, listed certifications, and whether the card is a paid placement. |
| `supplier` | `name`, `companyId`, store `url`, `profileUrl`, `country`, `yearsOnAlibaba`, `verified`, `verifiedPro`, `goldSupplier`, `tradeAssurance`, `responseRate` and `logo`. |

Paging fields: `nextPage` is the next Alibaba page not yet returned (pass it as `page` to continue) and `hasMore` says whether there is one. When `max_results` ends inside a page, the rest of that page is not returned (`droppedFromLastPage`), so ask in multiples of 48 to get every product.

## Product

```
POST /marketplace/alibaba-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | Numeric Alibaba product id, e.g. `1601840898248` (the number before `.html`). |
| `url` | one of `product_id` / `url` | Alibaba product URL, e.g. `https://www.alibaba.com/product-detail/..._1601840898248.html`. |
| `proxy_country` | no | Proxy country (ISO-2). Alibaba prices the product in that country's currency; USD figures are always included. Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/alibaba-product?product_id=1601840898248&proxy_country=NL" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.alibaba_product("1601840898248", proxy_country="NL")
```

```ts Node.js

```


A removed or unknown product, or one Alibaba does not show in the proxy country, returns `404` - try another `proxy_country`.

## What you can build

- **Supplier sourcing** - shortlist verified suppliers for a product with MOQ, lead time and response rate side by side.
- **Landed-cost models** - feed quantity price tiers in USD into your costing at the order size you plan.
- **Price benchmarking** - track wholesale price ranges for a product category over time.
- **Supplier vetting** - pull years on Alibaba, inspection body, ratings and on-time delivery for every candidate.
