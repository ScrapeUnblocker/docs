The **Google Ads Transparency** plugin returns an advertiser's Google ads from the [Google Ads Transparency Center](https://adstransparency.google.com) as structured JSON: Search, YouTube, Display, Shopping, Maps and Play ads, each with its creative id, format, when it was first and last shown, the preview image or preview script, Google's ids behind the creative and a link to the ad. It is two endpoints:

- **`/ads/google-ads-transparency`** - the ads of an advertiser (by name or advertiser id) or of a website (`domain`), filtered by region, platform, format and dates. `include_details` adds each ad's reach per region and the targeting the advertiser disclosed; `include_preview` adds what the ad shows: headline, description, display URL, product, images or YouTube video.
- **`/ads/google-ads-transparency-advertisers`** - look an advertiser up by name: matching advertisers with their id, country, ad-count range and verification, plus matching domains.

Google serves up to 100 ads per page; one call collects up to 1,000. Most Search text ads exist only as an image of the ad (`imageUrl`), so their headline and description cannot always be read: `include_preview` returns them when Google keeps a preview script for the ad, as for the ad below. No Google account or API key is involved. For Facebook and Instagram ads, see the [Meta Ad Library plugin](/plugins/meta-ad-library).

## Ads

```
POST /ads/google-ads-transparency
```

| Field | Required | Notes |
| --- | --- | --- |
| `advertiser` | one of `advertiser` / `domain` | A name (e.g. `Nike`), resolved to the best-matching advertiser and reported in `advertisersUsed`, or an advertiser id (`AR16735076323512287233`). Comma-separate up to 10. A single brand name no advertiser is named like falls back to its domain. |
| `domain` | one of `advertiser` / `domain` | The website the ads point to, e.g. `nike.com`: the ads of every advertiser for that domain. |
| `region` | no | Where the ads were shown: a 2-letter country code (`US`, `DE`), a comma list of them, or `anywhere` (default). |
| `platform` | no | Only ads shown on these platforms, comma list of `search`, `youtube`, `maps`, `play`, `shopping`. |
| `format` | no | Only one ad format: `text`, `image` or `video`. |
| `date_from` / `date_to` | no | Only ads shown on or after / on or before this date (`YYYY-MM-DD`). |
| `sort` | no | `last_shown` (default): the most recently shown ads first. |
| `max_results` | no | Ads to collect, `1`-`1000`. Default `100`. |
| `page_token` | no | The `nextPageToken` of a previous response, to continue where it stopped. |
| `include_details` | no | `true` adds `details` per ad: the regions where it was shown with first and last dates (plus impressions per platform for EU regions), the EU reach, the targeting the advertiser disclosed and every preview variation. For up to 300 ads per call. Default `false`. |
| `include_preview` | no | `true` adds `preview` per ad: the headline, description and display URL of a text ad, the product title and merchant of a Shopping ad, image URLs, or the YouTube video of a video ad. For up to 40 ads per call. Default `false`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/ads/google-ads-transparency?advertiser=Nike&region=US&max_results=3&include_details=true&include_preview=true" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

The SDK method takes no positional argument: pass `advertiser` or `domain` as an option.

<Note>
Billing: one request per page of up to 100 ads fetched, plus one per ad with `include_details` and one per preview fetched with `include_preview`. The call above returns 3 ads with both and counts as 7 requests (1 page, 3 details, 3 previews); `callUnits` in the response is the exact number. Resolving an advertiser name is free.
</Note>

## Advertiser lookup

```
POST /ads/google-ads-transparency-advertisers
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | Advertiser name or brand to look up, e.g. `nike`. |
| `region` | no | Count ads shown in these regions only: a 2-letter country code, a comma list, or `anywhere` (default). |
| `max_results` | no | Most advertisers (and domains) to return, `1`-`50`. Default `10`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/ads/google-ads-transparency-advertisers?q=nike&region=US&max_results=3" \

```

A lookup is billed as one request. A name matches every advertiser named like it, so pass the `advertiserId` of the one you mean to the ads endpoint.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. both or neither of `advertiser` and `domain`, more than 10 advertisers, or an unknown `platform` or `format`. The message says what to fix. |
| `404` | No advertiser matches the name, or no ads match the filters. |
| `502` | Blocked on every attempt, an unusable answer, or no answer in time. Retry. |

## What you can build

- **Competitor ad monitoring** - track which Google ads a competitor runs, in which format and region, and since when.
- **Creative research** - collect the headlines, descriptions, images and YouTube videos of a brand's ads.
- **Brand protection** - find who advertises on your domain or under a name like your brand's.
- **Market scoping** - see which advertisers are active in a region before you spend.
