The **App Store** plugin turns Apple App Store listings into structured JSON. It covers three things:

- **App details** - one app's title and subtitle, developer, price, rating with the star histogram, content and age rating, genres, release and update dates, the current version with release notes and the version history, size, minimum iOS version, languages, description, screenshots, privacy labels, top-chart rank and similar apps.
- **App search** - up to 200 apps matching a keyword.
- **Reviews** - customer reviews with title, text, rating, author, date, the app version reviewed and helpful votes, newest or most helpful first.

Pass the app as a numeric id (`310633997`), `id310633997`, an apps.apple.com URL or a bundle id (`net.whatsapp.WhatsApp`). Prices, ratings and reviews are per store country, picked with `country`. No Apple developer account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## App details

```
POST /apps/app-store
```

| Field | Required | Notes |
| --- | --- | --- |
| `app_id` | yes | Numeric App Store id (`310633997`), `id310633997`, an apps.apple.com app URL, or a bundle id (`net.whatsapp.WhatsApp`). |
| `mode` | - | Set to `app` by `appStoreApp`. |
| `country` | no | App Store country (ISO-2), e.g. `us`, `gb`, `de`. Default: the country in an app URL, else `us`. |
| `lang` | no | Listing language, e.g. `fr` or `fr-CA`, for countries whose store has several languages. Default: the store's own. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/apps/app-store?mode=app&app_id=310633997&country=us" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python

```

| `chartRank` | The app's `position` in its top chart and the `chart` name. |
| `similarApps` / `moreByDeveloper` | Apps the store lists as similar, and the developer's other apps. |

An app that does not exist in the chosen country returns `404`.

## App search

```
POST /apps/app-store
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | Search term, e.g. `vpn`. |
| `mode` | - | Set to `search` by `appStoreSearch`. |
| `country` | no | App Store country (ISO-2). Default `us`. |
| `lang` | no | Listing language, e.g. `fr` or `fr-CA`. Default: the store's own. |
| `max_results` | no | How many apps to return, `1`-`200`. Default `50`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/apps/app-store?mode=search&q=vpn&max_results=5" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python

```

## Reviews

```
POST /apps/app-store
```

| Field | Required | Notes |
| --- | --- | --- |
| `app_id` | yes | Numeric App Store id, `id310633997`, an apps.apple.com app URL, or a bundle id. |
| `mode` | - | Set to `reviews` by `appStoreReviews`. |
| `country` | no | App Store country (ISO-2). Reviews are per country. Default: the country in an app URL, else `us`. |
| `max_results` | no | How many reviews to collect, `1`-`500`. Default `50`. Apple serves 50 per page and at most 10 pages per country; each page is billed as one request. |
| `sort` | no | `mostrecent` (default) or `mosthelpful`. |
| `page` | no | Review page to start from, `1`-`10`. Pass the `nextPage` of a previous response to continue. Default `1`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/apps/app-store?mode=reviews&app_id=310633997&sort=mostrecent&max_results=50" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client
```

| Field | Notes |
| --- | --- |
| `id` | Apple's review id. Use it to skip reviews you already have when you continue. |
| `title` / `text` | Review headline and body. |
| `rating` | Star rating, `1`-`5`. |
| `author` / `authorUrl` | The reviewer's display name and their reviews page. |
| `date` | When the review was posted (ISO-8601 with offset). |
| `version` | The app version the review was written for. |
| `helpfulVotes` / `totalVotes` | "Helpful" votes and all votes on the review. |

`hasMore` and `nextPage` tell you where to continue. When the last page was only partly used, `nextPage` points at it again, so skip reviews whose `id` you already have.

## What you can build

- **Review monitoring** - pull the newest reviews per country and flag low ratings after each release.
- **Release tracking** - follow `version`, `releaseNotes` and `versionHistory` of competing apps.
- **Keyword and chart tracking** - record search positions and `chartRank` over time.
- **Privacy and compliance research** - compare the privacy labels apps declare across a category.
