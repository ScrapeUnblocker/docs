The **Bing** plugin turns Bing searches into structured JSON. It has two endpoints:

- **Web search** (`/search/bing`) - a keyword to the results page: organic results with position, title, URL, displayed URL, domain, description, site name, favicon, date, sitelinks, star rating and facts line, top and bottom ads in their own lists (advertiser, real landing URL, favicon, sitelinks), related searches with their links, Bing's AI summary, its spelling correction and the total result count. The response uses the same keys as Google results from [`/serpApi`](/guides/serp-scraping), so one pipeline reads both engines.
- **Image search** (`/images/bing-search`) - a keyword to image results: the full-resolution image URL on the publisher's site (not a Bing thumbnail), the source domain and page, title, site name, thumbnail, pixel dimensions and a Bing viewer link. The response has the same shape as the [Google Images plugin](/plugins/google-images).

Pick the market with `proxy_country`: it sets both Bing's market and the country the search is sent from, so you get the results and ads a searcher there sees. No Bing or Azure account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Web search

```
POST /search/bing
```

| Field | Required | Notes |
| --- | --- | --- |
| `keyword` | yes | Search terms, e.g. `project management software`. |
| `pages_to_check` | no | How many result pages to collect, `1`-`10` (about 10 results each). Default `1`. |
| `proxy_country` | no | Country to search from (ISO-2), e.g. `GB`. Sets the result market and the location the search is sent from, which decides the ads. Default `US`. |
| `language` | no | Interface language (ISO-639-1), e.g. `en`, `de`. Default `en`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/search/bing?keyword=project%20management%20software&proxy_country=GB&language=en" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.bing_search("project management software", proxy_country="GB", language="en")
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.bingSearch("project management software", { proxyCountry: "GB", language: "en" });
```
```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->bingSearch('project management software', ['proxy_country' => 'GB', 'language' => 'en']);
```
```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.bing_search("project management software", proxy_country: "GB", language: "en")
```
</CodeGroup>

<Note>
Each results page fetched is billed as one request: `pages_to_check=3` that returns three pages counts as 3 requests, and `pagesChecked` shows the exact number. Bing often fills page 1 with ads and its AI summary and leaves room for only a few organic results; when a one-page call gets fewer than 8, the organic results of page 2 are added at no extra charge (`pagesChecked` stays `1`).
</Note>

| Field | Notes |
| --- | --- |
| `organic` | Organic results in page order: `position`, `title`, `url`, `displayedUrl` (as Bing prints it), `domain`, `description` (the snippet, without the date chip), `source` (the site name Bing prints above the link), `favicon` (the site icon Bing shows: a URL, or a small `data:` image), `date` (the date Bing prints with the snippet), `sitelinks` (the extra links under the result: `title`, `url`, `description`), `rating` (`value`, `max`, `reviews`, `url` of the star line when Bing shows one, e.g. `{"value": 4.4, "max": 5.0, "reviews": null, "url": null}`), `richSnippet` (the facts row under the snippet as one line, e.g. `4.4/5 Category: Utilities Operating System: Web Application`) and `thumbnail`. Every key is always present: `[]` or `null` when Bing shows nothing for it. |
| `topAds` / `bottomAds` | Ads above and below the results, with the organic keys up to `description` plus `advertiser` (the name Bing shows), `favicon` and `sitelinks`. `url` and the sitelink URLs are the advertiser's landing pages, taken out of Bing's click tracker; `domain` is the advertiser's domain. Bing does not show ads on every query, so an empty list is a normal answer. |
| `relatedSearches` / `relatedSearchLinks` | Bing's related searches: as strings, and as `query` with the Bing search `url` for it. |
| `aiOverview` | Bing's AI-written summary at the top of the page, in the [`/serpApi` shape](/guides/serp-scraping#aioverview): `text`, `markdown` (`null` for Bing), `sources` (cited hostnames) and `references` (`title`, `url`, `source`, `domain`, `snippet`). `null` when Bing shows none. |
| `spellingCorrection` | `type` (`showing_results_for`, `including_results_for` or `did_you_mean`) and `query` when Bing corrected the query; otherwise `null`. |
| `totalResults` | Bing's "about N results" count, as Bing prints it. |
| `resultsCollected` | Ads plus organic results returned. `topAdsCount`, `bottomAdsCount` and `organicResultsCount` count each list. |
| `pagesChecked` / `hasMore` | Pages billed and whether Bing has more pages. |
| `country` / `language` | The market the search ran in. |

## Image search

```
POST /images/bing-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | Image search term, e.g. `golden gate bridge`. |
| `pages` | no | How many result pages to fetch, `1`-`10` (about 35 results each). Default `1`. |
| `max_results` | no | Cap on the number of results returned, `1`-`400`. Default: all results of the fetched pages. |
| `proxy_country` | no | Country to search from (ISO-2); sets the Bing market. Default `US`. |
| `language` | no | Interface language (ISO-639-1), e.g. `en`, `de`. Default `en`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/images/bing-search?q=golden%20gate%20bridge&max_results=5&proxy_country=US" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.bing_images("golden gate bridge", max_results=5, proxy_country="US")
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.bingImages("golden gate bridge", { maxResults: 5, proxyCountry: "US" });
```
```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->bingImages('golden gate bridge', ['max_results' => 5, 'proxy_country' => 'US']);
```
```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.bing_images("golden gate bridge", max_results: 5, proxy_country: "US")
```
</CodeGroup>

<Note>
Each results page fetched is billed as one request: `pages=3` counts as 3 requests, and `pagesFetched` shows the exact number. `max_results` only trims the list, it does not change the pages fetched.
</Note>


| Field | Notes |
| --- | --- |
| `imageUrl` | The full-resolution original image on the publisher's site, not a Bing thumbnail. |
| `sourceDomain` / `sourcePageUrl` | The site and the page that show the image. |
| `title` / `sourceName` | The result title and the site name Bing shows for it. |
| `thumbnailUrl` | A Bing-hosted thumbnail, for fast previews. |
| `width` / `height` | Original image dimensions in pixels. |
| `fileSize` | Kept for the same shape as the Google Images plugin. Bing does not show a file size, so it is always `null`. |
| `bingImagesUrl` | Bing's image viewer link for the result. |
| `pagesFetched` / `hasMore` | Pages fetched (the billed number) and whether Bing has more results. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a `proxy_country` that is not an ISO-2 code (or not available) or a `language` that is not an ISO-639-1 code. |
| `502` | Bing blocked the search, returned no results page, or the search did not finish in time. Retry. |

## What you can build

- **Rank tracking** - follow where your pages rank on Bing next to Google, with one parser for both.
- **Ad intelligence** - see which advertisers bid on your keywords in each country.
- **Keyword research** - collect related searches for content planning.
- **Image sourcing and monitoring** - find where an image or product photo appears, with the original file and the page that uses it.
