The **Lowe's** plugin returns products from Lowe's (lowes.com, US) as structured JSON. It is two endpoints:

- **`/marketplace/lowes-search`** - the products for a keyword, in Lowe's own order: product id, item and model number, brand, title, link and image, rating and review count, the price with the was-price, savings and sale end date when it is on promotion, the clearance flag, the price range for items with options, the price type, the units on hand for pickup at the store and the parcel, delivery and expedited delivery options, plus the sponsored and marketplace flags and the key specifications. 24 products per page; one call collects up to 72.
- **`/marketplace/lowes-product`** - one product: the same price and stock fields plus the UPC, description, bullet points, the full specification table, images, videos, documents (manuals, warning labels), category path, package dimensions and weight, and how many units the nearby stores have.

Lowe's prices and stock are per store, so every answer is for one store, named in `store`. Pick it with `store_id`, or with a `zip` code (the nearest Lowe's store); with neither, store 1845 (Chicago-Brickyard, IL) is used. No Lowe's account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/lowes-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search for, e.g. `cordless drill`, `garden hose` or `interior paint`. |
| `url` | one of `query` / `url` | Instead of `query`: a Lowe's search link, e.g. `https://www.lowes.com/search?searchTerm=garden+hose` (its offset and store are used). Give one of the two, not both. |
| `store_id` | no | Lowe's store number whose prices and stock to return, e.g. `1845`. Give this or `zip`, not both; with neither, store 1845 (Chicago-Brickyard, IL) is used. |
| `zip` | no | US ZIP code; the nearest Lowe's store is used, e.g. `60639`. |
| `free_delivery` | no | `true` keeps only items Lowe's delivers for free. Default `false`. |
| `page` | no | 1-based results page to start from, `1`-`30` (24 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`72`. Default `24`. Each page fetched is billed as one request (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/lowes-search?query=cordless%20drill&zip=30301&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

A broad keyword that Lowe's sends to a category landing page (for example `patio furniture`) is answered from the landing page's first category tile that names the keyword, and `category` names it (`null` for a plain search). A landing page without such a tile answers `404`: search a more specific term.

| Field | Notes |
| --- | --- |
| `store` | The store the prices and stock are for: `storeId`, `name`, `address`, `city`, `state`, `zip` and `phone`. |
| `productId` / `url` | Lowe's item id and product link. Pass either to [Product](#product). |
| `itemNumber` / `modelNumber` | Lowe's item number and the maker's model number. |
| `brand` / `title` / `image` | Brand, title and main image. |
| `rating` / `reviewCount` | Star rating and number of reviews. |
| `price` / `wasPrice` / `savings` / `savingsPercent` / `saleEnds` | The price at this store, and on a promotion the was-price, the saving and the date the sale ends. |
| `clearance` | `true` for clearance items. |
| `minPrice` / `maxPrice` | The price range of an item sold with options (size, color), else `null`. |
| `priceType` | Where the price comes from: `store` (this store's price), `network` (Lowe's online price) or `sos` (special order). |
| `availability` | `pickup` (`available`, the `quantity` on hand at the store and, when it has none, `nearbyStores` that do), `parcel`, `delivery` and `expeditedDelivery` (`available`, `quantity` and `leadTimeDays`). |
| `sponsored` / `marketplace` | Whether the listing is sponsored, and whether a marketplace seller sells it. |
| `bullets` / `specifications` | Key points and specifications (`name` / `value`) as the search shows them. |
| `category` | The category a landing-page keyword was answered from, else `null`. |
| `totalResults` / `lastPage` / `nextPage` / `hasMore` | Lowe's match count and page count; pass `nextPage` as `page` to continue. |

## Product

```
POST /marketplace/lowes-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | Lowe's item id, e.g. `5016412045` (the number at the end of a product link; the `productId` of a search result). |
| `url` | one of `product_id` / `url` | Instead of `product_id`: a Lowe's product link, e.g. `https://www.lowes.com/pd/CRAFTSMAN-20-volt-Max-Drill/5016412045`. Give one of the two, not both. |
| `store_id` | no | Lowe's store number whose prices and stock to return, e.g. `1845`. Give this or `zip`, not both; with neither, store 1845 is used. |
| `zip` | no | US ZIP code; the nearest Lowe's store is used. |

| `buyable` / `status` | Whether the item can be bought online, and Lowe's status for it (e.g. `ACTIVE`). |
| `store` | The store the prices and stock are for, as in search. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. no `query` or `url`, both `query` and `url`, both `store_id` and `zip`, a `zip` that is not a 5-digit US ZIP code, or `max_results` above `72`. |
| `404` | Lowe's found no products, sent the keyword to a category landing page without a tile naming it, has no such product, or has no such store (or none near `zip`). |
| `502` | Lowe's blocked every attempt, returned no results or product data, or the call did not finish in time. Retry. |

## What you can build

- **Store-level price tracking** - follow prices, promotions, sale end dates and clearance at the stores that matter to you.
- **Local stock checks** - see units on hand at a store and its nearby stores before sending a customer or a crew.
- **Price comparison** - compare Lowe's with other home improvement retailers by model number or UPC.
- **Catalog enrichment** - fill product records with specifications, images, documents and package dimensions.
