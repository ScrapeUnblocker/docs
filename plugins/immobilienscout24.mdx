The **ImmobilienScout24** plugin turns a search on Germany's largest property portal into structured JSON. Give it a German city, a state or an ImmobilienScout24 region path, choose rent or buy and apartment or house, and get the listings back: title, price with its type (cold rent, warm rent or purchase price), warm rent, living area, rooms, plot area, street, postcode, district and coordinates, construction year, energy efficiency class, the realtor, images and a clean listing URL.

Filter by price, rooms and living area, and collect up to 500 listings in one call. No ImmobilienScout24 account is needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Property search

```
POST /realestate/immobilienscout24
```

| Field | Required | Notes |
| --- | --- | --- |
| `location` | yes | German city (`Berlin`, `Muenchen`, `Köln`, `Frankfurt am Main`), a state (`Bayern`) or an ImmobilienScout24 region path such as `berlin/berlin/mitte` or `bayern/muenchen-kreis/unterschleissheim`. An unknown location returns `400`. |
| `channel` | no | `rent` (default) or `buy`. |
| `property_type` | no | `apartment` (default) or `house`. |
| `min_price` / `max_price` | no | Price range in EUR: cold rent per month, or purchase price with `channel=buy`. |
| `min_rooms` / `max_rooms` | no | Room range. Half rooms are allowed, e.g. `2.5`. |
| `min_area` / `max_area` | no | Living area range in m². |
| `max_results` | no | How many listings to collect across pages (20 per page). Default `20`, max `500`. |
| `page` | no | 1-based results page to start from. Default `1`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

| Field | Notes |
| --- | --- |
| `id` / `url` / `title` | Listing (expose) id, clean URL and title. |
| `propertyType` | ImmobilienScout24's type, e.g. `ApartmentRent`. |
| `price` / `currency` / `priceType` | Price in EUR and what it is: `rent_cold`, `rent_warm` or `purchase`. |
| `priceOnRequest` | `true` when the advertiser shows no price. |
| `warmRent` | Warm rent (rent including running costs), when shown. |
| `livingArea` / `rooms` / `plotArea` | Living area in m², rooms and plot area in m² (houses). |
| `address`, `street`, `postcode`, `city`, `district` | Address parts. |
| `coordinates` | `lat` / `lng`. |
| `image` / `images` | Main photo and the listing photos. |
| `realtor` / `privateOffer` | Advertiser name and whether it is a private offer. |
| `constructionYear` / `energyEfficiencyClass` | Year built and energy class. |
| `tags` | Feature tags such as `Balkon/Terrasse`, `Einbauküche` or `Aufzug`. |
| `isNew` / `publishedAt` | ImmobilienScout24's "new" flag and the publish time. |

The response also carries the resolved `regionPath`, `totalResults` (matches ImmobilienScout24 reports) and `truncated`, which is `true` when the call stopped paging early to stay within its time limit; continue from the next `page` to get the rest.

## What you can build

- **Rent indexes** - track cold and warm rent per m² by city and district.
- **Housing supply monitoring** - count new listings by region, rooms and price band with `isNew` and `publishedAt`.
- **Investment screening** - compare purchase prices, living area, construction year and energy class across cities.
- **Realtor analysis** - see which realtors list the most in a region.
