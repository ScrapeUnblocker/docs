The **Magazine Luiza** plugin returns products from Magazine Luiza (Magalu, magazineluiza.com.br), one of Brazil's largest retailers and marketplaces, as structured JSON. It is two endpoints:

- **`/marketplace/magazineluiza-search`** - the products for a keyword, in Magalu's order: product and offer id, title, brand and link, the price, the best price with its payment method (usually Pix), the list price and discount, installments, rating and review count, the seller, availability, the sponsored and "Magalu indica" flags, category and subcategory, badges, the image and the variation summary (e.g. colour and voltage). Magalu shows 40 products per page; one call collects up to 200.
- **`/marketplace/magazineluiza-product`** - one product in full: description and key selling points, prices and installments, the rating histogram and per-aspect ratings, the first page of reviews, the seller's card (legal name, city, seller since, score, total sales), the coupon, breadcrumbs, the technical sheet, every variation option with its own product id, images, videos and package dimensions.

Prices are in Brazilian reais (BRL). No Magalu account or API key is involved.

## Search

```
POST /marketplace/magazineluiza-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search, e.g. `geladeira`, `smart tv 55` or `air fryer`. |
| `url` | one of `query` / `url` | A Magazine Luiza search link instead of `query`, e.g. `https://www.magazineluiza.com.br/busca/geladeira/`. Its sort and page are used. |
| `sort` | no | `relevance`, `price_low`, `price_high`, `best_selling`, `rating`, `newest`, `fastest_delivery` or `price_with_shipping_low`. Default `relevance`. |
| `page` | no | 1-based results page to start from, `1`-`25`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`200`. Default `40`. Magalu serves 40 per page and **each page fetched is billed as one request** (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/magazineluiza-search?query=air%20fryer&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.magazineluiza_search("air fryer", max_results=3)
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```

| Field | Notes |
| --- | --- |
| `productId` / `offerId` / `url` | Magalu's product id, the offer id and the product link. Pass `productId` or `url` to [Product](#product). |
| `title` / `brand` / `image` | Name, brand and main image. |
| `price` | The regular price (what the installments add up to). |
| `bestPrice` / `bestPriceMethod` | The lowest price and how to get it, usually `no Pix` (paid by Pix). |
| `originalPrice` / `discountPercent` | The crossed-out list price and the discount, when shown. |
| `installments` | `count`, `amount` per installment, `total` and whether it is `interestFree`. |
| `rating` / `reviewCount` | Average rating and number of reviews. |
| `sellerId` / `sellerName` | The seller: Magalu itself (`magazineluiza`) or a marketplace seller. |
| `available` / `sponsored` / `magaluIndica` / `badges` | Stock, sponsored placement, the "Magalu indica" recommendation flag and other badges. |
| `category` / `subcategory` | Magalu's category and subcategory. |
| `variations` | Each variation dimension with its `name`, the `current` value and the number of `options`. |
| `position` | Rank in Magalu's results. |
| `totalResults` / `lastPage` / `hasMore` / `nextPage` | Magalu's match count as it reports it, its last page, whether more pages exist, and the page to pass as `page` to continue. |

## Product

```
POST /marketplace/magazineluiza-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | Magalu product id, e.g. `240354400` or `jc60hbaa6d` (the part after `/p/` in a product link). |
| `url` | one of `product_id` / `url` | A Magazine Luiza product link instead, e.g. `https://www.magazineluiza.com.br/notebook-acer-aspire-go/p/240354400/in/nota/`. Give `product_id` or `url`, not both. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `query` nor `url`, a `url` that is not a Magazine Luiza search or product link, or both `product_id` and `url`. |
| `404` | Search: Magalu found no products. Product: no such product. |
| `502` | Magalu blocked every attempt, returned no results page or product data, or the call did not finish in time. Retry, or ask for fewer pages. |
