The **idealo** plugin returns idealo's price comparison as structured JSON. It is two endpoints:

- **`/marketplace/idealo-search`** - the products for a keyword: whether the result is a price comparison of many shops (`product`) or a single shop offer idealo has not matched to a product (`offer`), product and offer ids, title, subtitle and key characteristics, link and image, the lowest price and unit price, the number of offers, the cheapest shop with its shipping cost, rating and review count, the average press test grade, energy class, bargain saving and best-seller rank. A page holds 60 products; one call collects up to 300.
- **`/marketplace/idealo-offers`** - one product's price comparison: the product (title, brand, images, lowest and highest price, offer count, rating, pros and cons, variants with their own price range) and its **offers**, cheapest first, each with the shop's own title, price, shipping cost, total price, delivery estimate, carriers, free returns, payment methods, the shop with its rating (and the marketplace seller, if any) and idealo's click-out link.

Pick the site with `country`: `de` (default), `at`, `uk` (idealo.co.uk), `fr`, `it` or `es`. Prices are in that site's currency. No idealo account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.

## Search

```
POST /marketplace/idealo-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `iphone 17` or `kaffeevollautomat`. |
| `country` | no | idealo site: `de`, `at`, `uk`, `fr`, `it`, `es`. Default `de`. |
| `sort` | no | `relevance` (default) or `price_asc` (cheapest first). |
| `page` | no | First idealo results page to read, `1`-`100`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`300`. Default `60`. A page holds 60 products; each page is billed as one request. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/idealo-search?query=kaffeevollautomat&country=de&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.idealo_search("kaffeevollautomat", country="de", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.idealoSearch("kaffeevollautomat", { country: "de", maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->idealoSearch('kaffeevollautomat', ['country' => 'de', 'max_results' => 3]);
```



| Field | Notes |
| --- | --- |
| `type` | `product` = a price comparison of many shops; `offer` = a single shop offer idealo has not matched to a product. |
| `productId` / `offerId` | idealo product id (pass it to [Offers](#offers)) and the offer id. |
| `title` / `subtitle` / `characteristics` | Product name, product type and key characteristics. |
| `url` / `image` | The product's price comparison (or the shop link of a single offer) and its image. |
| `lowestPrice` / `basePrice` | The lowest price and the unit price text, when idealo shows one. |
| `offerCount` / `usedOnly` | Number of offers, and whether only used offers exist. |
| `cheapestShop` | The shop with the lowest price: `id`, `name`, `shippingCost`, `delivery` and `freeReturnDays`. |
| `rating` / `reviewCount` | Stars (rounded to half a star by idealo) and number of reviews. |
| `testGrade` | Average press test grade, where `1` is best. |
| `energyClass` / `bargainSavingPercent` / `bestsellerRank` | Energy class, idealo's bargain saving and best-seller rank, when shown. |
| `categoryId` / `variantOf` | idealo's category id, and the parent product of a variant. |
| `total` / `productCount` / `lastPage` / `nextPage` | idealo's result and product counts and last page; pass `nextPage` as `page` to continue. |

## Offers

```
POST /marketplace/idealo-offers
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | idealo product id, e.g. `207643424` (the number in a price comparison link, or `productId` from search). |
| `url` | one of `product_id` / `url` | An idealo price comparison link, e.g. `https://www.idealo.de/preisvergleich/OffersOfProduct/207643424_-iphone-17-apple.html`. Its site sets the country. |
| `country` | no | idealo site, as in search. Default `de`. |
| `max_results` | no | Offers to collect, `1`-`200`. Default `20`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/idealo-offers?product_id=202691981" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.idealo_offers("202691981")
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.idealoOffers("202691981");
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

```


</CodeGroup>

The offers come in blocks of 20: the product and its first 20 offers are billed as one request, and each further block of 20 (`max_results` above 20) as one more. To look a product up by link, leave the first argument out and pass `url` (`su.idealo_offers(url="https://www.idealo.de/preisvergleich/...")` in Python, `su.idealoOffers(undefined, { url })` in Node.js).

| Field | Notes |
| --- | --- |
| `lowestPrice` / `highestPrice` / `offerCount` | The price range and the number of offers across shops. |
| `rating` / `reviewCount` / `pros` / `cons` | idealo's rating, review count and its summary of pros and cons. |
| `variants` | The product's variants: `productId`, `name`, `gtin`, their own price range, offer count and link. |
| `offers` | The offers, cheapest first: `offerKey`, the shop's own `title`, `price`, `shippingCost`, `totalPrice`, `delivery` (as idealo prints it), `carriers`, `freeReturns`, `paymentMethods`, the `shop` (`id`, `name`, `rating`, `ratingCount`, `marketplace` and the marketplace `seller`), `variantId` / `variantName`, idealo's click-out `url` and `position`. |
| `offersCollected` / `pagesFetched` | How many offers came back and how many blocks were read. |

Offers are the new-item offers idealo lists by default.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, an unsupported `country`, or no valid `product_id` or `url`. |
| `404` | idealo found nothing for the search, or has no product with this id. |
| `502` | idealo blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Price comparison** - see every shop's price, shipping and total for a product in one call.
- **Competitor monitoring** - track where your shop ranks among the offers and who undercuts you.
- **Market overview** - map a category's price ranges, offer counts, ratings and press test grades.
- **Cross-country pricing** - compare the same product across idealo's six sites.
