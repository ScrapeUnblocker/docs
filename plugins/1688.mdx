The **1688** plugin turns 1688.com - China's B2B wholesale marketplace, where factories and wholesalers sell in yuan and by quantity - into structured JSON. It is two endpoints:

- **`/marketplace/1688-search`** - a keyword search (Chinese or English): offer id, title, URL, images, the price in yuan with the quantity price ladder (`priceTiers`), units sold, repurchase rate, service and promotion tags, a sponsored flag and the supplier - company name, shop URL, years on 1688, province and city, factory and business inspection, super factory flag and trade-service scores.
- **`/marketplace/1688-product`** - one offer by id or link in full: status, brand, category, price ladder or per-SKU prices, prices before a promotion, unit, minimum order, stock, units sold, the SKU matrix with every SKU's price and stock, attributes, images, video, shipping origin and dispatch promise, service guarantees, the buyer rating summary and the supplier.

Text comes back in Chinese, as 1688 publishes it, and prices are in yuan (CNY). No 1688 account, login or API key is involved. For the international B2B site, see the [Alibaba plugin](/plugins/alibaba).

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/1688-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | What to search, in Chinese or English, e.g. `手机壳`, `连衣裙` or `bluetooth earphones`. Chinese keywords match the most offers. |
| `page` | no | 1-based results page to start from, `1`-`34`. Default `1`. Pass the `nextPage` of a previous response to continue. |
| `max_results` | no | Offers to collect across pages, `1`-`300`. Default `60`. 1688 serves 60 per page and each page fetched is billed as one request (`pagesFetched`). |
| `sort` | no | `relevance` (default), `sales` (most sold in the last 30 days first), `price_asc` or `price_desc`. |
| `price_min` / `price_max` | no | Only offers priced within this range, in yuan (CNY). |
| `province` | no | Only suppliers in this Chinese province, by its Chinese name, e.g. `广东` (Guangdong), `浙江` (Zhejiang), `江苏` (Jiangsu). |
| `proxy_country` | no | Proxy country (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/1688-search?q=%E6%89%8B%E6%9C%BA%E5%A3%B3&sort=sales&max_results=60" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```

```

| Field | Notes |
| --- | --- |
| `offerId` / `url` | 1688 offer id and the offer page URL. Pass the id to [Offer](#offer) for the full listing. |
| `title` / `image` / `images` | Offer title (Chinese) and images. |
| `price` / `currency` | Lowest listed price, in yuan (`CNY`). |
| `priceTiers` | The quantity price ladder: `quantityText`, `minQuantity`, `maxQuantity` (`null` = and up) and `price`. Empty when the card shows one price. |
| `sold` / `soldText` | Units sold as a number (the lower bound 1688 shows, e.g. `已售1.4万+件` -> `14000`) and the original text. |
| `repurchaseRatePercent` | Share of buyers who reorder, in percent. |
| `serviceTags` / `promotionTags` / `tags` | 1688's service badges, promotion labels and other card tags. |
| `brand` / `sponsored` | Brand when listed, and whether the card is a paid placement. |
| `supplier` | `name`, `loginId`, `memberId`, `shopUrl`, `yearsOnPlatform`, `province`, `city`, `factoryInspected`, `businessInspected`, `superFactory` and `tradeScores` (composite, consultation, logistics, disputes, returns, goods). |

Paging fields: `nextPage` is the next 1688 page not yet returned (pass it as `page` to continue) and `hasMore` says whether there is one. When `max_results` ends inside a page, the rest of that page is not returned (`droppedFromLastPage`), so ask in multiples of 60 to get every offer.

## Offer

```
POST /marketplace/1688-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `offer_id` | one of `offer_id` / `url` | Numeric 1688 offer id, e.g. `735353578254` (the number in `detail.1688.com/offer/<id>.html`). |
| `url` | one of `offer_id` / `url` | 1688 offer link, e.g. `https://detail.1688.com/offer/735353578254.html`. Mobile `m.1688.com` and `offerId=` links work too. |
| `proxy_country` | no | Proxy country (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/1688-product?offer_id=735353578254" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

## What you can build

- **Factory sourcing** - find manufacturers for a product with prices, MOQ and inspection flags.
- **Cost benchmarking** - compare 1688 yuan prices with Alibaba.com and retail prices for the same item.
- **SKU-level stock and price checks** - monitor every variant's stock and price for an offer you buy from.
- **Supplier scoring** - rank suppliers by repurchase rate, trade scores and years on 1688.
