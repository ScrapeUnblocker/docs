The **MediaMarkt** plugin returns products from MediaMarkt (and its Saturn and MediaWorld banners) as structured JSON. It is two endpoints:

- **`/marketplace/mediamarkt-search`** - the products for a keyword: product id, title, brand, EAN, link and image, breadcrumbs, the price with the crossed-out price and its kind (`RRP` = the manufacturer's recommended price, `LOP` = the lowest price of the last 30 days) and the discount, the installment offer, rating and review count, availability (online status, delivery, store pickup, delivery window and shipping cost), energy label, key features, badges, the refurbished price, the marketplace seller and the sponsored flag. MediaMarkt shows 12 products per page and 30 pages at most; one call collects up to 120.
- **`/marketplace/mediamarkt-product`** - one product: the same fields plus the rating breakdown, VAT rate, energy label and data sheet, every specification (group, name, value, unit), all images, the variants (colour, storage and so on, each with its own product id, price and online status), the description and the latest reviews.

Pick the shop with `country`: `de`, `at`, `ch`, `nl`, `be`, `es`, `it` (MediaWorld), `pl`, `hu` or `tr`. For **Saturn** (Germany) set `banner=saturn` with `country=de`. Where a shop has several languages (Belgium: `nl` or `fr`; Switzerland: `de`, `fr` or `it`), `language` picks one. Prices are in the shop's currency. No MediaMarkt account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/mediamarkt-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `iphone 17` or `waschmaschine`. |
| `country` | no | MediaMarkt shop: `de`, `at`, `ch`, `nl`, `be`, `es`, `it` (MediaWorld), `pl`, `hu`, `tr`. Default `de`. |
| `banner` | no | `mediamarkt` (default) or `saturn` (Saturn Germany, with `country=de` only). |
| `language` | no | Site language where the shop has several: `be` = `nl` or `fr`, `ch` = `de`, `fr` or `it`. Default: the shop's first. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `rating`, `bestseller`, `newest`. |
| `page` | no | First results page to read, `1`-`30`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`120`. Default `12`. A page holds 12 products; each page is billed as one request. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/mediamarkt-search?query=kaffeevollautomat&banner=saturn&sort=bestseller&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.mediamarkt_search("kaffeevollautomat", banner="saturn", sort="bestseller", max_results=3)
```

});
```

```

When MediaMarkt sends a keyword to a category or brand listing, the results come from that listing and `listingUrl` names it.

| Field | Notes |
| --- | --- |
| `productId` / `offerId` | MediaMarkt product number (pass it to [Product](#product)) and the offer id of a marketplace offer. |
| `title` / `brand` / `ean` / `url` / `image` / `breadcrumbs` | Product name, brand, EAN barcode, link, image and category path. |
| `price` / `currency` | The price, in the shop's currency. |
| `strikePrice` / `strikePriceType` / `discountPercent` | The crossed-out price and its kind (`RRP` = manufacturer's recommended price, `LOP` = lowest price of the last 30 days), and the discount. |
| `installment` | The financing offer: `months`, `monthly` amount and `interestRate`. |
| `marketplace` / `seller` | Whether a marketplace seller sells it, and that seller with its rating (`null` for MediaMarkt's own offers). |
| `rating` / `reviewCount` | Average rating and number of reviews. |
| `availability` | `online` status, `buyable`, `deliverable`, `storePickup` and `pickupStatus`, `releaseDate`, and `delivery` with its status, shipping cost and the earliest and latest delivery time. |

| `highlights` / `badges` | Key features and the promotion badges on the tile. |
| `refurbishedFrom` | The price and condition of a refurbished unit, when MediaMarkt offers one. |
| `sponsored` / `position` | Sponsored flag and rank in the results. |
| `total` / `lastPage` / `nextPage` | MediaMarkt's result count and last page; pass `nextPage` as `page` to continue. |
| `listingUrl` | The category or brand listing the keyword was sent to, when MediaMarkt sends it to one. |

## Product

```
POST /marketplace/mediamarkt-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | MediaMarkt product number, e.g. `3071615` (the number at the end of a product link, or `productId` from search). |
| `url` | one of `product_id` / `url` | A product link, e.g. `https://www.mediamarkt.de/de/product/_apple-iphone-18-pro-max-256gb-silver-3071615.html`. Its shop and language win over `country`, `banner` and `language`. |
| `country` | no | MediaMarkt shop, as in search. Default `de`. |
| `banner` | no | `mediamarkt` (default) or `saturn` (with `country=de`). |
| `language` | no | Site language where the shop has several, as in search. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/mediamarkt-product?product_id=3071615&country=de" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python

```

To look a product up by link, leave the first argument out and pass `url` (`su.mediamarkt_product(url="https://www.mediamarkt.de/de/product/...")` in Python, `su.mediamarktProduct(undefined, { url })` in Node.js). Each product is billed as one request.

The other fields are as in search. Store-level stock needs a chosen store and is not included.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query`, a `country` that is not a MediaMarkt shop, `banner=saturn` outside Germany, or a `product_id` that is not a product number. |
| `404` | MediaMarkt found nothing for the search, or the shop has no product with this number. |
| `502` | MediaMarkt blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Price monitoring** - track MediaMarkt and Saturn prices, discounts and the reference price they are measured against.
- **Cross-country comparison** - compare the same product across MediaMarkt's ten countries.
- **Availability tracking** - watch online status, delivery windows and store pickup for launches and best sellers.
- **Assortment research** - map brands, specifications and energy classes per category.
