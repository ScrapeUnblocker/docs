The **Yahoo** plugin turns Yahoo searches into structured JSON. It has two endpoints:

- **Web search** (`/search/yahoo`) - a keyword to the results page: organic results with position, title, URL, displayed URL, domain and description, top and bottom ads in their own lists, and related searches. Organic links come back as the destination URL, not Yahoo's `r.search.yahoo.com` redirect. The response has the same shape as Google results from [`/serpApi`](/guides/serp-scraping).
- **Image search** (`/images/yahoo-search`) - a keyword to image results: the full-resolution image URL on the publisher's site (not a thumbnail), the source domain and page, title, site name, thumbnail, pixel dimensions and a Yahoo viewer link. The response has the same shape as the [Google Images plugin](/plugins/google-images).

`proxy_country` picks Yahoo's regional site (for example `de.search.yahoo.com` for `DE` or `uk.search.yahoo.com` for `GB`) and the country the search is sent from, so you get the results and ads a searcher there sees. A country without a regional site uses `search.yahoo.com`. No Yahoo account is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Web search

```
POST /search/yahoo
```

| Field | Required | Notes |
| --- | --- | --- |
| `keyword` | yes | Search terms, e.g. `project management software`. |
| `pages_to_check` | no | How many result pages to collect, `1`-`10`. Default `1`. Yahoo shows about 7 organic results per page. |
| `proxy_country` | no | Country to search from (ISO-2), e.g. `US`, `DE`. Picks Yahoo's regional site and the location the search is sent from, which decides the ads. Default `US`. |
| `language` | no | ISO-639-1 code, e.g. `de`. When set, Yahoo returns only results in that language; without it the regional site's default applies. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/search/yahoo?keyword=project%20management%20software&proxy_country=US" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

```
```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```


</CodeGroup>

<Note>
Each results page fetched is billed as one request: `pages_to_check=3` that returns three pages counts as 3 requests, and `pagesChecked` shows the exact number.
</Note>

```json
      "position": 1,
      "title": "10 Best Project Management Software of 2026 - Forbes Advisor",
      "url": "https://www.forbes.com/advisor/business/software/best-project-management-software/",
      "displayedUrl": "https://www.forbes.com › advisor › business",
      "domain": "forbes.com",
      "description": "Sep 25, 2026 · To find the best project management software, we evaluated 26 platforms and scored 61 metrics."
    },
    {

      "domain": "pcmag.com",
      "description": "Jul 16, 2026 · Have a major deliverable coming up that involves lots of people and tasks? The top project management apps..."
    }
  ],
  "relatedSearches": [
    "construction project management software",
    "microsoft project management software",
    "free project management software"
  ],
  "pagesChecked": 1,
  "hasMore": true
}
```

| Field | Notes |
| --- | --- |
| `organic` | Organic results in page order: `position`, `title`, `url` (the destination, decoded from Yahoo's redirect link), `displayedUrl`, `domain` and `description` (the snippet). |
| `topAds` / `bottomAds` | Ads above and below the results, with the same fields; `domain` is the advertiser's domain. Yahoo does not show ads on every query, so an empty list (as above) is a normal answer. |
| `relatedSearches` | Yahoo's related searches. |
| `totalResults` | Always `null`. Kept for the same shape as `/serpApi`. |
| `resultsCollected` | Ads plus organic results returned. `topAdsCount`, `bottomAdsCount` and `organicResultsCount` count each list. |
| `pagesChecked` / `hasMore` | Pages fetched (the billed number) and whether Yahoo has more pages. |

## Image search

```
POST /images/yahoo-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | Image search term, e.g. `golden gate bridge`. |
| `pages` | no | How many result pages to fetch, `1`-`10` (about 60 results each). Default `1`. |
| `max_results` | no | Cap on the number of results returned, `1`-`600`. Default: all results of the fetched pages. |
| `proxy_country` | no | Country to search from (ISO-2); picks Yahoo's regional image site (e.g. `de.images.search.yahoo.com` for `DE`). Default `US`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/images/yahoo-search?q=golden%20gate%20bridge&max_results=5&proxy_country=US" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

```

| Field | Notes |
| --- | --- |
| `imageUrl` | The full-resolution original image on the publisher's site, not a thumbnail. |
| `sourceDomain` / `sourcePageUrl` | The site and the page that show the image. |
| `title` / `sourceName` | The result title and the site Yahoo shows for it. |
| `thumbnailUrl` | The thumbnail Yahoo shows in its grid, for fast previews. |
| `width` / `height` | Original image dimensions in pixels. |
| `fileSize` | Kept for the same shape as the Google Images plugin. Always `null` for Yahoo. |
| `yahooImagesUrl` | Yahoo's image viewer link for the result. |
| `pagesFetched` / `hasMore` | Pages fetched (the billed number) and whether Yahoo has more results. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a `proxy_country` that is not an ISO-2 code (or not available) or a `language` that is not an ISO-639-1 code. |
| `502` | Yahoo blocked the search, returned no results page, or the search did not finish in time. Retry. |

## What you can build

- **Rank tracking** - follow where your pages rank on Yahoo's regional sites next to Google, with one parser for both.
- **Ad intelligence** - see which advertisers show on your keywords in each country.
- **Keyword research** - collect related searches for content planning.
- **Image sourcing and monitoring** - find where an image appears, with the original file and the page that uses it.
