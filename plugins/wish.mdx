The **Wish** plugin returns products from Wish (wish.com) as structured JSON. It is two endpoints:

- **`/marketplace/wish-search`** - the products for a keyword, in Wish's own order: id, name, link and image, the price with its currency and any crossed-out price, the same price in USD, shipping cost, rating and rating count, units bought, stock, the number of colors and sizes, the merchant with its rating and feedback share, and where the product comes from. Wish shows up to 30 products per page; one call collects up to 300.
- **`/marketplace/wish-product`** - one product: description, attributes, badges, images, every variant (color, size, price, shipping, stock), the merchant's rating and tier, where it ships from and to, the delivery estimate, the return policy and the top reviews (rating, comment, date, variant, upvotes and country, without reviewer names).

Wish prices its store for the visitor's country. The default is the US store in USD; `proxy_country` reads another country's store (`GB`, `DE`, ...) with its catalogue, prices and currency, and `priceUsd` keeps prices comparable across stores. No Wish account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/wish-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search for, e.g. `yoga mat` or `phone case`, or a `wish.com/search/...` link. |
| `page` | no | 1-based results page to start from, `1`-`300`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`300`. Default `30`. Each page fetched is billed as one request (`pagesFetched`). |
| `proxy_country` | no | Country of the Wish store to read (ISO-2, e.g. `US`, `GB`, `DE`): its catalogue, prices and currency. Default `US` (prices in USD). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/wish-search?query=yoga%20mat&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.wish_search("yoga mat", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.wishSearch("yoga mat", { maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->wishSearch('yoga mat', ['max_results' => 3]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.wish_search("yoga mat", max_results: 3)
```
</CodeGroup>

A search with no matches is a `200` with an empty `products` list.

| Field | Notes |
| --- | --- |
| `id` / `url` | Wish product id and link. Pass either to [Product](#product). |
| `name` / `image` / `thumbnail` | Name and images. |
| `price` / `currency` / `priceText` | The price shoppers see in this store, its currency and the price as Wish prints it. |
| `originalPrice` | The crossed-out price, when the product is discounted. |
| `priceUsd` | Wish's USD value of the price, comparable across stores. |
| `shipping` | Shipping cost, in the same currency. |
| `rating` / `ratingCount` | Product rating and how many ratings it has (`null` and `0` for an unrated product). |
| `numBought` / `inventory` | Units bought and stock, as Wish reports them. |
| `colors` / `sizes` | Number of color and size options. |
| `merchant` | `id`, `name`, `rating`, `ratingCount`, the `feedback` text and the merchant's `country`. |
| `originCountry` / `shipsFrom` | Where the product comes from and ships from, when Wish says. |
| `tileText` / `isWishPick` | Wish's label on the product tile, and the Wish Pick flag. |
| `position` | Rank in Wish's results. |
| `totalResults` / `totalPages` / `nextPage` | Wish's result count and page count; pass `nextPage` as `page` to continue. |

## Product

```
POST /marketplace/wish-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product` | yes | A Wish product id (`5f96ad46b3f6480c7b9d7b52`) or a product link (`https://www.wish.com/product/...` or `/c/...`). |
| `proxy_country` | no | Country of the Wish store to read, as in search. Default `US`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `query` or a `page` above `300`. |
| `404` | Wish has no such product. |
| `502` | Wish blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Price and shipping comparison** - compare Wish prices, shipping costs and delivery estimates with other marketplaces.
- **Cross-country pricing** - read the same product in several country stores with `proxy_country` and compare them by `priceUsd`.
- **Merchant research** - rank merchants by rating, feedback and tier.
- **Product research** - spot what sells by units bought and reviews.
