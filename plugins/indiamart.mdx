The **IndiaMART** plugin returns B2B product data from IndiaMART (indiamart.com, India's largest B2B marketplace) as structured JSON. It is two endpoints:

- **`/marketplace/indiamart-search`** - the products for a keyword: product id, title and link, the price with its unit (price per kg, per piece...) and the price as IndiaMART prints it, minimum order quantity, category, specifications, description, image and brochure link, and the supplier (name, city, state, business type, verified-exporter, TrustSEAL, GST and IEC flags, rating, membership age, export markets and website), plus the supplier's other matching products.
- **`/marketplace/indiamart-product`** - one product: the same fields plus the full image gallery, category path, delivery time, packaging, production capacity, port of dispatch and payment terms where the supplier gives them, and the supplier's company profile (year established, employees, annual turnover, legal status, verification flags, rating and top export countries).

<Note>
**What signed-out visitors see.** IndiaMART shows signed-out visitors its export catalogue: verified exporters, 10 products a page and 2 pages per search, so a search returns **at most 20 products**. `totalResults` is IndiaMART's own count of all matches. The plugin **never returns supplier phone numbers, e-mail addresses, contact names or street addresses**, only the company-level details above. No IndiaMART account is involved.
</Note>

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/indiamart-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search for, e.g. `steel pipe`, `cotton t shirt` or `solar panel`. |
| `url` | one of `query` / `url` | Instead of `query`: an IndiaMART search link, e.g. `https://dir.indiamart.com/search.mp?ss=steel+pipe` (its keyword is used). |
| `page` | no | 1-based results page to start from, `1`-`2` (10 products a page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`20`. Default `20`. Each page read is billed as one request (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/indiamart-search?query=steel%20pipe&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.indiamart_search("steel pipe", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.indiamartSearch("steel pipe", { maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->indiamartSearch('steel pipe', ['max_results' => 3]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.indiamart_search("steel pipe", max_results: 3)
```
</CodeGroup>

To search with a link instead, leave the first argument out and pass `url` (`su.indiamart_search(url="https://dir.indiamart.com/search.mp?ss=steel+pipe")` in Python, `su.indiamartSearch(undefined, { url })` in Node.js).

## Product

```
POST /marketplace/indiamart-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `product_id` | one of `product_id` / `url` | IndiaMART product id, e.g. `2854548650133` (the number at the end of a `/proddetail/` link; search results give it as `productId`). |
| `url` | one of `product_id` / `url` | Instead of `product_id`: an IndiaMART product link, e.g. `https://www.indiamart.com/proddetail/stainless-steel-347h-pipes-2854548650133.html`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `query` nor `url`, both `product_id` and `url`, a non-numeric `product_id`, a `page` above `2` or a `max_results` above `20`. |
| `404` | IndiaMART found no products for the search, or has no such product. |
| `502` | IndiaMART blocked every attempt, gave an unusable answer, or did not answer in time. Retry. |

## What you can build

- **Supplier sourcing** - shortlist verified Indian exporters for a product by price per unit, minimum order, rating and certifications.
- **B2B price benchmarks** - track the per-unit prices suppliers quote for a commodity (steel, textiles, chemicals) over time.
- **Supplier vetting** - compare company size, turnover band, years in business, GST and TrustSEAL status before reaching out through IndiaMART.
- **Export market research** - see which countries an industry's suppliers sell to.
