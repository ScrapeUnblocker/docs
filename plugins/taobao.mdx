The **Taobao & Tmall** plugin returns listings from Taobao and Tmall, Alibaba Group's consumer marketplaces in China, as structured JSON. It is two endpoints:

- **`/marketplace/taobao-search`** - the products Taobao lists for a keyword (Chinese or English) or a category: item id and catalogue key, title, link, catalogue link and image, the price in yuan with Taobao's price tag (such as a discount price) and the same price in local currencies, the shop and its description score, free shipping, category ids, selling points and review highlights, plus Taobao's count of matching listings and the brand and property filters you can apply next.
- **`/marketplace/taobao-product`** - one Taobao or Tmall item, by the catalogue key a search returns: the platform, title, price, original price and price range in yuan, image, ship-from location, category path, free shipping, payment methods, the buyer rating split (Taobao items only), the latest review (stars, text, date and variant, no reviewer identity) and the shop with its seller type, credit level, opening date, item count and description, service and delivery scores.

The plugin reads the public catalogue Taobao publishes for signed-out visitors, so no Taobao login is involved, and what Taobao shows only after a login is not included: SKUs (variants), stock and monthly sales. Taobao shows signed-out visitors the first 20 products of a list, so one search returns up to 20; narrow it with a price range or a filter to reach other products. Text comes back in Chinese, as sellers write it, and prices are in yuan (CNY). For wholesale prices, see the [1688 plugin](/plugins/1688).

## Search

```
POST /marketplace/taobao-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | one of `q` / `category` | Keyword, in Chinese or English, e.g. `手机壳`, `连衣裙` or `phone case`. Chinese keywords match far more listings. A Taobao search or list link works too. |
| `category` | one of `q` / `category` | A Taobao category id, e.g. `50005050`, or a category list link (`https://www.taobao.com/list/category/50005050.htm`). Returns the category's best sellers; sort and filters apply to keyword searches only. |
| `sort` | no | `relevance` (default), `sales`, `price_asc` or `price_desc`. |
| `price_min` / `price_max` | no | Only products priced within this range, in yuan (CNY). Products whose listed price falls outside it are left out and counted in `droppedOutsidePriceRange`. |
| `filter` | no | One brand or property filter: the `filter` value of an option in `filterOptions` of an earlier answer, e.g. `20000-88634403`. |

To list a category, leave the keyword out and pass `category`, e.g. `su.taobao_search(category="50005050")` in Python. Each call that returns products is billed as one request; `404` and `502` are not billed.

When Taobao has no public list for a keyword, the call answers with the list of the closest keyword Taobao itself suggests and says so: `keywordSubstituted` is `true` and `matchedKeyword` is the keyword whose products you got. Check it before you treat the products as matches for your keyword.

| Field | Notes |
| --- | --- |
| `matchedKeyword` / `keywordSubstituted` | The keyword whose list was returned, and `true` when it is Taobao's suggestion instead of `q`. |

| `products[].title` / `image` | Title (Chinese) and image. |

| `products[].localPrices` | The same price in the storefront's currencies (`SGD`, `HKD`, `TWD`). |
| `products[].shopId` / `shopName` / `descriptionMatchScore` | The shop and its score for how well items match their descriptions. |
| `products[].freeShipping` / `categoryId` / `rootCategoryId` | Free shipping flag and category ids. |
| `products[].sellingPoints` / `reviewHighlights` | The selling points and review highlights Taobao shows on the card. |
| `filterOptions` | Brand and property facets: `name`, `propertyId` and `options` with `name`, `filter` and, for some, a `count`. Pass an option's `filter` back as `filter`. |
| `droppedOutsidePriceRange` | With a price range: how many products were left out because their listed price fell outside it. |
| `source` / `localCurrency` | Which Taobao catalogue answered, and its local currency. |

## Item

```
POST /marketplace/taobao-product
```

Taobao's public catalogue opens an item page only by the item's catalogue key, an opaque string such as `M3hoaXBUL3N4L2VnVUJncG9JWFphZz09` (item 765833709683) that only Taobao's own pages carry. Take it from `itemKey` in a [search](#search) result; a numeric item id is tried once, but it usually answers `404` (not billed) with a message asking for the `itemKey`.

| Field | Required | Notes |
| --- | --- | --- |
| `item_id` | one of `item_id` / `url` | The item's catalogue key, e.g. `M3hoaXBUL3N4L2VnVUJncG9JWFphZz09`: `itemKey` from a [search](#search). A numeric Taobao or Tmall item id (the `id` in `item.taobao.com/item.htm?id=...`) is tried as given, but usually answers `404`. |
| `url` | one of `item_id` / `url` | The item's catalogue link, e.g. `https://www.taobao.com/list/item/M3hoaXBUL3N4L2VnVUJncG9JWFphZz09.htm` (`catalogueUrl` from a search) or `https://world.taobao.com/item/M3hoaXBUL3N4L2VnVUJncG9JWFphZz09.htm`. An `item.taobao.com` or `detail.tmall.com` link is taken by its numeric id, like a numeric `item_id`. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `q` nor `category`, an unknown `sort`, or a missing `item_id` / `url`. |
| `404` | Taobao has no public list for the keyword (nor for any keyword it suggests instead), the category or the filters, or no public page for the item (removed, not shown to signed-out visitors, or asked for by a numeric id the catalogue does not open: pass its `itemKey`). Not billed. |
| `502` | Taobao refused every attempt, or did not answer in time. Not billed; retry. |

## What you can build

- **Cross-border sourcing** - find consumer products and shops on Taobao and Tmall with yuan prices.
