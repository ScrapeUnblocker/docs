The **DuckDuckGo** plugin turns a DuckDuckGo search into structured JSON. Give it a keyword and it returns organic results with position, title, URL, displayed URL, domain and description, the first page's ads in top and bottom lists, and related searches. Collect up to 10 pages in one call.

The response has the same shape as Google results from [`/serpApi`](/guides/serp-scraping), so code written for Google results reads DuckDuckGo results by changing the path only. Pick the region with `proxy_country`: it sets DuckDuckGo's region and the country the search is sent from.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Web search

```
POST /search/duckduckgo
```

| Field | Required | Notes |
| --- | --- | --- |
| `keyword` | yes | Search terms, e.g. `project management software`. |
| `pages_to_check` | no | How many result pages to collect, `1`-`10` (about 10 results each). Default `1`. Ads come from the first page; further pages add organic results. |
| `proxy_country` | no | Country to search from (ISO-2), e.g. `US`, `DE`. Sets the result region and the location the search is sent from, which decides the ads. Default `US`. |
| `language` | no | Interface language (ISO-639-1), e.g. `en`, `de`. Default `en`. |

<Note>
Each results page fetched is billed as one request: `pages_to_check=3` that returns three pages counts as 3 requests, and `pagesChecked` shows the exact number.
</Note>

```json
  ],
  "pagesChecked": 1,

```

| Field | Notes |
| --- | --- |
| `organic` | Organic results in page order: `position`, `title`, `url`, `displayedUrl` (as DuckDuckGo prints it), `domain` and `description` (the snippet). |
| `topAds` / `bottomAds` | Ads above and below the results on the first page, with the same fields. `domain` is the advertiser's domain. DuckDuckGo does not show ads on every query, so an empty list is a normal answer. |
| `relatedSearches` | DuckDuckGo's related searches. |
| `totalResults` | Always `null` - DuckDuckGo shows no result count. Kept for the same shape as `/serpApi`. |
| `resultsCollected` | Ads plus organic results returned. `topAdsCount`, `bottomAdsCount` and `organicResultsCount` count each list. |
| `pagesChecked` / `hasMore` | Pages fetched (the billed number) and whether more results are available. |
| `country` / `language` | The region and language the search ran in. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a `proxy_country` that is not an ISO-2 code (or not available) or a `language` that is not an ISO-639-1 code. |
| `502` | DuckDuckGo blocked the search, returned no results page, or the search did not finish in time. Retry. |

## What you can build

- **Keyword research** - collect related searches for content planning.
- **Privacy-focused audience research** - see what DuckDuckGo users find for your brand and products.
