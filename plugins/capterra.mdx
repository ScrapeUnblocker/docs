The **Capterra** plugin turns a Capterra product and its reviews into structured JSON. Give it a product - its numeric id such as `135003`, `id/slug` such as `135003/Slack`, or a capterra.com product URL - and it returns the product (name, vendor, overall rating, review count, the four sub-ratings, categories, description and pricing with its plans) plus the reviews: title, overall and sub-ratings, likelihood to recommend, date, the reviewer's job title, industry, company size and time using the product, comments, pros, cons, reasons for choosing or switching, the incentive and source badges, and the vendor's response.

Reviews come in Capterra's "Most Helpful" order, 25 to a page; one call collects up to 500. The same endpoint also searches Capterra's product catalog by keyword.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Product reviews

```
POST /reviews/capterra
```

| Field | Required | Notes |
| --- | --- | --- |
| `product` | yes | Capterra product: numeric id (`135003`), `id/slug` (`135003/Slack`) or a capterra.com product URL such as `https://www.capterra.com/p/135003/Slack/reviews/`. |
| `mode` | - | Set to `reviews` by `capterraReviews`. |
| `slug` | no | Product slug to go with a bare id, e.g. `Slack`. Capterra finds the product by id alone; the canonical slug is returned. |
| `page` | no | 1-based review page to start from: 25 reviews per page, at most 100 pages per product. Pass the `nextPage` of a previous response to continue. Default `1`. |
| `max_results` | no | How many reviews to collect across pages, `1`-`500`. Default `25`. Each page fetched is one billed unit. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank for the country chosen for the site. |

<Tip>
Pass `id/slug` (such as `135003/Slack`) rather than a bare id when you start past page 1. With a bare id, Capterra first redirects to the canonical slug, which costs one extra fetch.
</Tip>

<CodeGroup>

The `product` carries the overall `rating`, `reviewCount`, the sub-`ratings` (`easeOfUse`, `customerSupport` - Capterra's "Customer Service" rating - `features` and `valueForMoney`), `categories`, `description`, `targetMarket` and `pricing` with its `plans`. `hasMore` and `nextPage` tell you where to continue; `viewLimitReached` is `true` at Capterra's 100-page limit. A product with only a few reviews has no review pages, so its reviews come from its profile in one page. A product without reviews answers `200` with an empty `reviews` list, and an unknown id returns `404`.

### Review fields

| Field | Notes |
| --- | --- |
| `id` / `url` | Capterra's review id and a link to it. |
| `title` / `rating` / `date` | Review headline, overall rating (out of 5) and date. |
| `ratings` | The sub-ratings plus `likelihoodToRecommend` (`0`-`10`). |
| `reviewer` | `name` (as Capterra shows it, e.g. first name and initial), job `title`, `industry`, `companySize`, `timeUsedProduct` and how the reviewer was validated (`validated`, `validations`). |
| `comments` / `pros` / `cons` / `advice` | The overall comments and the reviewer's pros, cons and advice. `answers` lists every question and answer; `text` joins them. |
| `reasonsForChoosing` / `reasonsForSwitching` | Why the reviewer picked the product, or switched to it, with `alternativesConsidered` and `switchedFrom`. |
| `incentive` / `incentivized` / `vendorReferred` / `reviewSource` | Capterra's incentive and source badges. |
| `source` | The site the review was collected on: Capterra, GetApp or Software Advice. |
| `vendorResponse` | The vendor's reply, or `null`. |

## Catalog search

```
POST /reviews/capterra
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | Product name or keyword to search for, e.g. `crm` or `project management`. |
| `mode` | - | Set to `search` by `capterraSearch`. |
| `max_results` | no | How many products to return, `1`-`20`. Default `20`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank for the country chosen for the site. |

| Field | Notes |
| --- | --- |
| `id` / `slug` | Pass them as `id/slug` to `capterraReviews` to fetch the product's reviews. |
| `name` / `position` | Product name and its rank in Capterra's search results. |

| `description` / `logo` | Short product description and logo URL. |
| `url` / `reviewsUrl` | The product page and its reviews page. |
| `categories` | Capterra categories that match the keyword, with their pages. |

## What you can build

- **Review monitoring** - collect new reviews for your product and competitors and track the sub-ratings.
- **Switching analysis** - mine `reasonsForSwitching` and `switchedFrom` to see which tools buyers leave and why.
- **Pricing research** - compare `pricing` plans, free trials and free versions across a category.
- **Buyer persona insight** - break ratings down by reviewer industry, company size and time using the product.
