The **Redfin** plugin turns Redfin into structured JSON. One endpoint, `/realestate/redfin`, works in two modes:

- **Search** (`mode=search`) - give it a ZIP or a city and state and get the listings back: price, beds, baths, living area and lot size, address and coordinates, property type, MLS status and number, days on market, price per sqft and a clean listing URL. Filter by status (for sale or sold), price, beds, baths and property type, and collect up to 1,750 listings in one call.
- **Detail** (`mode=detail`) - give it a listing URL and get one home in full: status, the Redfin Estimate, listing brokerage, tax and assessed values, the full price history and the photo gallery.

No Redfin account or API key is needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search listings

```
POST /realestate/redfin
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `redfinSearch`. |
| `location` | yes | ZIP or city and state, e.g. `78704` or `Austin, TX`. A ZIP resolves most reliably; a plain city and state is best effort, and a location Redfin cannot resolve returns `400`. |
| `status` | no | `for_sale` (default) or `sold`. |
| `sold_within_days` | no | With `status=sold`: how many days to look back. Default `90`, max `1825`. |
| `property_type` | no | `houses`, `condos`, `townhomes`, `multi_family`, `land`, `manufactured` or `other`. Omit for all types. |
| `min_price` / `max_price` | no | Price range in USD. |
| `beds` | no | Minimum bedrooms. |
| `baths` | no | Minimum bathrooms. |
| `sort` | no | `recommended` (default), `newest`, `price_asc`, `price_desc`, `sqft` or `price_per_sqft`. |
| `max_results` | no | How many listings to collect across pages (about 350 per page). Default `350`, max `1750`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Defaults to US. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/realestate/redfin?mode=search&location=78704&status=for_sale&beds=3&max_results=10" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.redfin_search("78704", status="for_sale", beds=3, max_results=10)
```

```ts Node.js

  status: "for_sale",
  beds: 3,
  maxResults: 10,
});
```

```php PHP
    'status' => 'for_sale',

```

## Home detail

```
POST /realestate/redfin
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `detail` by `redfinDetail`. |
| `url` | yes | Redfin listing URL, e.g. the `url` of a search result. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Defaults to US. |

## What you can build

- **Comparable sales** - search `status=sold` with `sold_within_days` to pull recent sold prices for a ZIP.
- **Pricing models** - feed `price`, `sqFt`, `lotSize`, `yearBuilt` and `pricePerSqFt` into valuation or rent models.
- **Listing monitoring** - track `mlsStatus` and `daysOnMarket` for a market and flag new or stale listings.
- **Property research** - add tax values, the Redfin Estimate and the full price history to a home through detail mode.
