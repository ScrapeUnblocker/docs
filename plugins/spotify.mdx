title: "Spotify plugin"
description: "Spotify artists, albums, tracks, playlists and search as clean JSON - with play counts, monthly listeners, world rank and top cities, plus followers, discography and full track lists."
sidebarTitle: "Spotify"
---

The **Spotify** plugin turns the Spotify catalog into structured JSON, including the play counts and audience numbers that Spotify's official Web API does not expose:

- **Artist** - followers, monthly listeners, world rank, top cities with listener counts, biography, links and images, top tracks with play counts, discography groups, related artists, releases the artist appears on and playlists that feature the artist.
- **Album** - type, release date, label, copyright, artists, cover and its tracks with play counts.
- **Track** - play count, duration, explicit flag, album and every credited artist.
- **Playlist** - name, description, followers, owner, cover and its tracks with play counts, date added, tempo (`bpm`) and key.
- **Search** - matching tracks, artists, albums or playlists.

Pass an item as an open.spotify.com URL, a Spotify URI (`spotify:artist:...`) or a bare id. Lists page with `offset` and `max_results`, and every list answer carries `hasMore` and `nextOffset`. Each page fetched is one billed unit (`pagesFetched`). No Spotify account, developer app or OAuth token is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Artist

```
POST /music/spotify
```

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | The artist: an open.spotify.com URL (`https://open.spotify.com/artist/4tZwfgrHOc3mvqYlEYSvVi`), a Spotify URI or a bare 22-character id. |
| `type` | - | Set to `artist` by `spotifyArtist`. |
| `discography` | no | `true` also returns the artist's full release list (albums, singles, compilations, newest first) in `releases`, paged by `offset` and `max_results`. Default `false`. |
| `proxy_country` | no | Country the request is sent from (ISO-2, e.g. `DE`). Spotify's market follows it, which can change `playable` and search order; play counts are the same everywhere. Leave blank for any. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/music/spotify?type=artist&id=4tZwfgrHOc3mvqYlEYSvVi" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client
```

## Album

```
POST /music/spotify
```

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | The album: an open.spotify.com URL, a Spotify URI or a bare id. |
| `type` | - | Set to `album` by `spotifyAlbum`. |
| `offset` | no | 0-based track position to start from. Pass the `nextOffset` of a previous response to continue. Default `0`. |
| `max_results` | no | How many tracks to collect, `1`-`1000` (100 per page). Default `100`. |
| `proxy_country` | no | Country the request is sent from (ISO-2). Leave blank for any. |

<CodeGroup>

## Search

```
POST /music/spotify
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | Search text, e.g. `daft punk`. |
| `type` | - | Set to `search` by `spotifySearch`. |
| `search_type` | no | What the search returns: `tracks` (default), `artists`, `albums` or `playlists`. |
| `offset` | no | 0-based result position to start from. Pass the `nextOffset` of a previous response to continue; Spotify serves search results up to position 1000. Default `0`. |
| `max_results` | no | How many results to collect, `1`-`1000` (50 per page). Default `20`. |
| `proxy_country` | no | Country the request is sent from (ISO-2). It can change search order. Leave blank for any. |
