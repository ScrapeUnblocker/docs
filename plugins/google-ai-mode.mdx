The **Google AI Mode** plugin asks Google AI Mode a question and returns its full answer as structured JSON. AI Mode is Google's conversational search tab (`udm=50`), not the AI Overview that sits on top of a normal results page: the answer is longer, structured with headings, lists and tables, and backed by a list of cited pages.

Every call returns the answer three ways - plain text, Markdown, and ordered `blocks` (paragraphs, headings, lists, tables and code) for when you want to render or analyse its structure - plus the `references` the answer cites (title, URL, domain, site name and snippet), the `links` written into the answer text and the `followUps` Google closes the answer with. Use it to see which sites Google's AI recommends for a question, how it describes your brand or product, and how that changes by market.

Set `proxy_country` to ask from a market (the Google market `gl` follows it) and `hl` for the answer's language. Answers differ between identical requests, as they do for a person, so track them over several calls rather than reading one answer as fixed. No Google account or API key is involved. For the AI Overview on a regular results page, use [`/serpApi`](/guides/serp-scraping), whose response carries an `aiOverview` block.

## Endpoint

```
POST /search/google-ai-mode
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | The question to ask, e.g. `how to learn python fast`. |
| `proxy_country` | no | Country the request is sent from (ISO-2, e.g. `US`, `DE`). The Google market (`gl`) follows it unless `gl` is set. |
| `gl` | no | Google market override (ISO-2, e.g. `us`, `de`). Default: `proxy_country`, else `us`. |
| `hl` | no | Language Google answers in, e.g. `en`, `de`, `pt-BR`. Default `en`. |

To ask from another market, add `proxy_country` (and `hl` for the language), e.g. `su.google_ai_mode("beste laptop für studenten", proxy_country="DE", hl="de")`.

Each answer is billed as one request. A `502` (no complete answer) is not billed.

| Field | Notes |
| --- | --- |
| `answer.text` | The whole answer as plain text. |
| `answer.markdown` | The whole answer as Markdown, with bold, headings, lists and tables kept. |
| `answer.blocks` | The answer in order, one object per block: `paragraph` and `code` (`text`), `heading` (`level`, `text`), `list` (`ordered`, `items` with `text` and nesting `level`) and `table` (`header`, `rows`). |
| `references` | The pages the answer cites, in Google's order: `title`, `url`, `domain`, `source` (site name), `snippet` and `position`. |
| `links` | Links written into the answer text, each with its anchor `text` and `url`. |
| `followUps` | The follow-up questions Google closes the answer with, when it offers any (else an empty list). |
| `hl` / `gl` / `proxyCountry` | The language and market used, and the country the request was sent from. |
| `url` | The AI Mode address the answer was read from. |

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. an empty `q` (plain-text message). |
| `403` | Google kept answering with a CAPTCHA after retries. Try another `proxy_country`. |
| `502` | No complete AI Mode answer: Google blocked the request, the answer did not finish streaming, or the call did not finish in time. Not billed. Retry. |
| `503` | No proxy exit was free for this market. Retry, or pick another `proxy_country`. |

## What you can build

- **AI search visibility tracking** - see whether Google's AI recommends your brand, product or site for the questions your customers ask, and which competitors it cites instead.
- **Citation monitoring** - track which domains AI Mode cites for a topic and how that shifts over time and by market.
- **Content research** - read how Google's AI structures an answer (steps, comparison tables, recommended tools) to plan your own content.
- **Market comparison** - ask the same question from several countries and languages and compare the answers.
