The **Wellfound** plugin turns Wellfound (formerly AngelList Talent) into structured JSON. It covers two endpoints in four modes:

- **Job search** (`/jobs/wellfound`, `mode=search`) - jobs by role, location or remote role: title, link, full description, compensation parsed into a salary range and an equity range, job type, locations, remote policy, accepted remote regions, years of experience, posting date and the hiring startup.
- **Job page** (`/jobs/wellfound`, `mode=job`) - one job in full: description as text and HTML, salary with its period, skills, visa sponsorship, relocation, remote hiring regions, preferred timezones, hiring contact and the company with its funding and founders.
- **Company profile** (`/companies/wellfound`, `mode=profile`) - a startup's profile: description, website and social links, size, stage, markets, locations, total raised and funding rounds, founders, perks, open jobs by role, its first open jobs and similar companies.
- **Startup directory** (`/companies/wellfound`, `mode=search`) - Wellfound's startup directory by location or industry, 10 companies per page.

Role, location and company accept plain text (`software engineer`, `new york`) or Wellfound slugs (`software-engineer`, `new-york`). No Wellfound account is needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Job search

```
POST /jobs/wellfound
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `wellfoundJobs`. |
| `role` | no | Role as text or Wellfound slug, e.g. `software engineer`, `product-manager` or `data-scientist`. |
| `location` | no | Location as text or slug, e.g. `new york`, `san-francisco`, `london` or `berlin`. |
| `remote` | no | `true` for remote jobs only (needs `role`, no `location`). Default `false`. |
| `url` | no | A Wellfound search URL instead of `role` / `location` / `remote`, e.g. `https://wellfound.com/role/l/software-engineer/san-francisco`. |
| `page` | no | 1-based listing page to start from, `1`-`500`. Default `1`. Use `nextPage` from a previous response to continue. |
| `max_results` | no | How many jobs to collect across pages, `1`-`500`. Default: the whole first page (20 companies with up to 3 jobs each, usually 30-60 jobs). Each page fetched is one billed request (`pagesFetched`). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/jobs/wellfound?mode=search&role=software%20engineer&location=new%20york" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.wellfound_jobs("software engineer", location="new york")
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

```


| Field | Notes |
| --- | --- |
| `id` / `title` / `slug` / `url` | Wellfound job id, title, slug and link. Pass `url` to job page mode. |
| `primaryRole` / `jobType` | Role category and `full-time`, `part-time`, `contract` or `internship`. |
| `compensation` | Compensation line as Wellfound prints it. |
| `salary` | Parsed `min`, `max` and `currency`, or `null`. |
| `equity` | Parsed `min` and `max` in percent (and `offered`), or `null` when no equity is listed. |
| `locations` / `remote` | Job locations and the remote flag. |
| `remotePolicy` / `wfhFlexible` | `ONSITE`, `REMOTE`, `ONSITE_OR_REMOTE` or `HYBRID`, and Wellfound's flexible-WFH flag. |
| `acceptedRemoteLocations` | Regions a remote job accepts. |
| `yearsExperienceMin` / `yearsExperienceMax` | Years of experience asked for. |
| `postedAt` | Posting time (ISO 8601). |
| `autoPosted` / `atsSource` | Wellfound's flag for jobs imported automatically, and the applicant tracking system they came from when known. |
| `description` | The full job description (Markdown). |
| `company` | Hiring startup: `id`, `name`, `slug`, `url`, `tagline`, `logoUrl`, `companySize`, `stage` and `badges`. |

`totalJobs`, `totalCompanies` and `pageCount` are the totals for the search; `nextPage` and `hasMore` drive paging. A listing page holds 20 companies with up to 3 matching jobs each.

## Startup directory

```
POST /companies/wellfound
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | Set to `search` by `wellfoundCompanySearch`. |
| `location` | no | Location as text or slug, e.g. `new york` or `london`. |
| `industry` | no | Wellfound industry slug, e.g. `saas`, `fintech-2`, `artificial-intelligence`, `health-care` or `e-commerce`. Common names such as `fintech`, `healthcare`, `crypto` or `edtech` are mapped to their slug. |
| `url` | no | A Wellfound directory URL instead of `location` / `industry`, e.g. `https://wellfound.com/startups/location/new-york`. |
| `page` | no | 1-based page to start from (10 companies per page). Default `1`. |
| `max_results` | no | How many companies to collect, `1`-`100`. Default `10`. Each page fetched is one billed request (`pagesFetched`). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

## What you can build

- **Startup job boards** - pull jobs by role and location with salary and equity ranges.
- **Compensation research** - compare salary and equity ranges by role, stage and company size.
- **Deal and market research** - list startups by industry or city with funding rounds, total raised and founders.
- **Hiring signals** - track `openJobs` and `openJobsByRole` for a list of startups over time.
