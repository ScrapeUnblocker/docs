The **Idealista** plugin turns idealista, the property portal for Spain (idealista.com), Italy (idealista.it) and Portugal (idealista.pt), into structured JSON. It has two endpoints:

- **Search** (`/realestate/idealista`) - give it a location the way idealista writes it in its URLs (or any idealista search URL) and get the listings back: price with currency and rent period, the original price and the drop in percent after a price cut, price per m², area, rooms, floor, lift, exterior and parking flags, description, tags, photos, plan, video and virtual tour flags, and the agency. Filter by sale or rent, property type, price and size, rooms, bathrooms and features, and collect up to 300 listings in one call.
- **Listing detail** (`/realestate/idealista-detail`) - give it a listing id or URL and get the full listing: the price breakdown, every feature group idealista lists, bathrooms, year built, energy rating, description, address lines, coordinates, the photo gallery, floor plans and the advertiser.

No idealista account or API key is needed.

## Property search

```
POST /realestate/idealista
```

| Field | Required | Notes |
| --- | --- | --- |
| `location` | yes | Location as idealista writes it in its URLs: a municipality (`madrid-madrid`, `barcelona-barcelona`, `milano-milano`, `lisboa`), a district (`madrid/centro`, `lisboa/arroios`) or a province (`malaga-provincia`). Not used when `url` is given. |
| `url` | no | Any idealista search URL with its filters (idealista.com, .it or .pt). Overrides `location` and the filter fields. |
| `country` | no | `es` (default, idealista.com), `it` (idealista.it) or `pt` (idealista.pt). |
| `operation` | no | `sale` (default) or `rent`. |
| `property_type` | no | `homes` (default), `new_homes`, `offices`, `premises`, `garages`, `lands`, `storage`, `buildings` or `rooms`. |
| `min_price` / `max_price` | no | Price range in EUR (monthly rent with `operation=rent`). |
| `min_size` / `max_size` | no | Area range in m². |
| `rooms` | no | Comma-separated room counts, e.g. `2,3`. Bedrooms in Spain (`0` = studio ... `4` = four or more) and Portugal (T0 ... T4+); total rooms in Italy (`1` ... `5` = five or more). |
| `bathrooms` | no | Comma-separated `1`, `2`, `3` (`3` = three or more). |
| `features` | no | Comma-separated: `lift`, `terrace`, `balcony`, `garage`, `pool`, `garden`, `air_conditioning`, `storage_room`, `fitted_wardrobes`, `accessible`, `luxury`, `new_construction`, `good_condition`, `to_renovate`. |
| `sort` | no | `relevance` (default), `price_asc`, `price_desc`, `newest`, `oldest`, `size_asc`, `size_desc`, `price_per_m2_asc`, `price_per_m2_desc` or `biggest_drop`. |
| `page` | no | 1-based results page to start from (30 listings per page, idealista shows at most 60 pages per search). Use `nextPage` from a previous response to continue. |
| `max_results` | no | How many listings to collect across pages, `1`-`300`. Default `30`. Each page fetched is one billed request (`pagesFetched`). |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

| Field | Notes |
| --- | --- |
| `id` / `url` / `title` | idealista listing id, link and title. |
| `price` / `priceText` / `currency` | Numeric price, the price as printed, and the currency (`EUR`). |
| `pricePeriod` | `month` on rentals. |
| `originalPrice` / `priceDropPercent` | The price before a cut and the drop in percent, when idealista shows a price cut. |
| `pricePerM2` | Price per m², when idealista shows it on the card. |
| `area` / `rooms` | Area in m² and room count. |
| `floor` / `lift` / `exterior` | Floor line as printed, plus lift and exterior flags. |
| `parking` | `included` or `optional`, when the card mentions parking. |
| `description` | Listing description from the search card. |
| `tags` | idealista's labels, e.g. `Alquiler de temporada` (seasonal rental). |
| `images` / `imageCount` | Card photo and the total photo count. |
| `multimedia` | Extra media on the listing: `PLAN`, `VIDEO`, `VIRTUAL_TOUR_3D`, `VIRTUAL_TOUR_360`. |
| `agency` / `professional` | The agency (`name`, `url`, `logo`) and whether the advertiser is a professional. |

The response also carries `totalResults`, the `heading` idealista shows, `page`, `nextPage` and `hasMore` for paging, `viewLimitReached` (true once the 60-page limit of a search is hit) and the `searchUrl` that was read. A search with no match answers `200` with an empty `listings`; an unknown location answers `404`.

## Listing detail

```
POST /realestate/idealista-detail
```

| Field | Required | Notes |
| --- | --- | --- |
| `listing` | yes | idealista listing id (`112207707`) or URL, e.g. `https://www.idealista.com/inmueble/112207707/`, `https://www.idealista.it/immobile/37068709/` or `https://www.idealista.pt/imovel/34868387/`. |
| `country` | no | Country of a bare listing id: `es` (default), `it` or `pt`. Ignored for a URL. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2). Leave blank to let the API pick. |

| Field | Notes |
| --- | --- |

A field idealista does not show for a listing is left out. A listing its advertiser removed answers `404`.

## What you can build

- **Rent and price indexes** - track price and price per m² by district across Spain, Italy and Portugal.
- **Price-cut tracking** - sort by `biggest_drop` and follow `originalPrice` / `priceDropPercent` over time.
- **Investment screening** - combine area, rooms, floor, energy rating and price per m² to rank listings.
- **Listing enrichment** - read each search result in full through the detail endpoint for features, coordinates and floor plans.
