The **Smyths Toys** plugin returns data from Smyths Toys UK (smythstoys.com) as JSON. One endpoint, `/marketplace/smyths-inventory`, works in four modes:

- **Stock and price** (`mode=product`, the default when you pass `code`) - one product's stock and price as the JSON Smyths' own storefront reads: price, was-price, RRP and discount, home delivery stock and messages, click & collect stock, pre-order flags and expected stock dates, age suitability and the delivery type.
- **Details** (`mode=details`) - the JSON Smyths' product page is built from: name, brand, EAN, description, key features, safety warnings, the image gallery with any videos, rating, review count and breadcrumb.
- **Search** (`mode=search`) and **category** (`mode=category`) - the products of a search or a category with code, name, link, price, image and rating, 60 per page, so you can find product codes. A category also returns its breadcrumbs and subcategories with product counts.

Stock and details come back as Smyths' own JSON, unchanged, so code written against Smyths' response keeps working. Prices are in GBP. Smyths' search returns its best 240 matches at most; list a category to get every product of a range. No Smyths account or API key is involved.

The SDKs have one method per mode: `smyths_inventory`, `smyths_details`, `smyths_search` and `smyths_category` (`smythsInventory`, `smythsDetails`, `smythsSearch` and `smythsCategory` in Node.js and PHP).

<Note>

## Stock and price

```
POST /marketplace/smyths-inventory
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | `product`, the default when `code` is given. Set by `smythsInventory`. |
| `code` | yes | Product code (`259087`), a product or bundle page link, or a product-inventory link. |
| `bundle` | no | `true` to ask for a bundle. A bundle page link sets it, and a code Smyths does not answer as a product is asked again as a bundle. Default `false`. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/smyths-inventory?code=259087" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

## Search and categories

```
POST /marketplace/smyths-inventory
```

| Field | Required | Notes |
| --- | --- | --- |
| `mode` | - | `search` (the default with `query`, set by `smythsSearch`) or `category` (the default with `category`, set by `smythsCategory`). |
| `query` | for a search | What to search for, e.g. `lego star wars`. Smyths returns its best 240 matches at most. |
| `category` | for a category | A category code (`SM060101`) or a category page link. The top categories are Toys `SM0601`, Baby `SM0602`, Outdoor `SM0603` and Gaming & Tech `SM0604`; each listing names its subcategories. |
| `sort` | no | Search: `relevance` (default), `bestsellers`, `price_asc`, `price_desc`, `rating_desc` or `newest`. Category: `bestsellers` (default), `price_asc`, `price_desc`, `rating_desc` or `newest`. |
| `page` | no | 1-based listing page to start from (60 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`600`. Default `60`. Each page fetched is billed as one request (`pagesFetched`). |

| `category` | Category listings only: `code`, `title`, `url`, `breadcrumbs` and `subcategories` (`name`, `code`, `url` and product `count`). |

A search with no matches is a `200` with an empty `products` list.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, or none of `code`, `query` and `category`. |
| `404` | Smyths has no product with that code, or no such category. |
| `502` | Smyths refused every attempt or did not answer in time; retry. With `X-Origin-Status`, the body is Smyths' own JSON error, which Smyths also returns for some codes it does not know. That answer is not billed. |

## What you can build

- **Stock alerts** - watch home delivery and click & collect stock for sought-after toys and pre-orders.
- **Price tracking** - follow price, was-price and RRP across a category.
- **Catalogue sync** - pull descriptions, features, safety warnings and images for products you sell.
- **Range analysis** - list a whole category with its subcategories and product counts.
