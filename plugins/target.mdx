The **Target** plugin returns Target (US) data as structured JSON. It is three endpoints:

- **`/marketplace/target-search`** - the products Target shows for a keyword, each with a `tcin`, title, brand, price and formatted price, currency, image and a clean product URL. Sort, filter by price and collect up to `max_results`.
- **`/marketplace/target-category`** - the products of one category or brand page, with price, sale details, rating and promotions, sorted and paged. See [Category](#category).
- **`/marketplace/target-product`** - one product in full: price and sale details, ratings and the star histogram, description, specifications, images, every variant, and shipping dates to a ZIP code plus pickup stock and aisle at a store. See [Product](#product).

It runs on the same fetch chain that serves `getPageSource`. target.com is an empty client-rendered shell, so the plugin reads the products straight from Target's own Redsky JSON API (`plp_search_v2`) - no Target developer account needed.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Endpoint

```
POST /marketplace/target-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | What to search, e.g. `coffee maker` or `tv`. |
| `sort` | no | `relevance` (default), `newest`, `price_low` or `price_high`. |
| `min_price` / `max_price` | no | Price range in USD. |
| `max_results` | no | How many products to collect across pages. Default `24`, max `500`. |
| `proxy_country` | no | Proxy country (ISO-2). Defaults to US (required by Target). |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/target-search?query=coffee%20maker&sort=price_low&max_results=48" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.target_search("coffee maker", sort="price_low", max_results=48)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.targetSearch("coffee maker", {
  sort: "price_low",
  maxResults: 48,
});
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->targetSearch('coffee maker', [
    'sort' => 'price_low',
    'max_results' => 48,
]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.target_search("coffee maker", sort: "price_low", max_results: 48)
```

</CodeGroup>

```json
    }

```

### Product fields

| Field | Notes |
| --- | --- |
| `tcin` | Target's own product id, used in the `/p/-/A-<tcin>` URL. |
| `price` / `formattedPrice` | Numeric current price and the same price as Target prints it (e.g. `$79.99`). |
| `currency` | ISO currency (USD). |
| `brand` | Product brand. |
| `image` | Product image URL. |
| `url` | Clean `/p/-/A-<tcin>` product URL. |

<Note>
Any field with no value is omitted from a product, so each item carries only the fields Target's search returned (e.g. `brand` or `image` may be absent).
</Note>

## Category

```
POST /marketplace/target-category
```

| Field | Required | Notes |
| --- | --- | --- |
| `category` | yes | Target category id (e.g. `5xtro`, the part after `N-` in a category link) or a target.com category link, e.g. `https://www.target.com/c/coffee-makers-tea-espresso-kitchen-appliances-dining/-/N-5xtro`. A brand page (`/b/<brand>/-/N-<id>`) lists that brand. |
| `sort` | no | `relevance` (default), `price_low`, `price_high`, `rating`, `best_selling` or `newest`. |
| `page` | no | 1-based page to start from, `1`-`50` (24 products per page). Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`240`. Default `24`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/target-category?category=5xtro&sort=best_selling&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.target_category("5xtro", sort="best_selling", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.targetCategory("5xtro", {
  sort: "best_selling",
  maxResults: 3,
});
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->targetCategory('5xtro', [
    'sort' => 'best_selling',
    'max_results' => 3,
]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.target_category("5xtro", sort: "best_selling", max_results: 3)
```

</CodeGroup>

<Note>
Each page fetched is billed as one request (`pagesFetched`): a `max_results` of 240 reads up to 10 pages and is billed up to 10 times. Target serves at most 50 pages of 24. Filters in a category link (`...Z<facet>`) are not applied.
</Note>

## Product

```
POST /marketplace/target-product
```

| Field | Required | Notes |
| --- | --- | --- |
| `tcin` | one of `tcin` / `url` | Target item number (TCIN), e.g. `52580270` (the number after `A-` in a product link; the `tcin` of a search or category result). |
| `url` | one of `tcin` / `url` | Instead of `tcin`: a target.com product link, e.g. `https://www.target.com/p/hamilton-beach-coffee-maker/-/A-52580270` (a `?preselect=` variant in the link is honoured). |
| `store_id` | no | Target store whose pickup and shelf stock is reported, e.g. `1375`. Default `1375` (Minneapolis Nicollet Mall). |
| `zip` | no | US ZIP code the shipping dates are quoted for. Default `55403`. |

<CodeGroup>

```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/target-product?tcin=52580270&store_id=1375&zip=55403" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.target_product("52580270", store_id="1375", zip="55403")
```

```ts Node.js

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

  zip: "55403",
});
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY
```


</CodeGroup>

To look a product up by link, leave the first argument out and pass `url` (`su.target_product(url="https://www.target.com/p/...")` in Python, `su.targetProduct(undefined, { url })` in Node.js). Give `tcin` or `url`, not both. Each product is billed as one request.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters: a missing `query` (search) or `category`, a missing or invalid `tcin` / `url` (or both given), or an invalid `store_id` / `zip` (product). |
| `404` | Category: Target has no such category, or it has no products. Product: Target has no product with this TCIN. |
| `502` | Target blocked every attempt, returned no data, or the call did not finish in time. Retry. |

## What you can build

- **Price monitoring and repricing** - track `price` for a product over time.
- **Catalog and assortment research** - pull a whole category with brands.
- **Competitor tracking** - compare the same keyword against your own listings.
- **Availability and pricing feeds** - build a live Target price feed keyed by `tcin`.
- **Store stock checks** - read pickup status, quantity and aisle for a product at the stores you care about.
- **Category tracking** - follow a category's best sellers over time with `sort=best_selling`.
