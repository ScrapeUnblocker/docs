The **Bed Bath & Beyond** plugin returns product data from Bed Bath & Beyond (bedbathandbeyond.com, US) as structured JSON. It is two endpoints:

- **`/marketplace/bedbathandbeyond-search`** - the products for a keyword: product id and SKU, title, link and image, the price and the top of the range when options are priced differently, the price type (sale or standard), the compare-at price with its kind (MSRP, compare at or was), the discount, the regular price, the rating and review count, the number of options, the badge (e.g. Best Seller), the fast-delivery flag, the Welcome Rewards amount and whether the listing is sponsored. About 60 products a page; one call collects up to 300.
- **`/marketplace/bedbathandbeyond-product`** - one product in full: brand and part number, price with its label, compare-at price, savings, stock, rating with its star histogram, description, specifications, breadcrumbs, country of origin, images and videos, and up to 100 options (size, colour) each with its own price, regular and compare-at price, sale flag and quantity on hand.

Prices are the ones a signed-out shopper sees, in USD. No Bed Bath & Beyond account is involved.

<Note>
Bed Bath & Beyond protects its product pages with Akamai Bot Manager, so a **product call can take up to a minute**. Set a generous client timeout (the SDKs default to 180 seconds, which is enough). Searches usually answer in a few seconds.
</Note>

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /marketplace/bedbathandbeyond-search
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | one of `query` / `url` | What to search for, e.g. `bath towels`, `office chair` or `table lamp`. |
| `url` | one of `query` / `url` | Instead of `query`: a Bed Bath & Beyond search link, e.g. `https://www.bedbathandbeyond.com/search?keywords=towels` (its sort and page are used). |
| `sort` | no | `relevance`, `on_sale`, `best_selling`, `price_low`, `price_high`, `rating` or `newest`. Default `relevance`. |
| `page` | no | 1-based results page to start from, `1`-`100`. Default `1`. |
| `max_results` | no | Products to collect across pages, `1`-`300`. Default `60`. The site serves about 60 per page, and each page fetched is billed as one request (`pagesFetched`). |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/marketplace/bedbathandbeyond-search?query=bath%20towels&sort=price_low&max_results=3" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```

```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.bedbathandbeyond_search("bath towels", sort="price_low", max_results=3)
```

```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.bedbathandbeyondSearch("bath towels", { sort: "price_low", maxResults: 3 });
```

```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->bedbathandbeyondSearch('bath towels', ['sort' => 'price_low', 'max_results' => 3]);
```

```ruby Ruby
require "scrapeunblocker"

su = ScrapeUnblocker::Client.new # reads SCRAPEUNBLOCKER_KEY

result = su.bedbathandbeyond_search("bath towels", sort: "price_low", max_results: 3)
```
</CodeGroup>

To search with a link instead, leave the first argument out and pass `url` (`su.bedbathandbeyond_search(url="https://www.bedbathandbeyond.com/search?keywords=towels")` in Python, `su.bedbathandbeyondSearch(undefined, { url })` in Node.js). A keyword the site sends to a department page (e.g. `rugs` or `sofa`) returns that department's listing, named in `redirectedTo`.

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. neither `query` nor `url`, an unknown `sort`, a `page` above `100`, a `max_results` above `300`, or a `product` that is not a product id or link. |
| `404` | The site found no products for the search, or has no such product. |
| `502` | The site blocked every attempt, returned no results page or product data, or the call did not finish in time. Retry. |

## What you can build

- **Price and discount tracking** - follow sale prices, compare-at prices and discounts on home goods over time.
- **Stock monitoring** - watch every option's quantity on hand and low-stock messages for the sizes and colours you care about.
- **Assortment research** - compare brands, ratings and badges across a category, sorted by best selling or newest.
- **Catalog enrichment** - pull specifications, descriptions, images and videos for products you list elsewhere.
