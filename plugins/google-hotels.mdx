The **Google Hotels** plugin turns Google Hotels into structured JSON. It is two endpoints:

- **`/travel/google-hotels`** - the properties Google lists for a place, an area, a landmark or a hotel name: name, type (hotel or vacation rental), class and stars, the price for your stay per night and in total with and without taxes, Google's deal badge, the rating with its 1-5 star breakdown and review topics, amenities, a short description, the website, coordinates, nearby places with travel times, images and a Google Maps link, plus the sponsored listings on the page.
- **`/travel/google-hotels-property`** - one property, by the `propertyToken` of a search result: the offer of every booking site Google lists for the stay (the hotel's own site marked `official`), room-level rates with free-cancellation deadlines where Google shows them, and the address, phone, description and Google place id.

Set the stay with `check_in` / `check_out`, the party with `adults` and `children`, and pick the `currency`, the language (`hl`) and the market (`gl`). Google serves about 20 properties per page; one call collects up to 100. No Google account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Search

```
POST /travel/google-hotels
```

| Field | Required | Notes |
| --- | --- | --- |
| `q` | yes | What to search, as on Google Hotels: a place (`hotels in Paris`, `Lisbon`), an area or landmark, or a hotel name. A query naming one hotel returns just that hotel (`matchedProperty: true`). |
| `check_in` / `check_out` | no | Stay dates, `YYYY-MM-DD`, for stays of up to 30 nights. Leave both empty for Google's default stay. |
| `adults` | no | Number of adults, `1`-`10`. Default `2`. |
| `children` | no | Ages of the children, comma-separated, e.g. `7,10` (up to 6 children). |
| `currency` | no | Price currency, ISO 4217 (`USD`, `EUR`, `GBP`, ...). Default `USD`. |
| `hl` | no | Language of names, amenities and price formats, e.g. `en`, `de`, `fr`. Default `en`. |
| `gl` | no | Market, a 2-letter country code. Google localizes the booking sites to it. Default `us`. |
| `max_results` | no | Properties to collect across pages, `1`-`100`. Default `20`. |
| `page_token` | no | The `nextPageToken` of a previous response, to continue where it stopped. |

<Note>
Each Google results page fetched is billed as one request. Google serves about 20 properties per page, so `max_results=60` usually takes three pages and counts as 3 requests; `pagesFetched` in the response is the exact number. A property call is one request.
</Note>

Name the city or area in `q`: a query Google cannot place returns hotels around the request's exit instead, and `warnings` says so.

| Field | Notes |
| --- | --- |
| `applied` | What Google actually used: `checkIn`, `checkOut`, `nights`, `adults`, `children`, `currency` and the `place` it searched. |
| `matchedProperty` | `true` when `q` named one hotel and Google answered with just that hotel. |
| `properties[].name` / `type` | Property name; `type` is `hotel` or `vacation_rental`. |
| `properties[].propertyToken` | Pass it to [Property](#property) for every booking site's offer. |
| `properties[].price` | The price for the stay in `currency`: `perNight`, `perNightWithTaxes`, `total`, `totalWithTaxes` and `taxes` as numbers, Google's own `display` string (`displayIncludesTaxes` says whether it includes taxes), and the formatted `perNightWithTaxesDisplay` / `totalWithTaxesDisplay`. |
| `properties[].deal` | Google's deal badge, e.g. `{ "type": "deal", "description": "18% less than usual" }`, or `null`. |
| `properties[].hotelClass` / `stars` | Google's class label (`5-star hotel`) and the star count; `null` for most vacation rentals. |
| `properties[].rating` / `reviews` / `ratingsBreakdown` | Average rating out of 5, the review count, and the share and count of reviews per star. |
| `properties[].reviewTopics` | What reviews mention: `name`, `fullName`, `mentions`, `positive`, `negative` and a `sentiment` score. |
| `properties[].amenities` / `amenityCodes` | Amenities as Google lists them, and Google's numeric amenity codes. |
| `properties[].description` / `website` | Google's one-line description and the property's own website. |
| `properties[].latitude` / `longitude` / `country` | Location. |
| `properties[].nearbyPlaces` | Nearby attractions, transit stops and airports, with the travel time per mode (`walking`, `public_transport`, `taxi`). |
| `properties[].thumbnail` / `images` | Image URLs. |
| `properties[].mapsUrl` / `mapsCid` / `hotelId` | The Google Maps link and Google's ids, when Google has them. |
| `ads` | The sponsored listings on the page: `name`, the advertiser as `provider` (e.g. `Booking.com`), `propertyToken`, `price`, `rating`, `reviews`, `stars`, coordinates and `thumbnail`. |
| `totalResults` | Google's count of matching properties. |
| `pagesFetched` / `droppedFromLastPage` | Pages fetched (the billed number), and how many properties of the last page were left out because `max_results` was reached. |
| `hasMore` / `nextPageToken` | Whether Google has more, and the token to pass as `page_token` to continue. |
| `googleUrl` / `exitCountry` | The same search on google.com/travel, and the country of the exit that fetched it. |
| `warnings` | Notes about the answer: Google priced in another currency or used other dates than you asked for, Google searched a place `q` does not seem to name, or a later page could not be fetched. Empty when there is nothing to note. |

## Property

## Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid parameters, e.g. a missing `q`, a `check_in` in the past or a `check_out` before `check_in`. The message says what to fix. |
| `404` | Google Hotels returned no properties for the search, or has no property for the `property_token`. |
| `502` | Google blocked every attempt, no page came back, or the call did not finish in time. Retry. |

## What you can build

- **Rate comparison** - compare what every booking site charges for the same stay, including the hotel's own site.
