The **Crunchbase** plugin turns a Crunchbase organization profile into structured JSON. Give it the organization's slug - the part after `/organization/` in its profile URL, such as `stripe` - or the full profile URL, and it returns the organization: name, legal name, descriptions, logo, website, headquarters, operating, company and IPO status, employee range, industries, CB rank with its 90-day trend, growth and heat scores, founders, funding rounds with their lead investors, investors, acquisitions, investments, exits, key people, board members, similar companies, products, contact details, social links, monthly web traffic, technology counts, Crunchbase's predictions, key events with their press sources, offices and recent news.

What Crunchbase leaves empty is filled from the company's own homepage when the homepage states it: its SEO description, share image, social profiles (Instagram, YouTube, GitHub and the rest), founding date, head count, street address and postal code, contact email and phone. `fromWebsite` names the keys that came from the homepage; Crunchbase's own values always win. The homepage is read in the same call, at no extra charge, and a slow or unreachable homepage leaves the Crunchbase answer as it is.

Only have a company name? Search by name first to get its slug.

It reads what a signed-out visitor sees, so values Crunchbase shows only to paying users (founding, closing and IPO dates, funding totals, round dates and amounts, acquisition prices, exits, valuation) come back `null` - except a founding date the company's homepage states - and `paywalledFields` names the ones Crunchbase holds for that organization. No Crunchbase account or API key is involved.

<Note>
Try it in the dashboard first: [app.scrapeunblocker.com/dashboard/plugins](https://app.scrapeunblocker.com/dashboard/plugins). You get a live results view plus a copy-paste snippet.
</Note>

## Company profile

```
POST /companies/crunchbase
```

| Field | Required | Notes |
| --- | --- | --- |
| `organization` | yes | Crunchbase organization slug, e.g. `stripe` or `tesla-motors`, or the full profile URL. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/companies/crunchbase?organization=stripe" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.crunchbase_company("stripe")
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

```

| Field | Notes |
| --- | --- |
| `name` / `legalName` / `slug` / `uuid` / `url` | Names and Crunchbase identifiers of the organization. |
| `shortDescription` / `description` / `logo` / `website` | Profile text, logo and the company's own website. |
| `seoDescription` / `coverImage` | The homepage's meta description and its share (`og:image`) picture. |
| `headquarters` | `city`, `region`, `country`, `continent` and a one-line `text`; `street` and `postalCode` when the homepage's schema.org address is in the same city. |
| `operatingStatus` / `companyType` / `ipoStatus` | E.g. `active`, `for_profit`, `private`; `stockSymbol` and `stockExchange` for public companies. |
| `employeeRange` / `employeeCount` / `industries` / `industryGroups` | Size band, the exact head count when the homepage states one, and Crunchbase's industry tags. |
| `rank` / `rankDelta90d` | CB rank and its 90-day trend score, from `-10` to `10` (positive means the company moved up, toward #1). |
| `growthScore` / `heatScore` | Crunchbase's scores (`0`-`100`), with `growthScoreDelta90d` and `heatScoreDelta90d` as their change in points over 90 days. |
| `founders` / `keyPeople` / `boardMembers` | People with `name`, `slug`, `url` and `image`; key people add their `title` and `startedOn`. |
| `num*` counts | `numFundingRounds`, `numInvestors`, `numAcquisitions`, `numInvestments`, `numEmployeeProfiles` and more. |
| `fundingRounds` / `investors` | The latest rounds with type and lead investors, and the investors behind them. |
| `acquisitions` / `investments` / `exits` / `subOrganizations` | The organization's deals and holdings; `acquiredBy` and `owner` when it has a parent. |
| `similarCompanies` / `products` | Companies Crunchbase lists as similar, and the organization's products. |
| `contactEmail` / `phone` / `socialLinks` / `linkedinId` | Public contact details; social profiles (`linkedin`, `twitter`, `facebook`, `instagram`, `youtube`, `github`); the company's LinkedIn handle. |
| `webTraffic` | `monthlyVisits` and `monthlyVisitsChange`, the month-over-month change as a fraction (`0.069` = +6.9%). |
| `technology` / `predictions` | Technology and IP counts, and Crunchbase's funding, IPO, acquisition and growth predictions. |
| `events` | `productLaunches`, `partnerships`, `awards`, `layoffs`, `keyEmployeeChanges` and `legalProceedings`, each with its press `source`. |
| `offices` / `news` | Office openings and recent press coverage. |
| `paywalledFields` | The keys that are `null` because Crunchbase shows them only to paying users. |
| `fromWebsite` | The keys filled from the company's homepage rather than Crunchbase. |

Every company or person reference in these lists has the same shape: `name`, `slug`, `url`, `type` and `image`. An unknown slug returns `404`.

## Search by name

```
POST /companies/crunchbase
```

| Field | Required | Notes |
| --- | --- | --- |
| `query` | yes | Company name to search for, e.g. `Revolut`. Returns matching organizations with their slugs instead of one full profile. |
| `max_results` | no | How many matches to return, `1`-`25`. Default `10`. |
| `proxy_country` | no | Proxy country the request is sent from (ISO-2, e.g. `US`). Leave blank to let the API pick. |

<CodeGroup>
```bash cURL
curl -X POST "https://api.scrapeunblocker.com/companies/crunchbase?query=Spotify&max_results=5" \
  -H "x-scrapeunblocker-key: YOUR_API_KEY"
```
```python Python
from scrapeunblocker import Client

su = Client()  # reads SCRAPEUNBLOCKER_KEY

result = su.crunchbase_search("Spotify", max_results=5)
```
```ts Node.js
import { ScrapeUnblockerClient } from "scrapeunblocker";

const su = new ScrapeUnblockerClient(); // reads SCRAPEUNBLOCKER_KEY

const result = await su.crunchbaseSearch("Spotify", { maxResults: 5 });
```
```php PHP
use ScrapeUnblocker\Client;

$su = new Client(); // reads SCRAPEUNBLOCKER_KEY

$result = $su->crunchbaseSearch('Spotify', ['max_results' => 5]);
```
